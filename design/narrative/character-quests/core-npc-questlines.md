**解锁条件**：云中鹤关系值≥30
**预计时长**：1.5小时
**境界要求**：炼气中期以上

### 场景二：废弃药园探索（关系值45解锁）

**场景描述**：
根据云中鹤提供的线索，你在青云镇北山发现了一处废弃的药园。这里曾经种植着珍贵的灵药，但现在大多枯萎。

**探索点**：
1. **药园石碑**：记载药园历史
2. **枯萎的灵药**：需要灵气复苏
3. **隐藏的储物袋**：获得基础炼丹工具

**解谜**：
- 使用灵气浇灌三株枯萎的灵药
- 按五行相生顺序：水→木→火→土→金
- 成功后药园复苏，获得"回春草"×3

**获得物品**：
- 回春草（可炼制回春丹）
- 炼丹笔记（残篇）
- 药园传承（被动：灵药种植+10%）

### 场景三：炼制回春丹（关系值60解锁）

**前提条件**：
- 获得回春草×3
- 基础炼丹技能

**炼制过程**：
1. 准备材料：回春草×3 + 灵气结晶×5
2. 控制火候（QTE小游戏）
3. 凝丹阶段（灵气引导）

**成功奖励**：
- 回春丹×1
- 炼丹经验+20

**使用回春丹**：
```json
{
  "dialogue_id": "YUN_HEAL_001",
  "speaker": "yunzhonghe",
  "text": "这是...回春丹！你竟然真的炼成了。好，好！{player_name}，你没有让我失望。",
  "effects": [
    {"type": "relationship_change", "target": "yunzhonghe", "value": 20}
  ]
}
```

**结果**：
- 云中鹤伤势缓解（但不治愈）
- 传授进阶剑诀（玄阶下品）
- 云中鹤关系值+20

## 支线四：慕容雪 — 前世之谜

**解锁条件**：慕容雪关系值≥30
**预计时长**：2小时
**境界要求**：炼气后期以上

---

### 场景一：神秘的少女（关系值30解锁）

**触发条件**：主线事件五后，青云镇出现神秘少女

**背景**：
- 慕容雪失忆状态出现在青云镇
- 她对飞升之战的符文有反应
- 玩家记忆水晶的画面似乎与她有关

**开场对话**：
```json
{
  "dialogue_id": "MU_QUEST_001",
  "speaker": "murongxue",
  "text": "这个符文...我好像在哪里见过...头好痛...",
  "effects": [
    {"type": "quest_trigger", "target": "murong_memory", "value": true}
  ]
}
```

---

### 场景二：记忆碎片收集（关系值45解锁）

**任务目标**：
- 收集3个记忆碎片触发物
- 每个碎片在中原腹地不同地点
- 慕容雪对碎片有感应

**碎片位置**：
1. 废弃古井底部
2. 青云镇老槐树下
3. 云中鹤的旧物中

**获得线索**：
- 慕容雪可能是上古修士转世
- 她与飞升封印有密切关系

---

### 场景三：封印真相（关系值60解锁）

**场景描述**：
收集完3个碎片后，慕容雪陷入昏迷，梦中看到300年前的真相。

**记忆重现**：
- 慕容雪前世是逍遥派掌门
- 她与血无痕共同发现飞升通道
- 血无痕为独占飞升机会封锁通道
- 慕容雪选择转世等待破局之人

---

### 场景四：宿命觉醒（关系值80解锁）

**获得奖励**：
- 北冥神功残篇（天阶上品）
- 慕容雪的记忆恢复（部分）
- 解锁最终线索：破除封印的方法
- 最终战中慕容雪协助概率+30%

## 支线五：萧寒夜 — 魔道之路

**解锁条件**：萧寒夜关系值≥20
**预计时长**：1.5小时
**境界要求**：炼气后期以上
**注意**：此支线会降低道心值

---

### 场景一：魔道初遇（关系值20解锁）

**触发条件**：主线事件四后，选择放走或击杀魔修时遇到萧寒夜

**背景**：
- 萧寒夜路过青云镇处理宗门事务
- 他对玩家的实力产生兴趣
- 他提供魔道功法的诱惑

**开场对话**：
```json
{
  "dialogue_id": "XIAO_QUEST_001",
  "speaker": "xiaohanye",
  "text": "正道虚伪，不如加入魔道，力量才是永恒。",
  "effects": [
    {"type": "dao_heart_change", "value": -5}
  ]
}
```

---

### 场景二：力量考验（关系值35解锁）

**场景描述**：
萧寒夜设下考验，证明玩家有资格修炼魔道功法。

**考验内容**：
- 击败3个魔道试炼者
- 选择是否杀死俘虏（道心-10）
- 接受魔气入体（需要炼气后期）

**奖励**：
- 噬魂诀（玄阶中品）
- 萧寒夜的认可（关系值+15）

---

### 场景三：家族血仇（关系值50解锁）

**背景**：
- 萧寒夜透露自己是正道大族遗孤
- 家族被天剑盟陷害灭门
- 他需要玩家帮忙寻找证据

**任务目标**：
- 调查天剑盟历史档案
- 找到萧家被陷害的证据
- 揭露正道黑暗面

---

### 场景四：道魔之择（关系值65解锁）

**最终选择**：
- 帮助萧寒夜复仇：道心-20，获得魔道功法
- 劝说萧寒夜放下仇恨：道心+20，关系值取决于检定
- 保持中立：不改变道心

**获得奖励（复仇路线）**：
- 血魔大法残篇（地阶中品）
- 萧寒夜的承诺（最终战协助）
- 魔教声望+30
