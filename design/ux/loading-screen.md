## 1. Purpose & Player Need

### 核心目的

加载界面在游戏启动、存档加载、场景切换时显示，承担以下职责：

1. **进度反馈** — 告知玩家加载正在进行，避免"卡死"焦虑
2. **时间填充** — 利用加载时间展示游戏提示、 lore 或操作指南
3. **沉浸维持** — 水墨风格加载界面维持修真世界沉浸感，不让黑屏打断体验
4. **中断保护** — 提供取消选项（非首次加载时），允许玩家中止操作

### 玩家需求

**游戏启动时**：
- 期望看到游戏品牌标识，建立期待感
- 加载时间较长时需要进度指示
- 首次启动可能有较长的资源初始化

**读取存档时**：
- 期望快速回到游戏
- 显示正在加载的存档信息（境界 + 区域）
- 加载失败时有明确的错误反馈

**场景切换时**：
- 短加载（1-3秒）：显示简洁的加载指示
- 长加载（3秒+）：显示完整加载界面+提示

### 设计原则

- **进度透明**：始终显示加载进度，不使用"旋转菊花"无限指示器
- **信息填充**：加载期间展示有用的游戏知识，不浪费玩家时间
- **沉浸优先**：水墨风格+修真主题文案，维持世界沉浸感
- **容错保护**：加载失败时提供明确错误信息和重试选项

## 2. Player Context on Arrival

### 游戏启动加载

- **时机**：双击游戏可执行文件后
- **前序状态**：无（从桌面进入）
- **情感状态**：期待、好奇
- **预期加载时间**：3-8秒（首次可能更长）
- **特殊**：首次启动需要初始化资源，加载时间较长

### 读取存档加载

- **时机**：主菜单选择"继续修炼"或暂停菜单选择"读取存档"后
- **前序状态**：玩家已选择存档
- **情感状态**：期待回到游戏
- **预期加载时间**：2-5秒
- **特殊**：加载期间显示存档信息

### 场景切换加载

- **时机**：进入战斗、切换区域、传送等
- **前序状态**：游戏运行中
- **情感状态**：过渡期，可能紧张（如进入战斗）
- **预期加载时间**：1-3秒（短加载）
- **特殊**：使用简化加载指示器，不打断沉浸

## 3. Navigation Position

### 层级关系

```
[游戏启动] → 加载界面 → 主菜单
[主菜单] → 选择继续 → 加载界面 → 游戏场景
[游戏内] → 传送/切换区域 → 加载界面 → 新场景
```

### 导航架构

加载界面是**全屏过渡层**，不属于常规UI导航层级：

```
加载界面 (Z-index=600, 全屏模态)
├── 游戏Logo/标题
├── 进度条
├── 加载提示（可选，长加载时显示）
└── 取消按钮（可选，非首次加载时显示）
```

### 定位说明

- **Z-index**: 600（最高层，覆盖所有内容，在Dialog Overlay 500之上）
- **层级深度**: 全屏过渡场景
- **返回方式**: 加载完成后自动进入下一场景
- **取消方式**: ESC键或点击"取消"按钮中止加载

## 4. Entry & Exit Points

### 入口点

| 入口来源 | 触发条件 | 到达状态 |
|----------|----------|----------|
| 游戏启动 | 启动可执行文件 | 完整加载界面 |
| 主菜单 | 点击"继续修炼" | 完整加载界面，显示存档信息 |
| 暂停菜单 | 选择"读取存档"并确认 | 完整加载界面，显示存档信息 |
| 游戏内 | 场景切换/传送/进入战斗 | 简化加载指示器（短加载时） |
| 返回主菜单 | 从游戏内返回 | 完整加载界面 |

### 出口点

| 出口去向 | 触发条件 | 状态变化 |
|----------|----------|----------|
| 主菜单 | 游戏启动加载完成 | 加载界面淡出 → 主菜单淡入 |
| 游戏场景 | 存档加载完成 | 加载界面淡出 → 游戏场景显示 |
| 新场景 | 场景切换完成 | 简化指示器消失 → 新场景可见 |
| 返回来源 | 加载失败或用户取消 | 加载界面淡出 → 返回来源界面 |
| 错误界面 | 加载失败（存档损坏等） | 加载界面 → 错误提示界面 |

## 6. States & Variants

| 状态 / 变体 | 触发条件 | 变化说明 |
|-------------|----------|----------|
| **完整加载** | 游戏启动/存档加载 | 显示Logo、进度条、提示面板、取消按钮 |
| **简化加载** | 场景切换（预计<3秒） | 仅显示状态文字+进度条，无Logo无提示 |
| **进度增长** | 加载过程中 | 进度条从0%增长到100%，状态文字随阶段变化 |

## 7. Interaction Map

| 组件 | 操作 | 输入方式 | 即时反馈 | 结果 |
|------|------|----------|----------|------|
| 取消按钮 | 点击/确认 | 鼠标左键 / Enter | 缩放动画 + 音效 | 取消加载，返回来源界面 |
| 取消按钮 | 快捷键 | ESC | 无 | 取消加载，返回来源界面 |
| 重试按钮（错误时） | 点击/确认 | 鼠标左键 / Enter | 缩放动画 + 音效 | 重新尝试加载 |
| 返回按钮（错误时） | 点击/确认 | 鼠标左键 / Enter | 缩放动画 + 音效 | 返回来源界面 |

### 导航顺序（错误状态时）

```
1. 重试 ← 默认焦点
2. 返回主菜单
```

### 焦点管理

- 加载期间不接受键盘/手柄焦点输入（进度条自动增长）
- 仅在错误状态或取消操作时需要焦点导航
- 错误状态下焦点默认在"重试"按钮

## 9. Transitions & Animations

### 加载界面入场

1. **背景淡入** (0.0s - 0.15s) — 全屏黑色淡入
2. **Logo显现** (0.1s - 0.4s) — 游戏标题从上方落下，水墨扩散效果
3. **进度条淡入** (0.3s - 0.5s) — 进度条和状态文字淡入
4. **提示淡入** (0.5s - 0.7s) — 提示面板淡入（如有）

### 加载界面退场（成功）

1. **进度条满格停留** (0.0s - 0.3s) — 100%停留0.3秒
2. **全局淡出** (0.2s - 0.4s) — 所有内容同时淡出
3. **新场景淡入** (0.3s - 0.5s) — 新场景从背景淡入

### 加载界面退场（取消/失败）

1. **面板缩小退出** (0.0s - 0.2s) — 内容向中心收缩
2. **背景淡出** (0.15s - 0.3s) — 黑色背景淡出
3. **返回来源界面** — 恢复之前状态

### 进度条动画

- 进度条增长使用平滑缓动，非线性跳跃
- 每完成一个加载阶段，进度条有轻微的"脉冲"效果（0.1s的1.02x宽度缩放）
- 进度条填充颜色使用青色渐变 (#2E8B57 → #3CB371)

### 提示切换动画

- 提示面板切换时：旧提示淡出(0.15s) → 新提示淡入(0.15s)
- 切换间隔5秒

### 减少运动选项

启用时：
- Logo无落下动画，直接显示
- 进度条无脉冲效果
- 提示切换无淡入淡出，直接替换
- 退场无收缩动画，直接淡出

## 10. Data Requirements

| 数据 | 来源系统 | 读/写 | 说明 |
|------|----------|-------|------|
| 加载进度 | Resource Loader | Read | 当前加载百分比（0-100） |
| 加载阶段 | Resource Loader | Read | 当前加载阶段名称 |
| 存档信息 | Save System | Read | 存档的境界、区域信息 |
| 加载提示配置 | Loading Screen Config | Read | 5条提示文本 |
| 减少运动设置 | Accessibility System | Read | 决定是否禁用动画 |
| 游戏版本号 | Build System | Read | 显示在右下角 |

> **架构注意**: 加载界面不阻塞主线程。使用 Godot 的 `ResourceLoader.load_threaded()` 实现异步加载，进度条通过 `ResourceLoader.load_threaded_get_status()` 轮询更新。

## 11. Accessibility

### 键盘导航
- 加载期间不接受输入（自动流程）
- 错误状态下：Tab/方向键可在"重试"和"返回"间导航
- Enter确认，ESC取消/返回

### 视觉无障碍
- 进度条不仅用颜色区分，还显示百分比数值
- 状态文字提供额外的加载阶段信息
- 所有文字对比度达到 WCAG AA 级（4.5:1）

### 屏幕阅读器
- 加载开始时播报"正在加载游戏"
- 进度达到100%时播报"加载完成"
- 加载失败时播报错误信息

### 减少运动
- Logo无动画
- 进度条无脉冲
- 提示切换直接替换

## 13. Acceptance Criteria

- [ ] 游戏启动后 0.2 秒内加载界面完全可见
- [ ] 进度条从0%平滑增长到100%，无跳跃或回退
- [ ] 加载完成后进度条满格停留0.3秒再进入下一场景
- [ ] 加载期间ESC键可取消加载（非首次启动时）
- [ ] 场景切换加载时间<3秒时使用简化指示器
- [ ] 场景切换加载时间>3秒时切换为完整加载界面
- [ ] 提示内容每5秒切换一次，最多5条循环
- [ ] 加载失败时显示错误信息和"重试"/"返回"按钮
- [ ] 错误状态下焦点默认在"重试"按钮
- [ ] 所有文字对比度达到 WCAG AA 级（4.5:1）
- [ ] 进度条显示百分比数值，不仅用颜色传达进度
- [ ] 减少运动启用时所有动画禁用
- [ ] 加载界面文字支持本地化，每种语言独立提示
- [ ] 加载完成后场景切换无黑屏闪烁

## 14. Open Questions

1. **取消按钮的显示时机？** 游戏启动时是否显示取消按钮？
   - 建议：首次启动不显示（初始化不可中断），存档加载时显示

2. **加载失败的重试次数限制？** 连续失败后是否限制重试？
   - 建议：不限制重试次数，但连续3次失败后在错误信息中增加"可能是存档损坏"的提示

3. **是否需要加载背景音效/音乐？** 加载时是否播放BGM？
   - 建议：MVP阶段不需要，后续可增加环境音效（如水墨扩散的沙沙声）

4. **加载提示的内容来源？** 是否从GDD中自动提取，还是手动维护？
   - 建议：MVP阶段手动维护5条提示，后续可连接到GDD系统自动提取

5. **Steam首次下载（资源包）如何处理？** 游戏安装包下载和资源初始化可能需要较长时间
   - 建议：使用Steam内置下载进度条，安装完成后显示游戏内加载界面
