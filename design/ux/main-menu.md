## Purpose & Player Need

### 核心目的

主菜单是玩家进入九州修真界的入口，承担以下核心功能：

1. **开始新的修炼之旅** — 创建新角色，进入开场引导
2. **继续未完成的修炼** — 加载最近存档，快速回到上次进度
3. **调整修炼环境** — 访问设置（画面、音效、控制）
4. **了解制作团队** — 制作人员与版权信息
5. **结束修炼** — 退出游戏

### 玩家需求

**首次启动时**：
- 玩家期望快速开始游戏，不被过多选项困扰
- 需要通过视觉美学建立对修真世界的期待和沉浸感
- 明确的游戏入口引导，降低认知负担

**回头玩家时**：
- 快速继续上次进度是最关键的需求
- 显示"上次修炼进度"提示（境界、所在区域）增强归属感
- 设置选项易于访问，无需进入游戏即可调整

### 设计原则

- **简洁为要**：不超过 7 个主选项，避免信息过载
- **意境先行**：水墨修真风视觉语言，从第一屏建立沉浸感
- **效率优先**：回头玩家应在 2 次点击内继续游戏

## Player Context on Arrival

### 首次启动

- **时机**：游戏安装完成后首次启动
- **前序状态**：无（游戏刚启动）
- **情感状态**：好奇、期待、被美术吸引
- **期望**：快速进入游戏，不要有太长的引导或强制教程
- **背景**：玩家可能通过 Steam 商店页面了解过游戏，对修真武侠题材有基本认知

### 回头玩家

- **时机**：已有存档记录，再次启动游戏
- **前序状态**：可能在战斗、探索或修炼中途
- **情感状态**：急于回到上次进度，可能有时间压力
- **期望**：一眼看到上次进度，一键继续
- **背景**：已有角色存档数据（境界、区域、功法等）

### 无存档玩家（非首次）

- **时机**：启动游戏但无存档（新安装或存档被删除）
- **情感状态**：困惑（如果是老玩家），或正常（如果是新玩家）
- **期望**："继续游戏"选项应有明确反馈说明无存档
- **处理**："继续游戏"显示为不可用状态或点击后提示"无修炼记录"

## Navigation Position

### 层级关系

```
[游戏启动] → 主菜单 (root)
```

主菜单是导航树的**根节点**，所有其他界面均从此处进入。

### 导航架构

```
主菜单 (root)
├── 开始新游戏 → 开场引导/角色创建
├── 继续游戏 → 直接加载存档 → 游戏场景
├── 设置 → 设置子菜单 (见 settings.md)
│   ├── 画面设置
│   ├── 音效设置
│   └── 控制设置
├── 制作人员 → 制作人员滚动字幕
└── 退出游戏 → 退出确认 → 返回桌面
```

### 定位说明

- **层级深度**: 一级主菜单 + 设置子菜单（最多两级）
- **返回方式**: 所有子菜单均可通过 ESC/返回键回到主菜单
- **替代入口**: 游戏内可通过 ESC 暂停菜单返回主菜单（见 pause-menu.md）

## Entry & Exit Points

### 入口点

| 入口来源 | 触发条件 | 到达状态 |
|----------|----------|----------|
| 游戏启动 | 启动游戏可执行文件 | 主菜单默认状态 |
| 游戏内返回 | 从暂停菜单选择"返回主菜单" | 弹出确认对话框"是否保存当前进度并返回主菜单？"→ 确认后自动存档 → 主菜单默认状态 |
| 通关后返回 | 完成结局后返回 | 主菜单，显示通关标记 |

### 出口点

| 出口去向 | 触发条件 | 状态变化 |
|----------|----------|----------|
| 开场引导 | 选择"开始新游戏" | 进入游戏场景，新角色创建 |
| 游戏场景 | 选择"继续游戏" | 加载存档，进入游戏场景 |
| 设置子菜单 | 选择"设置" | 进入设置界面 |
| 制作人员 | 选择"制作人员" | 进入滚动字幕，可跳过 |
| 退出游戏 | 选择"退出游戏" → 确认 | 关闭游戏，返回桌面 |
| 暂停菜单 | 游戏内按ESC → "返回主菜单" | 退出到主菜单 |

## Layout Specification

### Layout Type

| 属性 | 值 | 说明 |
|------|-----|------|
| 布局类型 | 全屏布局 | 主菜单为全屏场景，不适用面板宽度标准 |
| Z-index (根场景) | 0 | 全屏场景层级 |
| Z-index (UI按钮层) | 100 | 与HUD一致 |
| Z-index (设置遮罩) | 150 | 打开设置子菜单时覆盖主菜单 |
| 半模态 | 15% 变暗遮罩 | 设置子菜单打开时主菜单按钮层变暗，输入被遮罩拦截 |
| 焦点样式 | 金色边框 #FFD700 + 1px 内发光 | 遵循 interaction-patterns.md |

### Information Hierarchy

| 优先级 | 信息 | 说明 |
|--------|------|------|
| P0 - 最高 | 游戏 Logo / 标题 | 建立品牌和沉浸感，水墨修真风视觉 |
| P0 - 最高 | 主菜单选项 | 核心交互入口，5个按钮 |
| P1 - 高 | 上次修炼进度 | 快速引导回头玩家（境界 + 区域） |
| P2 - 中 | 背景氛围元素 | 动态水墨粒子，增强修真世界沉浸感 |
| P3 - 低 | 版本号 / 版权信息 | 辅助信息，底部小字 |

### Layout Zones

```
+-------------------------------------------+
|           Zone A: Logo 区域                |
|    游戏标题 + 水墨意境背景                  |
+-------------------------------------------+
|           Zone B: 菜单选项区域             |
|    5个核心按钮（垂直排列，左侧居中）         |
+-------------------------------------------+
|           Zone C: 辅助信息区域             |
|    版本号 + 版权 + 上次进度提示             |
+-------------------------------------------+
```

**Zone A - Logo 区域** (顶部，约占屏幕 30%)
- 游戏主标题："武侠奇遇录"
- 副标题（可选）："Cultivation Wuxia RPG"
- Logo 采用书法风格字体，水墨质感

**Zone B - 菜单选项区域** (中左部，约占屏幕 30%)
- 垂直排列的 5 个主菜单按钮
- 左侧居中对齐，与 Logo 形成视觉平衡
- 按钮间距一致，鼠标悬停有反馈

**Zone C - 辅助信息区域** (底部，约占屏幕 10%)
- 左下角：版本号 (vX.X.X)
- 右下角：版权信息
- 居中（可选）：上次修炼进度提示

**Zone D - 背景区域** (全屏，剩余空间)
- 水墨修真风背景，填充Zone A/B/C之外的空间
- 动态粒子效果（可选，跟随减少运动设置）

## States & Variants

| 状态 / 变体 | 触发条件 | 变化说明 |
|-------------|----------|----------|
| **默认状态** | 游戏启动 | 完整主菜单，所有按钮可用 |
| **无存档状态** | 首次启动或无存档 | "继续修炼"按钮置灰但仍可点击，点击后提示"无修炼记录，请开始新的修炼之旅"，Zone C 无修炼进度提示 |
| **有存档状态** | 存在存档记录 | "继续修炼"按钮高亮，Zone C 显示"上次：境界·区域" |
| **按钮聚焦** | 鼠标悬停或键盘/手柄导航 | 按钮背景变色/边框高亮，有音效反馈 |
| **按钮按下** | 鼠标点击或确认键按下 | 短暂缩放动画（0.1s），触发对应功能 |
| **退出确认** | 点击"退出修炼" | 弹出确认对话框，可选"确认退出"或"取消" |
| **设置子菜单** | 点击"修炼设置" | 设置面板居中缩放进入（80% → 100%），主菜单15%变暗遮罩 |
| **制作人员** | 点击"制作人员" | 全屏覆盖，背景纯黑，滚动字幕从底部淡入，可跳过（按任意键或ESC） |
| **加载状态** | 点击"继续修炼"后 | 显示加载动画（水墨旋转或进度条），背景渐暗 |
| **错误状态** | 加载失败或存档损坏 | 提示"修炼记录损坏，无法继续"，提供"新游戏"或"返回"选项 |

**退出确认对话框**:
```
┌──────────────────────────────────────┐
│         确认退出修炼？                 │
│                                      │
│    [ 确认退出 ]    [ 取消 ]          │
└──────────────────────────────────────┘
```

**错误状态对话框**:
```
┌──────────────────────────────────────┐
│         修炼记录损坏                    │
│   无法加载存档，请开始新的修炼之旅      │
│                                      │
│    [ 开始新修炼 ]    [ 返回 ]        │
└──────────────────────────────────────┘
```

**返回主菜单确认对话框**:
```
┌──────────────────────────────────────┐
│     确认保存当前进度并返回主菜单？      │
```

- 对话框默认焦点在"保存并返回"按钮

| ESC键 | 返回/关闭 | 键盘ESC | 无 | 关闭当前弹出对话框或子菜单，返回主菜单 |

| 设置子菜单 | 返回 | ESC / 返回按钮 | 滑动退出动画 | 关闭设置面板，返回主菜单 |

### 导航顺序

按钮焦点循环顺序（从上到下）：

**有存档时**:
```
1. 开始新修炼
2. 继续修炼 ← 默认焦点
3. 修炼设置
4. 制作人员
5. 退出修炼
```

**无存档时**:
```
1. 开始新修炼 ← 默认焦点
2. 继续修炼（置灰可点击）
3. 修炼设置
4. 制作人员
5. 退出修炼
```

到达底部后再按 ↓ 回到顶部，形成循环导航。

## Transitions & Animations

### 主菜单入场动画

游戏启动后，主菜单按以下时序淡入：

1. **背景渐变** (0.0s - 1.0s) — 黑屏淡入到水墨背景，1秒缓动
2. **Logo 显现** (0.3s - 0.8s) — 游戏标题从上方缓缓落下，带轻微水墨扩散效果
3. **按钮组入场** (0.8s - 1.2s) — 按钮从左侧滑入，依次出现（间隔0.08s）
4. **底部信息** (1.2s - 1.4s) — 版本号和存档信息淡入

### 按钮交互动画

| 状态 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 鼠标悬停 | 背景色变化 + 微缩放(1.02x) | 0.15s | ease-out |
| 鼠标离开 | 恢复默认 | 0.15s | ease-out |
| 点击按下 | 缩放(0.98x) + 颜色加深 | 0.1s | ease-in |
| 点击释放 | 恢复悬停状态 | 0.15s | ease-out |
| 焦点移动 | 焦点指示器移动 | 0.15s | ease-out |

### 子菜单过渡

| 过渡类型 | 动画 | 时长 |
|----------|------|------|
| 设置面板打开 | 从右侧滑入，背景遮罩淡入 | 0.3s ease-out |
| 设置面板关闭 | 向右滑出，遮罩淡出 | 0.2s ease-in |
| 退出确认 | 居中弹出，背景遮罩 | 0.2s ease-out |
| 制作人员 | 从底部向上淡入滚动 | 0.5s ease-out |

### 减少运动选项

对于容易晕动症的玩家，所有动画应可通过设置关闭：
- 禁用入场动画：直接显示主菜单
- 禁用按钮缩放：仅保留颜色变化
- 禁用滑入效果：直接切换显示

> **注意**: 减少运动选项在设置子菜单中配置，详见 settings.md

## Accessibility

### 键盘导航

- 所有菜单按钮必须可通过 Tab 键和方向键（↑↓）访问
- 焦点指示器必须清晰可见（高对比度边框或颜色变化）
- Enter/Space 键确认选择，ESC 键返回/关闭

### 手柄导航

- 手柄方向键/摇杆可控制焦点移动
- 肩键（L1/R1）支持快速导航：L1=上一项，R1=下一项
- A 按钮（或 X）确认选择
- B 按钮（或 O）返回
- 焦点循环导航支持（到底部后继续到顶部）

### 视觉无障碍

- 所有文字对比度至少达到 WCAG AA 级（4.5:1）
- 按钮文字字号不低于 18pt（1080p 基准）
- 不依赖颜色传达信息（如禁用状态同时使用灰度 + 图标）
- Logo 使用图片+文字备选方案（图片加载失败时显示文字）

### 减少运动

- 设置中提供"减少运动"选项
- 启用时禁用所有入场动画和按钮缩放效果
- 切换改为淡入淡出

### 屏幕阅读器

- 所有按钮必须有可读的 Accessible Name
- 焦点变化时触发屏幕阅读器播报
- 存档信息（"上次：境界·区域"）应作为独立可访问元素

## Localization Considerations

### 文本本地化

| 文本元素 | 原文（中文） | 翻译考虑 | 最大字符数 |
|----------|-------------|----------|------------|
| 游戏标题 | 武侠奇遇录 | 不同语言长度差异大，建议用 Logo 图片 | Logo 替换 |
| 开始新修炼 | 开始新修炼 | 英语约 15 字符，德语更长 | 12 字符 |
| 继续修炼 | 继续修炼 | 同上 | 12 字符 |
| 修炼设置 | 修炼设置 | 同上 | 12 字符 |
| 制作人员 | 制作人员 | 同上 | 10 字符 |
| 退出修炼 | 退出修炼 | 同上 | 12 字符 |
| 确认退出修炼？ | 确认退出修炼？ | 确认对话框文本，翻译可能更长 | 20 字符 |
| 修炼记录损坏 | 修炼记录损坏 | 错误提示文本 | 25 字符 |
| 上次：境界·区域 | 上次：金丹初期·中原腹地 | 动态拼接，注意语言格式 | 30 字符 |

### 布局影响

- 按钮宽度应支持英文文本 40% 扩展（从中文基准计算）
- 游戏标题优先使用图片方案，避免不同语言下布局溢出
- 确认对话框文本使用自适应宽度，最大不超过屏幕宽度的 60%

### 字体支持

- 中文：优先使用内置字体或自定义字体（支持简体/繁体中文）
- 英文：标准系统字体
- 日韩文字：确保字符覆盖完整

## Acceptance Criteria

- [ ] 主菜单在游戏启动后 2 秒内完全可见（入场动画结束后）
- [ ] 有存档时，"继续修炼"按钮可用，点击后正确加载存档进入游戏
- [ ] 无存档时，"继续修炼"按钮置灰不可用，点击提示"无修炼记录"
- [ ] 所有 5 个主菜单按钮可通过键盘 ↑↓ 键循环导航
- [ ] 所有 5 个主菜单按钮可通过手柄方向键循环导航
- [ ] 鼠标悬停任一按钮时，有明确的视觉反馈（颜色变化或高亮）
- [ ] 点击"退出修炼"弹出确认对话框，取消后返回主菜单
- [ ] ESC 键可关闭设置子菜单和确认对话框，返回主菜单
- [ ] Zone C 正确显示上次存档的角色境界和区域信息
- [ ] 所有文字对比度达到 WCAG AA 级（4.5:1 最小值）
- [ ] 按钮文本在英文翻译后不溢出（支持 40% 文本扩展）
- [ ] 主菜单背景为水墨修真风视觉，与游戏美术风格一致

## Open Questions

1. **是否需要多存档位选择？** 当前设计只支持"最近存档"快速加载。是否需要存档槽位选择界面？
   - 建议：MVP 阶段仅最近存档，后续更新增加存档槽位

2. **主菜单背景音乐？** 是否需要循环播放的主题曲？
   - 建议：需要，使用修真风格轻音乐，设置中可调节音量

3. **是否需要"新游戏+"选项？** 通关后是否显示二周目入口？
   - 建议：MVP 阶段不需要，通关后统一显示"通关"标记

4. **背景是静态图片还是动态场景？** 水墨粒子动态背景还是静态图片？
   - 建议：MVP 使用静态图片+轻微粒子效果，后续可增加动态元素
