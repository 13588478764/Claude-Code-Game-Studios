# UX Spec: 奇遇UI面板 (Encounter UI Panel)

> **Status**: Approved (UX Review Complete — 2026-05-08)
> **Author**: 用户 + ux-designer
> **Last Updated**: 2026-05-08
> **Journey Phase(s)**: 大地图探索、战斗胜利后、休息/存档时
> **Template**: UX Spec

## Purpose & Player Need

奇遇UI面板是玩家与奇遇系统交互的唯一界面载体，承担以下核心目标：

1. **展示奇遇事件**：以类型差异化卡片形式清晰显示奇遇名称、描述文本、类型标识和福缘状态
2. **玩家决策**：提供交互选项按钮（接受/拒绝/开启/阅读等），让玩家做出有意义的选择
3. **奖励预览与确认**：直观展示奖励物品、数量、类型颜色标签，帮助玩家理解收益
4. **秘境挑战入口**：显示敌人信息、等级属性，提供"进入战斗"和"放弃挑战"选项

**如果这个面板不存在或难用**：玩家无法了解奇遇内容、无法做出选择、奖励发放不透明，奇遇系统的"惊喜感"和"正向反馈"将完全失效。

**玩家来到这个面板的目的是**："我触发了什么奇遇？它给我什么？我需要做什么选择？"

## Player Context on Arrival

### 到达时机与场景

玩家可能在以下三种场景中突然遭遇奇遇面板：

| 触发场景 | 基础概率 | 玩家当前状态 | 情绪预期 |
|---------|---------|-------------|---------|
| 大地图移动中 | 5%（福缘修正后最高7.5%） | 正在探索世界 | 好奇、期待 |
| 战斗胜利后 | 2% | 刚经历战斗，可能情绪高涨 | 惊喜、成就感 |
| 休息/存档时 | 3% | 处于平静状态 | 意外、温暖 |

### 到达方式

奇遇面板是**系统主动推送到玩家面前**的模态覆盖层，不是玩家通过导航菜单主动进入的。这意味着：

- 玩家无法预判何时会出现
- 到达时当前游戏流程被**暂停**（秘境挑战除外，见下方）
- 面板是唯一的交互焦点，玩家必须处理完奇遇才能继续

### 暂停粒度定义

奇遇面板显示期间，以下系统暂停/恢复：

**暂停（游戏逻辑冻结）**:
- 敌人AI（所有NPC行为停止）
- 玩家移动/交互（大地图/探索场景）
- 游戏计时器（倒计时、Buff持续时间等）
- 敌人攻击/移动动画

**不暂停（保持运行）**:
- 音效/BGM（奇遇面板有独立音效）
- UI动画（奇遇面板自身的入场/退场动画）
- 粒子效果（奇遇面板专属特效，除非减少运动启用）
- 存档系统后台操作（如休息/存档触发奇遇时）

**不同触发场景的暂停时机**:
| 触发场景 | 暂停时机 | 恢复时机 |
|---------|---------|---------|
| 大地图移动中 | 奇遇触发瞬间立即暂停 | 奇遇面板关闭后恢复 |
| 战斗胜利后 | 战斗结算时已暂停，奇遇面板追加覆盖 | 奇遇面板关闭后继续结算流程 |
| 休息/存档时 | 休息/存档操作已暂停，奇遇面板追加覆盖 | 奇遇面板关闭后继续休息/存档流程 |

### 情绪状态

**目标情绪**：惊喜、好奇、期待。玩家应该感受到"被命运眷顾"的武侠幻想——"我遇到了什么？是高人？还是宝物？"

**5种类型的情绪差异化**：
- **江湖传闻**：轻松、八卦感（淡雅水墨）
- **天材地宝**：兴奋、收获感（金色光效）
- **高人指点**：敬畏、成长期待（古朴卷轴）
- **失传秘籍**：神秘、探索欲（残破古籍）
- **秘境挑战**：紧张、战斗准备（红色警示）

### 关键交付时刻

1. **类型揭示瞬间**：面板打开的前0.5秒，玩家通过视觉风格识别奇遇类型
2. **选择按钮出现时**：玩家理解"我能做什么"
3. **奖励预览滚动时**：玩家看到具体收益，产生满足感
4. **确认关闭时**：奖励发放，面板优雅退场

## Navigation Position

奇遇面板是**系统推送的模态覆盖层**，不属于游戏的主菜单导航层级。

### 导航层级关系

```
Main Game (root)
├── 大地图场景 (World Map)
├── 战斗场景 (Battle)
├── 休息/存档场景 (Rest/Save)
│
└── CanvasLayer: Encounter Overlay [Z-index: 最高层]
    └── 奇遇事件卡片 (EncounterPopup) ← 模态，阻断下层交互
```

### 层级规则

- **Z-index**: 奇遇覆盖层=300（遵循跨面板标准），奇遇面板内的确认子对话框=400（覆盖奇遇面板），HUD=100，设置面板=200
- **奇遇模态期间屏蔽**: 奇遇面板显示期间，HUD快捷入口（设置按钮等）被禁用，其他面板无法打开
- **实例模式**: 单例预加载（游戏启动时实例化，触发时更新内容）
- **对象池**: 使用预实例化单例，避免运行时动态创建延迟
- **阻断性**: 面板存在期间，下层游戏逻辑暂停，玩家无法操作其他UI
- **堆叠限制**: 同一时间仅显示一个奇遇面板，不支持多个奇遇同时触发

### 备选入口路径

| 路径 | 触发方式 | 玩家携带的上下文 |
|------|---------|-----------------|
| 大地图移动 → 奇遇 | 系统概率判定 | 当前所在区域、移动方向 |
| 战斗胜利 → 奇遇 | 战斗结束事件回调 | 战斗结果、敌人类型 |
| 休息/存档 → 奇遇 | 休息操作完成时 | 休息地点、存档状态 |

## Entry & Exit Points

### Entry Points

| 入口来源 | 触发器 | 玩家携带的上下文 |
|---------|--------|-----------------|
| 大地图移动 | 系统概率判定成功（5%基础概率×福缘修正） | 当前区域名称、移动节点 |
| 战斗胜利 | BattleManager战斗结束事件回调（2%基础概率） | 战斗结果、敌人等级 |
| 休息/存档 | 休息操作完成时（3%基础概率） | 休息地点、存档点名称 |

### Exit Points

| 出口目标 | 触发器 | 不可逆状态变化 |
|---------|--------|---------------|
| 原场景（大地图/战斗结算/存档） | 奇遇处理完成 | 奖励已发放、奇遇已标记完成 |
| 战斗场景（秘境挑战） | 玩家点击"进入战斗" | 战斗即将开始 |
| 原场景 | 玩家点击"放弃挑战" | 转换为替代奖励（天材地宝） |

### 类型差异化出口行为

| 奇遇类型 | 关闭行为 | 后续流程 |
|---------|---------|---------|
| 江湖传闻 | 自动关闭（无选择，纯文本展示） | 返回原场景 |
| 天材地宝 | 玩家点击"开启"确认后关闭 | 奖励发放 → 返回原场景 |
| 高人指点 | 玩家选择"接受"/"拒绝"后关闭 | 选择"接受"则发放属性点/天赋点 |
| 失传秘籍 | 玩家点击"阅读"后关闭 | 武学入库或转换为熟练度 |
| 秘境挑战 | 进入战斗 或 放弃挑战 | "进入战斗"→加载战斗场景；"放弃"→转换为天材地宝奖励 |

## Layout Specification

### Panel Dimensions

| 属性 | 值 | 说明 |
|------|-----|------|
| 通用类型宽度 | 40% 屏幕宽度 | 最小 560px，最大 720px；175% 缩放时 1260px |
| 秘境挑战宽度 | 50% 屏幕宽度 | 因双栏布局需要更多空间，最大 900px |
| 高度 | 自适应内容 | 最大 80% 屏幕高度，超出可滚动 |
| 对齐 | 居中 | 水平垂直居中 |
| 焦点样式 | 金色边框 #FFD700 + 2px 内发光 | 遵循 interaction-patterns.md |

### Information Hierarchy

奇遇面板必须展示的所有信息，按优先级排列：

| 优先级 | 信息项 | 用途 | 是否始终可见 |
|-------|--------|------|-------------|
| 1 | 奇遇类型标识（图标+颜色） | 第一眼识别"这是什么奇遇" | ✅ 始终 |
| 2 | 奇遇标题 | 事件名称，书法字体 | ✅ 始终 |
| 3 | 奇遇描述文本 | 事件内容、情境描述 | ✅ 始终 |
| 4 | 交互选项按钮 | 玩家知道"我能做什么" | ✅ 始终 |
| 5 | 奖励预览（图标网格+数量+类型颜色标签） | 玩家看到"我能得到什么" | ✅ 始终 |
| 6 | 福缘状态图标 | 高福缘显示"吉星高照" | 条件性（福缘≥60） |
| 7 | 敌人等级属性面板 | 秘境挑战专属信息 | 仅秘境挑战 |
| 8 | 玩家当前状态 | 秘境挑战专属信息 | 仅秘境挑战 |

### Layout Zones

奇遇面板采用**居中模态卡片**布局，覆盖于当前游戏场景之上。面板本身分为以下区域：

#### 通用奇遇卡片布局（江湖传闻、天材地宝、高人指点、失传秘籍）

```
┌─────────────────────────────────────────────────────────┐
│  A. Header 区域                                           │
│  [类型图标] 奇遇标题                          [福缘图标]   │
├─────────────────────────────────────────────────────────┤
│  B. 内容区域                                              │
│                                                         │
│  奇遇描述文本（多行，支持滚动）                             │
│                                                         │
│  ┌──────────── 奖励预览区域 ────────────┐                │
│  │  [物品] [物品] [物品] [物品]          │                │
│  │  数量标签  类型颜色标签               │                │
│  └──────────────────────────────────────┘                │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  C. Action 区域                                           │
│                                                         │
│  [选项按钮1]  [选项按钮2]                                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### 秘境挑战卡片布局（特殊）

```
┌─────────────────────────────────────────────────────────┐
│  A. Header 区域                                           │
│  [秘境类型图标] 秘境名称                      [福缘图标]   │
├──────────────────┬──────────────────────────────────────┤
│  D. 敌人信息区域  │  B. 内容区域                          │
│                  │                                       │
│  [敌人3D预览]    │  秘境描述文本                           │
│                  │                                       │
│  等级: Lv.XX     │  ┌──────── 奖励预览 ─────────┐        │
│  属性列表...     │  │  [紫色装备] [EXP] [碎片]   │        │

├──────────────────┴──────────────────────────────────────┤
│  C. Action 区域                                           │
│                                                         │
│  玩家状态: Lv.XX  HP/MP          [进入战斗]  [放弃挑战]    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### 区域定义

| 区域 | 内容 | 背景 |
|------|------|------|
| **A. Header** | 类型图标（左上）、奇遇标题、福缘状态图标（右上） | 根据奇遇类型动态切换 |
| **B. 内容** | 奇遇描述文本、奖励预览网格 | 半透明深色蒙版 |
| **C. Action** | 交互选项按钮（居中排列） | 透明，按钮自带样式 |
| **D. 敌人信息**（秘境专属） | 敌人3D预览、等级属性面板 | 深色半透明，红色边框 |

## States & Variants

| 状态/变体 | 触发条件 | 什么变化 |
|-----------|---------|---------|
| **默认** | 奇遇正常触发 | 完整显示：Header + 内容 + Action区域，动态背景对应奇遇类型 |
| **首次奇遇** | 玩家创建角色后第一次触发奇遇（全局永久仅一次） | 奖励预览区域下方显示简短引导文本："这是你旅途中的第一次奇遇，选择吧！"，5秒后淡出或玩家点击任意按钮后淡出 |
| **自动关闭（江湖传闻）** | 江湖传闻类型触发 | 无交互按钮，描述文本显示后停留2秒，自动执行关闭动画并返回原场景 |
| **奖励确认（天材地宝/高人指点/失传秘籍）** | 三种高价值奇遇触发 | 奖励预览区域高亮（金色边框呼吸动画），主按钮为"开启"/"接受"/"阅读"，次按钮为"放弃"（灰色） |
| **秘境挑战** | 秘境类型触发 | 布局切换为秘境专属双栏布局，显示敌人3D预览、等级属性面板、玩家状态，按钮为"进入战斗"（红色）和"放弃挑战"（灰色） |
| **高福缘增强** | 玩家福缘≥60 | Header区域右上角显示"吉星高照"金色图标，奇遇标题下方显示"福缘加持：奖励品质提升"提示文本 |
| **加载失败降级** | 奇遇背景图加载失败 | 使用默认水墨山水背景（res://assets/encounters/backgrounds/default.tres），视觉降级但功能完整 |
| **战斗加载中** | 秘境挑战选择"进入战斗" | 显示过渡动画（水墨晕染效果，1.5秒），掩盖后台战斗场景加载，加载完成后直接切入战斗 |
| **放弃挑战转换** | 秘境挑战选择"放弃挑战" | 面板内容转换为天材地宝奖励预览，按钮变为"领取"，确认后返回原场景 |
| **背包满状态** | 玩家背包已满时触发奖励 | 弹出确认对话框"背包已满，不可堆叠物品将转换为银两/经验值"，显示转换前后对比列表；确认后发放转换后奖励 |
| **文本溢出** | 奇遇描述文本超过面板高度 | 描述文本区域启用滚动（Godot ScrollContainer），确保完整内容可浏览 |
| **UI缩放175%** | 玩家设置UI缩放到最大 | 面板宽度从默认的720px扩大到1260px（720×1.75），所有组件等比例放大，内容区域使用ScrollContainer处理溢出 |
| **数据错误（EncounterManager返回null）** | EncounterManager 无法提供奇遇数据 | 面板显示"仙缘异常"错误提示，按钮为"继续旅途"，点击后关闭面板，游戏不暂停 |
| **奇遇面板打断** | 奇遇面板显示期间发生游戏事件 | 面板为模态且不可打断，所有游戏事件延迟或排队处理（详见下方打断规则表） |
| **奖励物品缺失（ItemDatabase查询失败）** | 奖励物品ID在数据库中不存在 | 该物品位置显示"??"占位图标，数量标签显示"未知"，不阻断面板显示 |
| **奇遇JSON配置损坏** | 奇遇配置文件解析失败 | EncounterManager 跳过损坏条目，面板不触发。如正在运行中遇到此问题，面板自动关闭并记录错误日志 |

### 奇遇面板打断规则

奇遇面板显示期间，面板为**模态且不可打断**。具体规则如下：

| 事件 | 是否打断奇遇面板 | 处理方式 |
|------|-----------------|---------|
| 敌人攻击/移动 | ❌ 不打断 | 游戏逻辑已暂停，敌人行为冻结 |
| 玩家受到伤害 | ❌ 不打断 | 伤害计算延迟至奇遇面板关闭后 |
| 玩家死亡 | ❌ 不打断 | 死亡判定延迟至奇遇面板关闭后；若玩家在奇遇面板中选择"进入战斗"后死亡，按正常战斗死亡流程处理 |
| 时间流逝/Buff到期 | ❌ 不打断 | 游戏计时器暂停，Buff持续时间冻结 |
| 新奇遇触发 | ❌ 不打断 | 新奇遇进入队列，当前奇遇关闭后判定是否触发 |
| 系统通知/成就解锁 | ✅ 可共存 | 通过HUD右上角Toast通知，不阻断奇遇面板 |
| 玩家主动打开设置面板 | ❌ 不允许 | 奇遇面板期间HUD快捷入口被禁用 |

**设计原则**: 奇遇面板是"命运时刻"，必须保证完整性和沉浸感。任何可能破坏体验的中断都被延迟或排队处理。

## Data Requirements

| 数据 | 来源系统 | 读/写 | 备注 |
|------|---------|-------|------|
| 奇遇事件数据 | EncounterManager | Read | encounter_id, encounter_type, title, description, choices, rewards |
| 奇遇类型配置 | EncounterConfig (JSON) | Read | 类型权重、背景图路径、触发概率 |
| 奖励物品数据 | ItemDatabase | Read | 物品ID、名称、图标、数量、类型颜色 |
| 玩家福缘值 | CharacterStats | Read | 用于判断是否显示"吉星高照"图标 |
| 玩家背包状态 | InventorySystem | Read | 用于判断背包是否已满，决定是否转换奖励 |
| 玩家等级/属性 | CharacterStats | Read | 秘境挑战时显示玩家状态 |
| 敌人模板数据 | EnemyDatabase | Read | 秘境挑战时显示敌人等级和属性 |
| 奇遇完成状态 | EncounterRecordManager | Read/Write | 标记奇遇已完成，写入存档 |
| 连续失败计数器 | EncounterManager | Read/Write | 用于保底机制 |
| 减少运动设置 | SettingsSystem | Read | 决定是否禁用动画和特效 |
| UI缩放设置 | SettingsSystem | Read | 决定是否放大面板尺寸 |

**实时数据**：
- 奇遇事件数据：EncounterManager 触发 `encounter_triggered(encounter_data)` 信号，EncounterPanel 监听信号并填充面板字段
- 背包状态：触发时查询一次，不持续监听
- 玩家/敌人属性：触发时查询一次，面板存在期间不变

**数据流机制**:
```
EncounterManager.detects_encounter()
  → 查询 EncounterConfig 获取奇遇数据
  → 查询 ItemDatabase 获取奖励物品
  → emit_signal("encounter_triggered", encounter_data)
  → EncounterPanel.populate(encounter_data)
  → 面板播放入场动画，显示UI
``

**数据写入**：
- 奇遇完成后，通过 `encounter_completed` 事件通知 EncounterManager 标记奇遇为已完成
- 存档系统负责将奇遇状态写入存档文件

## Accessibility

### 键盘导航

- **焦点顺序**: Header区域（不聚焦）→ 描述文本（只读，可滚动）→ 奖励物品图标（逐个聚焦）→ 主按钮 → 次按钮
- **奖励网格内**: Left/Right 在同一行移动焦点，Up/Down 跨行移动焦点
- **Tab键**在奖励网格和按钮之间切换，最后一个奖励物品的Right焦点跳转到主按钮
- **Enter/Space** 确认当前焦点按钮操作
- 所有交互元素在获得焦点时显示 **2px金色边框** 高亮
- 奖励物品图标悬停时，Tooltip通过键盘可达（聚焦时自动显示，失焦时自动隐藏）

**奖励网格滚动焦点行为**（奖励>4个物品时）:

| 操作 | 焦点状态 | 滚动行为 |
|------|---------|---------|
| 焦点移动到可视区域最后一个物品 | 该物品聚焦 | 滚动区域自动滚动使下一个物品可见 |
| Down/Right 焦点超出可视区域 | 下一个物品聚焦 | ScrollContainer 自动滚动一行/一列 |
| Up/Left 焦点移回上方隐藏区域 | 上一个物品聚焦 | ScrollContainer 自动滚动回上方 |
| 焦点从最后一个奖励物品移出 | 主按钮聚焦 | 滚动区域失焦，滚动位置保持 |

- 如果奖励超过4个物品，网格区域启用内部滚动，焦点按顺序遍历所有物品
- 滚动区域内焦点遍历时，确保聚焦元素始终在可视区域内（Godot ScrollContainer `ensure_control_visible`）

## Localization Considerations

### 文本扩展风险

| 元素 | 当前最大长度(中) | 英文翻译预估长度 | 40%扩展影响 | 优先级 |
|------|-----------------|----------------|------------|--------|
| 奇遇标题 | ~12字 | ~25字符 | 可能超出行宽，需要多行布局 | HIGH |
| 描述文本 | ~150字/段 | ~300字符 | ScrollContainer处理，不破坏布局 | LOW |
| 按钮文本 | ~4字（"开启"/"接受"） | ~12字符（"Open"/"Accept"） | 按钮需要加宽 | MEDIUM |
| 福缘图标文字 | "吉星高照" | "Blessed by Fortune" | 图标下方需要额外行 | HIGH |

### 布局适配策略

- **奇遇标题区域**: 使用 `autowrap_mode = WORD_BOUNDARY`，支持多行自动换行
- **按钮文本**: 按钮最小宽度设置为120px，确保英文翻译不截断
- **福缘图标**: "吉星高照"替换为英文时使用两行布局（"Blessed by" / "Fortune"）

### 字体支持

- 中文字体：思源宋体 / 方正清刻本悦宋（主UI），确保CJK字符集完整
- 英文字体：Lora / Georgia（备用），与中文字体视觉风格一致
- Godot 4.6支持多字体Fallback机制，优先加载中文字体，缺失字符回退到英文字体

### 数字和货币

- 银两数量、经验值等数值显示使用Godot内置数字格式化，支持千位分隔符
- 不同语言的数字格式差异由Godot自动处理（如欧洲小数逗号）
- 日期/时间不在此面板显示，无需特殊处理

### 本地化流程

- 所有奇遇文本存储在 `data/encounters/` JSON文件中，支持多语言键
- JSON结构：`{"title": {"zh": "xxx", "en": "xxx"}, "description": {"zh": "xxx", "en": "xxx"}}`
- 新增奇遇内容时，同步创建多语言条目
