## 输入设备支持

| 设备 | 主输入 | 支持级别 |
|------|--------|---------|
| 键盘/鼠标 | 主 | 完整支持 |
| 手柄 | 次 | 部分支持 |
| 触屏 | 不支持 | — |

**手柄部分支持说明**：
- 所有 HUD 功能都可以通过手柄操作访问
- 某些操作（如拖拽、精确点击、悬停）在手柄上体验不如键鼠
- 系统为所有受限功能提供了手柄友好的替代操作方式

## 交互模式

### 1. 导航 (Navigation)

**描述**: 在菜单和 UI 元素之间移动焦点

| 设备 | 操作 | 焦点行为 |
|------|------|---------|
| 键盘 | Tab / WASD / 方向键 | 焦点在可交互元素间循环 |
| 鼠标 | 悬停 + 点击 | 悬停高亮，点击确认 |
| 手柄 | D-Pad / 左摇杆 + A | 焦点在可交互元素间循环 |

**焦点样式**:
- 键盘/手柄焦点：金色 (#FFD700) 边框 + 1px 内发光
- 鼠标焦点：悬停时背景色变化（+10% 亮度）
- 双焦点同时存在时，分别显示不同的焦点指示器（Godot 4.6 双焦点系统）

---

### 2. 选择 (Selection)

**描述**: 从选项列表中做出选择

| 设备 | 操作 | 确认 | 取消 |
|------|------|------|------|
| 键盘 | 方向键 + Enter | Enter / 空格 | Esc / Backspace |
| 鼠标 | 点击 | 左键点击 | 右键 / Esc |
| 手柄 | D-Pad / 摇杆 + A | A 按钮 | B 按钮 |

**视觉反馈**:
- 悬停时：元素放大 5% + 边框高亮
- 选中时：短暂动画（0.15s 缩放）+ 确认音效
- 不可选时：透明度降至 50%，不可交互

---

### 3. 确认对话框 (Confirmation Dialog)

**描述**: 需要玩家确认的关键操作（退出战斗、删除存档等）

```
┌────────────────────────────────┐
│  [图标] 确认操作？              │
│                                │
│  简要说明操作后果               │
│                                │
│  [ 确认 ]          [ 取消 ]    │
│                                │
│  □ 不再显示此提示               │
└────────────────────────────────┘
```

**交互规则**:
- 默认焦点在"确认"按钮上
- 支持键盘 Enter 确认，Esc 取消
- 手柄 A 确认，B 取消
- "不再显示"勾选状态持久化到配置文件

---

### 4. 滚动列表 (Scrollable List)

**描述**: 装备栏、技能列表、任务日志等可滚动内容

| 设备 | 操作 | 行为 |
|------|------|------|
| 键盘 | 方向键 + PageUp/PageDown | 逐项/逐页滚动 |
| 鼠标 | 滚轮 + 拖动滚动条 | 平滑滚动 |
| 手柄 | D-Pad / 摇杆 + 肩键 | 逐项/逐页滚动 |

**技术要求**:
- 使用 Godot ScrollContainer + Control 节点
- 虚拟滚动（大量数据时）
- 滚动到边缘时有视觉/触觉反馈

---

### 5. 拖拽 (Drag & Drop)

**描述**: 装备槽位、物品栏拖拽

| 设备 | 操作 | 行为 |
|------|------|------|
| 鼠标 | 按住左键拖拽 + 释放 | 拖拽时显示物品缩略图 |
| 手柄 | 选中后移动到目标槽位 + A | 选择模式，移动到目标后确认 |
| 键盘 | 不支持拖拽，使用"装备/卸下"按钮 | 替代方案 |

**无障碍考虑**:
- 键盘不支持拖拽，提供替代操作（Enter 装备/卸下）
- 拖拽区域有高亮边框，放置目标清晰可见

---

### 6. 文本输入 (Text Input)

**描述**: 角色命名、存档命名等

| 设备 | 操作 |
|------|------|
| 键盘 | 直接键入 |
| 鼠标 | 点击输入框后键入 |
| 手柄 | 虚拟键盘弹出 |

**技术要求**:
- 使用 Godot LineEdit 或 TextEdit
- 手柄虚拟键盘使用网格导航
- 最大字符数限制明确提示

---

### 7. 战斗快捷操作 (Combat Quick Actions)

**描述**: 战斗中快速选择武学、使用物品

**布局**:
```
    [武学1] [武学2] [武学3] [武学4]
    [武学5] [武学6] [物品] [防御]
```

| 设备 | 操作 |
|------|------|
| 键盘 | 数字键 1-8 或 WASD + Enter 选择 |
| 手柄 | 十字键/摇杆选择 + A 确认 |
| 鼠标 | 点击对应按钮 |

**反馈**:
- 选中武学显示详细信息（消耗、效果、冷却）
- 不可用武学显示为灰色，原因标注（内力不足、冷却中等）

## 焦点管理规则

### Godot 4.6 双焦点系统

项目使用 Godot 4.6 的鼠标/键盘分离焦点系统：

1. **鼠标焦点 (Mouse Focus)**: 悬停高亮，点击交互
2. **键盘/手柄焦点 (Input Focus)**: 逻辑焦点，Enter/A 确认

**规则**:
- 鼠标移动时，鼠标焦点覆盖键盘焦点（视觉反馈优先）
- 键盘/手柄输入时，逻辑焦点恢复到键盘/手柄焦点
- 两个焦点指示器样式不同，避免混淆

## 动画与过渡

| 交互状态 | 动画类型 | 时长 | 缓动 |
|---------|---------|------|------|
| 悬停 | 缩放 5% + 边框 | 0.15s | Ease Out |
| 选中 | 缩放回弹 | 0.2s | Ease Out Elastic |
| 不可用 | 透明度变化 | 0.1s | Linear |
| 页面切换 | 淡入淡出 | 0.3s | Ease In Out |
| 对话展开 | 从底部滑入 | 0.25s | Ease Out |
