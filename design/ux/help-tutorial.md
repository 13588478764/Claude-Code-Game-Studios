> **Status**: Draft — Ready for Review
> **Author**: ux-designer
> **Last Updated**: 2026-05-08
> **Journey Phase**: 游戏内覆盖面板 (HUD → Side Panel)
> **Template**: UX Spec

## 1. Purpose & Player Need

### 核心目的

帮助/教程系统承担两项职责：

1. **情境教程 (Contextual Tutorial)** — 玩家首次接触某个系统时，自动推送分步引导，降低学习门槛
2. **参考手册 (Reference Manual)** — 玩家主动查询游戏机制、操控方式、战斗策略的静态知识库

### 玩家需求

**新手玩家首次游玩时**：
- 期望游戏在恰当时机给出引导，而非一次性灌输全部信息
- 引导内容应与当前游戏情境相关（如获得第一件装备时弹出装备教程）
- 可以跳过或稍后查看，不被强制打断体验

**老玩家回顾机制时**：
- 期望快速找到某个系统的详细说明（如五行相克关系）
- 内容应有良好的索引和分类，支持搜索或快速定位
- 查看时不应暂停游戏进程（方便边玩边查）

**卡关或疑惑时**：
- 按F1随时打开帮助面板，查阅当前可能遗漏的机制
- 情境提示应标记"已读"状态，避免重复打扰

### 设计原则

- **情境驱动**：教程不是静态列表，而是根据玩家进度动态解锁
- **非阻断式**：面板打开时不暂停游戏，侧边滑入，宽度35%
- **渐进式揭露**：信息分层，先给出核心概念，再提供深入阅读
- **可查阅性**：参考手册随时可用，内容按系统分类

## 2. Player Context on Arrival

### 从情境提示触发

- **时机**：玩家首次遇到某个游戏系统（首次战斗、首次获得装备等）
- **前序状态**：游戏正常运行，HUD完整显示
- **情感状态**：好奇、可能略带困惑
- **期望**：简短的引导说明，解释当前发生了什么、该怎么做
- **特殊**：提示出现在屏幕右下角，10秒后自动收起，可点击"了解更多"展开

### 从HUD帮助按钮打开

- **时机**：玩家点击HUD右上角帮助按钮（问号图标，48x48px）
- **前序状态**：游戏正常运行
- **情感状态**：主动寻求帮助，有明确目标
- **期望**：打开参考手册，默认显示系统说明Tab
- **特殊**：游戏不暂停，面板从右侧滑入

### 从F1快捷键打开

- **时机**：玩家按下F1键
- **前序状态**：游戏正常运行
- **情感状态**：可能遇到了问题或想快速确认某个机制
- **期望**：面板切换（打开/关闭），如果已打开则关闭
- **特殊**：与帮助按钮打开同一面板，F1打开默认停留在上次打开的Tab

## 3. Navigation Position

### 层级关系

```
[HUD] → 帮助面板 (右侧滑入，不暂停游戏)
```

### 导航架构

```
帮助面板 (侧边面板，宽度35%)
├── [Tab 1] 教程 — 情境引导，逐步解锁
├── [Tab 2] 系统说明 — 游戏机制百科
├── [Tab 3] 控制 — 按键绑定与操作说明
└── [Tab 4] 五行与战斗 — 五行相克矩阵、战斗技巧
```

### 定位说明

- **层级深度**: 一级面板（HUD的直接子级）+ 4个分页签（面板内一级）
- **返回方式**: ESC键或F1键关闭面板
- **Z-index**: 180（低于暂停菜单250，高于HUD 100-160）
- **宽度**: 35% 屏幕宽度，最小420px
- **高度**: 100% 屏幕高度
- **对齐**: 右侧对齐，从屏幕右侧滑入
- **游戏状态**: 游戏不暂停，继续在面板后方运行

## 4. Entry & Exit Points

### 入口点

| 入口来源 | 触发条件 | 到达状态 |
|----------|----------|----------|
| HUD帮助按钮 | 点击右上角问号图标 | 帮助面板打开，默认Tab为"系统说明" |
| F1快捷键 | 按下F1 | 帮助面板切换（打开/关闭），默认Tab为上次打开的Tab |
| 情境提示"了解更多" | 点击情境提示中的"了解更多"按钮 | 帮助面板打开，自动定位到对应教程条目 |
| 教程Tab中"稍后查看"的条目 | 点击收藏的教程项 | 帮助面板打开，定位到该教程 |

### 出口点

| 出口去向 | 触发条件 | 状态变化 |
|----------|----------|----------|
| 关闭面板 | 按下ESC或F1键 | 面板向右滑出，游戏继续运行 |
| 关闭面板 | 点击面板外部区域（游戏画面） | 面板向右滑出，游戏继续运行 |
| 关闭面板 | 点击面板顶部"X"按钮 | 面板向右滑出，游戏继续运行 |

### 注意事项

- 打开/关闭面板 **不暂停游戏**，战斗和探索继续进行
- 如果玩家在面板打开时触发新情境提示，提示照常显示在面板后方
- 面板打开时，键盘输入被面板拦截（除F1/ESC外），不传递给游戏
- 手柄模式下，B键可关闭面板

## 5. Layout Specification

### Panel Dimensions

| 属性 | 值 | 说明 |
|------|-----|------|
| 宽度 | 35% 屏幕宽度 | 最小 420px，最大 672px（1920px基准） |
| 高度 | 100% 屏幕高度 | 全高面板，无上下边距 |
| Z-index | 180 | HUD=100-160, 面板=180, Settings=250, Encounter=300 |
| 遮罩 | 无 | 不暂停游戏，无遮罩层 |
| 左侧边框 | 2px 淡青色 | #00CED1, 40% opacity |

### Information Hierarchy

| 优先级 | 信息 | 说明 |
|--------|------|------|
| P0 | 当前分页签内容 | 玩家正在阅读的教程/说明 |
| P0 | 分页签导航 | 4个Tab入口 |
| P1 | 面板标题 + 关闭按钮 | 标识面板用途，提供退出方式 |
| P2 | 教程进度指示 | 显示已解锁/已完成教程数量 |
| P3 | 搜索框（系统说明Tab） | 快速定位系统条目 |

### Layout Zones

```
┌─────────────────────────────────────┐
│  帮助           [进度]         [✕]  │ ← Zone A: 顶部栏 (8%)
├─────────────────────────────────────┤
│  [教程] [系统说明] [控制] [五行与战斗]│ ← Zone B: 分页签导航 (7%)
├─────────────────────────────────────┤
│                                     │
│  🔍 [搜索系统说明...]               │ ← Zone C-1: 搜索框 (仅系统说明Tab, 5%)
│  当前教程/说明内容区域               │ ← Zone C: 内容区域 (75%)
│                                     │
│  ┌─────────────────────────────┐   │
│  │ 标题: 什么是境界突破？        │   │
│  │ 正文: 当修士修为达到当前     │   │
│  │ 境界上限时，可尝试突破至     │   │
│  │ 下一境界...                 │   │
│  │ [ ← 上一页 ]  [ 下一页 → ]   │   │
│  └─────────────────────────────┘   │
│                                     │
├─────────────────────────────────────┤
│           提示: 按 F1 关闭帮助面板   │ ← Zone D: 底部栏 (5%)
└─────────────────────────────────────┘
```

## 6. States & Variants

| 状态 / 变体 | 触发条件 | 变化说明 |
|-------------|----------|----------|
| **默认关闭** | 面板未打开 | 面板完全隐藏在游戏画面右侧之外 |
| **默认打开（从按钮）** | 点击HUD帮助按钮 | 面板从右侧滑入，默认"系统说明"Tab |
| **默认打开（从F1）** | 按下F1 | 面板从右侧滑入，默认上次打开的Tab |
| **默认打开（从情境提示）** | 点击"了解更多" | 面板滑入，自动定位到对应教程条目 |
| **教程步骤完成** | 点击"标记为已完成" | 当前步骤标记✓，自动跳转到下一步 |
| **教程步骤解锁** | 触发对应的游戏事件 | 原本锁定的章节变为可阅读状态 |
| **搜索过滤** | 在搜索框输入文字 | 系统说明词条列表实时过滤，高亮匹配项 |
| **分页签切换** | 点击Tab或键盘←→ | 当前Tab内容淡出，新Tab内容淡入 |

### 情境提示 (Contextual Tutorial Toast)

```
┌──────────────────────────────────────┐
│  💡 第一次战斗                        │
│                                      │
│  回合制战斗中，五行相克是关键。       │
│  金克木，木克土，土克水，水克火，    │
│  火克金。                             │
│                                      │
│  [ 了解更多 ]    [ 稍后查看 ]  [ ✕ ] │
└──────────────────────────────────────┘
```

- **位置**：屏幕右下角，距右边缘20px，距底部100px
- **尺寸**：最大宽度360px，高度自适应
- **Z-index**: 190（在帮助面板180和Tooltip 200之间，在HUD Notifications 160之上）
- **显示时长**：自动10秒后收起，或玩家交互后收起
- **动画**：从右向左滑入(0.3s ease-out)，收起时向右滑出(0.2s ease-in)
- **"了解更多"**：打开帮助面板并定位到对应教程
- **"稍后查看"**：关闭提示，在教程Tab中保存为待阅读
- **"[✕]"**：关闭提示，不再显示该提示

## 7. Interaction Map

### 分页签导航

| 操作 | 输入方式 | 即时反馈 | 结果 |
|------|----------|----------|------|
| 切换分页签（下一个） | 键盘→右箭头 | Tab高亮移动 + 音效 | 切换到下一页签 |
| 切换分页签（上一个） | 键盘→左箭头 | Tab高亮移动 + 音效 | 切换到上一页签 |
| 选择分页签 | 鼠标点击 / Enter / 手柄A | 缩放动画 + 音效 | 切换到对应页签 |
| 关闭面板 | 键盘ESC / F1 / 鼠标点击"X" | 退出动画 | 面板向右滑出 |

### 教程Tab

| 组件 | 操作 | 输入方式 | 即时反馈 | 结果 |
|------|------|----------|----------|------|
| 选择教程步骤 | 点击步骤项 | 鼠标点击 / Enter | 步骤高亮 | 内容区域显示该步骤详情 |
| 翻页（上一步） | 点击"上一页" | 鼠标点击 / Enter / 手柄A | 内容切换 | 显示上一步教程 |
| 翻页（下一步） | 点击"下一页" | 鼠标点击 / Enter / 手柄A | 内容切换 | 显示下一步教程 |
| 标记完成 | 点击"标记为已完成" | 鼠标点击 / Enter / 手柄A | ✓标识 + 音效 | 当前步骤标记完成，自动跳下一步 |

### 系统说明Tab

| 组件 | 操作 | 输入方式 | 即时反馈 | 结果 |
|------|------|----------|----------|------|
| 搜索 | 输入文字 | 键盘键入 | 实时过滤词条 | 仅显示匹配的词条 |
| 选择词条 | 点击词条项 | 鼠标点击 / Enter | 词条高亮 + 详情展开 | 显示该系统详细说明 |
| 清除搜索 | 点击"X"或ESC | 鼠标点击 / ESC | 搜索框清空 | 显示全部词条 |

### 导航顺序

分页签焦点循环顺序（从左到右）：

```
1. 教程 ← 默认焦点（首次打开时）
2. 系统说明
3. 控制
4. 五行与战斗
```

## 9. Transitions & Animations

### 面板动画

| 过渡类型 | 动画 | 时长 | 缓动 |
|----------|------|------|------|
| 面板滑入 | 从屏幕右侧滑入 | 0.3s | ease-out-cubic |
| 面板滑出 | 向屏幕右侧滑出 | 0.25s | ease-in-cubic |
| 分页签切换 | 当前淡出 + 新淡入 | 0.1s + 0.15s | ease-in / ease-out |

### 内容交互动画

| 状态 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 标记完成 | ✓图标弹出 + 微缩放 | 0.2s | ease-out-back |
| 章节解锁 | 灰色 → 正常 + 微光 | 0.3s | ease-out |
| 按钮悬停 | 背景色变化 + 微缩放(1.02x) | 0.15s | ease-out |

### 情境提示动画

| 过渡类型 | 动画 | 时长 | 缓动 |
|----------|------|------|------|
| 提示滑入 | 从右向左滑入 | 0.3s | ease-out |
| 提示滑出 | 向右滑出 | 0.2s | ease-in |
| 自动消失 | 停留10秒后滑出 | 0.2s | ease-in |

### 减少运动选项

启用时：
- 面板直接显示/隐藏，无滑动动画
- 分页签切换直接替换内容
- 情境提示直接出现/消失

## 11. Accessibility

### 键盘导航
- 所有交互元素可通过Tab键和方向键访问
- 分页签切换：左/右箭头键
- 返回/关闭：ESC键或F1键

### 手柄导航
- 方向键/摇杆控制焦点移动，A确认，B关闭
- 肩键（L1/R1）切换分页签

### 视觉无障碍
- 文字对比度WCAG AA级（4.5:1）
- 五行矩阵不仅用颜色区分，附带文字标签（金/木/水/火/土）
- 教程状态标识使用图标 + 文字，不只用颜色

### 减少运动
- 面板滑入/滑出替换为直接显示/隐藏
- 分页签切换无淡入淡出

### 屏幕阅读器
- 所有教程步骤和词条设置Accessible Name/Description
- 分页签切换时播报Tab名称

## 13. Acceptance Criteria

- [ ] 点击HUD帮助按钮后 0.3 秒内面板完全可见
- [ ] F1键可打开和关闭帮助面板（切换行为）
- [ ] 4个分页签可通过键盘左/右箭头循环导航
- [ ] 4个分页签可通过手柄肩键切换
- [ ] ESC键和F1键均可关闭面板
- [ ] 面板打开时游戏不暂停，画面在面板后方继续运行
- [ ] 情境提示在触发条件满足时正确弹出，10秒后自动收起
- [ ] 点击"了解更多"打开面板并定位到对应教程
