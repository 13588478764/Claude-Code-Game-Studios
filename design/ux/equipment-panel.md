> **Status**: Ready for Review
> **Author**: ux-designer
> **Last Updated**: 2026-05-06
> **Journey Phase(s)**: 大地图探索、战斗结束后、休息/存档时
> **Template**: UX Spec

## Purpose & Player Need

装备面板是玩家管理和强化角色装备的核心界面，承载以下目标：

1. **穿戴管理**：展示9个功能槽位（主手武器、副手/离手、头饰、衣袍、护手、靴子、项链、戒指(左)、戒指(右)）的当前装备状态，支持装备/卸下操作
2. **强化系统**：将装备强化至+1~+20，消耗银两+强化石，提升装备基础属性
3. **镶嵌系统**：在装备孔洞中镶嵌宝石（红/蓝/绿/黄/紫/钻），激活套装共鸣效果
4. **幻化系统**：仅限武器幻化外观+VFX特效，保留原属性，改变视觉表现

**如果这个面板不存在或难用**：玩家无法有效管理装备、不知道该强化哪件装备、无法理解宝石套装效果、看不到幻化预览——装备系统的深度Build和长期成长体验将完全失效。

**玩家来到这个面板的目的是**："我穿什么最强？我该强化哪件？宝石怎么搭配？武器外观好看吗？"

## Player Context on Arrival

### 到达时机与场景

| 触发场景 | 到达方式 | 玩家当前状态 | 情绪预期 |
|---------|---------|-------------|---------|
| HUD快捷键(E) / 点击装备按钮 | 玩家主动操作 | 游戏进行中，可能处于探索/战斗结束/休息 | 平静、策略思考 |
| 获得新装备后 | 战斗掉落/奇遇→点击"查看" | 刚获得新装备 | 兴奋、好奇 |
| 强化材料充足时 | 系统提示→玩家主动打开 | 背包中有足够强化石和银两 | 期待、规划 |
| 宝石获得后 | 掉落/拆解→点击"镶嵌" | 刚获得宝石 | 策略思考 |
| 武器外观解锁后 | 收集新武器→点击"幻化" | 刚解锁新武器外观 | 兴奋、审美 |

### 到达方式

装备面板是**玩家主动打开**的面板，不是系统强制推送。玩家带着明确意图——"我想看看装备"或"我需要强化/镶嵌/幻化"。

### 情绪状态

- **获得新装备后**：兴奋、好奇——"新装备有多强？该不该换？"
- **强化前**：紧张、期待——"成功率够吗？该不该用保护符？"
- **平时查看**：平静、策略思考——"我的Build合理吗？下一步强化什么？"

### 关键交付时刻

1. **装备新装备时**：玩家看到属性提升，感受到角色变强
2. **强化成功时**：玩家感受到投资回报，装备属性数字增长
3. **套装共鸣激活时**：玩家感受到Build成型的满足感
4. **武器幻化预览时**：玩家看到新外观，获得视觉满足感

## Navigation Position

装备面板是**侧边滑出面板**，属于HUD之上的二级菜单，与角色面板/背包面板形态一致。

### 导航层级关系

```
Main Game (root)
├── 大地图场景 (World Map)
├── 战斗场景 (Battle)
├── 休息/存档场景 (Rest/Save)
│
├── CanvasLayer: HUD [Z-index: 基础层]
│   └── 装备按钮 / 快捷键E ← 点击触发
│
└── CanvasLayer: Equipment Panel Overlay [Z-index: 200]
    ├── 半透明遮罩 (拦截游戏场景输入) ← 游戏画面渲染在背后，但不可交互
    └── 装备面板 (侧边滑出) ← 从右侧滑入，面板区域可交互
```

### 层级规则

- **Z-index**: HUD = 100, 角色面板 = 200, 背包面板 = 200, 装备面板 = 200, 奇遇面板 = 300, 确认对话框 = 400
- **面板形态**: 侧边滑出（从屏幕右侧），宽度约屏幕的40%（最小宽度560px，最大宽度720px）
- **半模态**: 面板存在期间，游戏场景持续渲染在遮罩后方（15%变暗），但输入被遮罩拦截，玩家无法与游戏场景交互。面板打开期间点击遮罩区域不会关闭面板，必须通过关闭按钮/Escape/E键退出
- **互斥性**: 与角色面板、背包面板、设置面板互斥，同一时间只能打开一个
- **面板内导航**: 四个Tab页签——穿戴（默认）、强化、镶嵌、幻化

## Entry & Exit Points

### Entry Points

| 入口来源 | 触发器 | 玩家携带的上下文 |
|---------|--------|-----------------|
| HUD装备按钮 | 鼠标点击 / 键盘E键 | 当前游戏场景、装备基本状态 |

| 角色面板跳转 | 点击"查看装备"按钮 | 当前角色属性上下文 |

| 强化材料获得提示 | 点击"去强化"按钮 | 刚获得的强化石数量 |

### Exit Points

| 出口目标 | 触发器 | 不可逆状态变化 |
|---------|--------|---------------|
| 游戏场景 | 点击关闭按钮 / 按Escape / 按E键 | 已装备/强化/镶嵌的装备已生效 |
| 角色面板 | 点击角色面板按钮 | 当前面板关闭，角色面板打开 |
| 背包面板 | 点击背包面板按钮 | 当前面板关闭，背包面板打开 |

| 强化 | 点击"强化"按钮并确认 | 强化等级已提升，材料已消耗 |
| 镶嵌 | 点击"镶嵌"按钮 | 宝石已镶嵌到孔洞 |
| 幻化 | 点击"应用幻化"按钮 | 武器外观已改变 |

## Layout Specification

### Information Hierarchy

装备面板必须展示的所有信息，按优先级排列：

| 优先级 | 信息项 | 用途 | 是否始终可见 |
|-------|--------|------|-------------|
| 1 | 面板标题 | 身份识别 | ✅ 始终（Header） |
| 2 | 战力评分 | 当前装备强度概览 | ✅ 始终（Header） |
| 3 | 当前Tab内容 | 穿戴/强化/镶嵌/幻化详情 | 根据Tab切换 |
| 4 | 装备槽位 | 9个功能槽位状态 | ✅ 始终（穿戴Tab） |
| 5 | 选中装备详情 | 属性、品阶、强化等级等 | 选中装备时显示 |
| 6 | 强化材料 | 强化石+银两数量 | ✅ 始终（强化Tab） |
| 7 | 宝石库存 | 各颜色宝石数量 | ✅ 始终（镶嵌Tab） |
| 8 | 套装共鸣状态 | 当前激活的套装效果 | ✅ 始终（镶嵌Tab） |
| 9 | 武器外观库 | 已收集的武器外观 | ✅ 始终（幻化Tab） |

### Layout Zones

装备面板采用**侧边滑出**布局，从屏幕右侧滑入，宽度约为屏幕的40%（最小宽度560px，最大宽度720px）。面板分为以下区域：

#### 整体布局

```
┌────────────────────────────────────────┐ ← 屏幕右侧40%
│  A. Header 区域                         │
│  [装备]                    战力: 1,250  │
├────────────────────────────────────────┤
│  B. Tab 导航                            │
│  [ 穿戴 ]  [ 强化 ]  [ 镶嵌 ]  [ 幻化 ] │
├────────────────────────────────────────┤
│  C. 内容区域 (ScrollContainer)          │
│                                        │
│  当前Tab的详细内容                       │
│  支持滚动查看所有内容                    │
│                                        │
├────────────────────────────────────────┤
│  D. 详情/操作区域 (底部面板)             │
│  选中装备属性 + 操作按钮                │
├────────────────────────────────────────┤
│  E. 关闭区域                            │
│  [X]                                    │
└────────────────────────────────────────┘
```

#### 区域定义

| 区域 | 内容 | 样式 |
|------|------|------|
| **A. Header** | 面板标题、战力评分 | 深色背景，传统纹样边框 |
| **B. Tab导航** | 穿戴/强化/镶嵌/幻化四个Tab按钮 | 当前Tab高亮，水墨风格选中态 |
| **C. 内容** | 当前Tab的详细内容（可滚动） | 半透明背景，ScrollContainer |
| **D. 详情/操作** | 选中装备的详细信息 + 可用操作按钮 | 根据当前Tab和选中装备动态变化 |
| **E. 关闭** | 关闭按钮（右上角） | 简洁的X图标 |

## States & Variants

| 状态/变体 | 触发条件 | 什么变化 |
|-----------|---------|---------|
| **默认** | 玩家通过HUD点击装备按钮打开面板 | 穿戴Tab默认激活，显示9个功能槽位状态，无装备选中 |
| **获得新装备后** | 战斗掉落/奇遇后打开 | 穿戴Tab中对应槽位为空时高亮闪烁（呼吸动画），提示可从背包装备 |
| **强化材料不足** | 打开面板时强化石/银两不足 | 强化Tab中强化按钮灰色禁用，材料显示区文字变红色 |
| **强化可升级** | 当前装备+10/+15/+20里程碑 | 强化按钮变为金色呼吸动画，显示"质变节点"提示 |
| **空槽位** | 9个槽位中有空位时打开 | 空槽位显示灰色虚线边框+槽位类型图标 |
| **装备选中** | 穿戴Tab点击装备槽位 | 详情区域显示装备完整属性、品阶、强化等级 |
| **装备对比** | 穿戴Tab选中装备且背包中有同类型更强装备 | 详情区域显示"可替换"提示，属性对比用▲绿色/▼红色 |
| **强化成功** | 强化Tab点击强化按钮并成功 | 强化等级+1，装备属性更新，播放成功动画 |
| **强化失败** | 强化Tab点击强化按钮且失败 | +11~+15等级不变消耗材料，+16~+20降级(-1/-2)，播放失败动画 |
| **保护符激活** | 强化Tab勾选保护符 | 强化消耗增加（保护符+强化石+银两），+16~+20失败不降级 |
| **孔洞已满** | 镶嵌Tab选择装备且孔洞全满 | 镶嵌按钮灰色禁用，提示"孔洞已满，无法继续镶嵌" |
| **套装共鸣激活** | 全身同色宝石达到3/6/9阈值 | 套装共鸣区对应颜色高亮，显示激活效果描述 |
| **武器已幻化** | 幻化Tab中当前武器已有幻化 | 外观库中已应用外观金色边框高亮，显示"取消幻化"按钮 |
| **武器类型不匹配** | 幻化Tab选择不同类型武器外观 | 应用幻化按钮灰色禁用，提示"武器类型必须一致" |
| **数据加载失败** | 本地存档数据损坏或序列化异常 | 内容区域显示"装备数据加载异常，请重新打开"，按钮区域显示"重试"按钮 |
| **UI缩放175%** | 玩家设置UI缩放到最大 | 面板宽度从40%扩大到70%，所有文字等比放大，槽位变为88×88px，内容区域使用ScrollContainer处理溢出 |

## Interaction Map

映射键盘/鼠标（主）、手柄（部分支持）的交互：

### 面板打开/关闭

| 组件 | 动作 | 输入方式 | 即时反馈 | 结果 |
|------|------|---------|---------|------|
| HUD装备按钮 | 点击 | 鼠标左键 / 键盘E | 面板从右侧滑入 | 装备面板打开 |
| 关闭按钮 | 点击 | 鼠标左键 / Escape | 面板向右侧滑出 | 装备面板关闭 |

## 确认对话框设计规范

### 确认对话框模板

所有强化/镶嵌/幻化操作的确认对话框遵循以下模板（遵循 interaction-patterns.md 确认对话框模式）：

| 元素 | 内容 |
|------|------|
| 标题 | "确认{操作}"（如"确认强化"、"确认镶嵌"、"确认幻化"） |
| 描述 | "确定要{操作}{目标名称}吗？{结果说明}" |
| 预览 | 操作结果预览（消耗材料/预期效果/成功率） |
| 主按钮 | 高亮按钮，文字"确定" |
| 取消按钮 | 次要按钮，文字"取消" |
| 快捷键 | Enter=确定，Escape=取消 |
| 焦点管理 | 默认焦点在"取消"按钮上（高风险操作）或"确定"按钮上（低风险操作） |

### "不再显示确认"选项

| 操作类型 | 是否支持"不再显示" | 说明 |
|---------|------------------|------|
| 装备/卸下 | 不适用 | 低风险操作，不需要确认对话框 |
| 强化 | 支持 | 玩家可勾选"不再显示此提示"，后续强化操作直接执行并显示结果 |
| 镶嵌 | 支持 | 玩家可勾选"不再显示此提示"，后续镶嵌操作直接执行并显示结果 |
| 移除宝石 | 不支持 | 宝石为有限资源，每次都需要确认 |
| 幻化 | 支持 | 玩家可勾选"不再显示此提示"，后续幻化操作直接执行并显示结果 |

**重置方式**：设置面板中提供"重置所有确认对话框"选项，恢复默认行为。

### 分析关键事件

以下事件用于玩家行为分析：

| 事件 | 用途 |
|------|------|
| `equipment_panel_opened` | 追踪装备面板使用频率和来源分布 |
| `equipment_item_equipped` | 追踪装备搭配偏好，识别高使用率装备 |
| `equipment_enhancement_succeeded` | 追踪强化成功率、玩家投入材料量、强化等级分布 |
| `equipment_enhancement_failed` | 追踪失败率、降级频率、玩家流失点 |

**设计要点**：
- 所有写入装备数据的事件（装备/卸下/强化/镶嵌/幻化）都是**状态变更事件**，需要持久化
- 面板打开/关闭、装备查看是**分析事件**，用于理解玩家行为
- 强化失败/套装失效等负面事件也需记录，用于难度调优

### Reduce Motion 支持

当玩家启用"减少动画"选项时：

| 原动画 | 降级行为 |
|--------|---------|
| 面板滑入/滑出 | 直接显示/隐藏（无动画） |
| Tab切换 | 直接切换内容（无淡入淡出） |
| 装备/卸下 | 直接更新显示状态 |
| 强化成功/失败 | 直接更新数值和等级 |
| 宝石镶嵌/移除 | 直接更新孔洞状态 |
| 幻化应用/取消 | 直接切换外观 |
| 战力评分变化 | 直接显示新值（无滚动） |
| 套装共鸣激活 | 仅改变文字（无光效） |

**设计要点**：
- 面板动画时长控制在300ms以内，确保流畅不拖沓
- 所有动画使用Godot的`Tween`节点实现，性能开销低
- 强化失败降级是唯一的"重动画"（600ms），但只在+16~+20失败时播放
- Reduce Motion选项通过全局设置读取，面板内组件统一遵守

| 数据项 | 来源系统 | 读/写 | 实时性 | 说明 |
|-------|---------|-------|--------|------|
| 各颜色宝石库存 | InventorySystem | Read | 静态 | 镶嵌Tab显示 |
| 套装共鸣状态 | GemSetBonusManager | Read | 计算 | 基于全身宝石实时计算 |
| 套装效果列表 | GemConfig | Read | 静态 | 宝石配置表数据 |

### 幻化数据

| 数据项 | 来源系统 | 读/写 | 实时性 | 说明 |
|-------|---------|-------|--------|------|
| 已收集外观列表 | TransmogCollectionManager | Read | 静态 | 幻化Tab外观库 |
| 幻化粉库存 | InventorySystem | Read | 静态 | 幻化消耗来源 |
| 银两库存 | EconomyManager | Read | 实时 | 幻化消耗来源 |

### 数据快照与并发策略

| 操作 | 持久化时机 | 失败处理 |
|------|-----------|---------|
| 装备/卸下 | 点击"装备"/"卸下"按钮后立即写入 | 槽位冲突时回滚操作 |
| 强化 | 确认对话框确认后写入 | 材料不足时回滚，等级不变 |
| 镶嵌宝石 | 确认对话框确认后写入 | 孔洞已满时回滚，宝石回到库存 |
| 移除宝石 | 确认对话框确认后写入 | 库存满时回滚，宝石保留孔洞 |
| 应用幻化 | 确认对话框确认后写入 | 材料不足时回滚，外观不变 |

**并发冲突处理**：
- 面板打开时从各系统读取**快照数据**，面板内操作基于此快照
- 面板存在期间，外部系统（战斗、奇遇）对装备的修改**不会实时同步到面板**
- 面板关闭时，若外部数据已变更（如战斗中获得新装备），关闭前刷新一次显示
- 装备/强化/镶嵌操作时，重新读取当前对应系统的资源进行校验，避免快照过期导致的错误操作
- 银两余额在强化/幻化后立即从EconomyManager重新读取

**设计要点**：
- 面板打开时从各系统读取快照数据，面板内操作不实时同步外部变化
- 所有Write操作需通过各系统的公开API（如`EquipmentManager.equip_item()`, `EnhancementManager.enhance()`）
- 物品数据库数据为只读，由ItemDatabase统一管理
- 战力评分由DerivedStatsCalculator实时计算，不持久化

## Localization Considerations

简体中文为基准语言，翻译到其他语言时的文本扩展预估：

| 元素 | 中文长度 | 英文扩展 | 德文扩展 | 法文扩展 | 布局影响 |

| 品阶名称 | 2字（普通/稀有等） | +40% | +60% | +50% | 低（标签空间充足） |

## Acceptance Criteria

### 性能

- [ ] 面板从点击触发到完全显示不超过400ms（含300ms滑入动画）
- [ ] Tab切换响应时间不超过50ms，内容切换动画200ms内完成
- [ ] 面板打开期间游戏场景持续渲染，帧率不下降超过5%
- [ ] 面板内存占用不超过50MB（含所有UI资源预加载）
- [ ] 强化操作确认后结果计算不超过100ms

### 功能

- [ ] HUD装备按钮(E键)可打开面板，穿戴Tab默认激活
- [ ] 穿戴Tab中，点击装备槽位可选中装备，详情区域显示属性
- [ ] 穿戴Tab中，从背包拖拽装备到对应槽位可完成装备操作
- [ ] 穿戴Tab中，点击卸下按钮可卸下当前装备
- [ ] 强化Tab中，显示当前装备强化等级、成功率、材料库存
- [ ] 强化Tab中，强化按钮在材料不足时灰色禁用
- [ ] 强化Tab中，强化成功后等级+1，属性更新，播放成功动画
- [ ] 强化Tab中，+16~+20失败时装备降级(-1/-2)，播放降级动画
- [ ] 强化Tab中，勾选保护符后+16~+20失败不降级
- [ ] 镶嵌Tab中，显示当前装备孔洞状态和已镶嵌宝石

- [ ] 幻化Tab中，武器类型不匹配时应用幻化按钮灰色禁用
