## 无障碍层级

**已选层级**: Standard — Basic + 色盲模式 + 可缩放 UI

---

## 1. 输入重映射

### 要求
- 所有操作均可通过键盘重新绑定
- 支持手柄和键盘/鼠标输入
- 至少 3 个预设控制方案
- 支持自定义按键绑定

### 实现
- 在设置菜单中提供"控制"页面
- 支持检测按键冲突并提示玩家

---

## 2. 色盲支持

### 要求
- 至少支持 3 种色盲模式：红色盲、绿色盲、蓝黄色盲
- 关键信息不单纯依赖颜色传达（需配合形状、图标或文字）

### 实现
- 使用语义色 + 图标组合传达信息
  - 生命值：红色 + 心形图标
  - 内力：蓝色 + 水滴图标
  - 增益效果：绿色 + 向上箭头
  - 减益效果：紫色 + 向下箭头
- 在设置菜单中提供"色盲模式"开关

### 高风险颜色对
| 颜色对 | 可能失败的玩家 | 替代方案 |
|--------|---------------|---------|
| 红/绿 | 红色盲、绿色盲 | 使用图标 + 文字标签 |
| 蓝/黄 | 蓝黄色盲 | 使用形状区分 |
| 紫/红 | 色觉正常玩家也可能混淆 | 使用对比度 + 形状区分 |

---

## 3. UI 可缩放性

### 要求
- UI 文本支持至少 100%、125%、150%、175% 四档缩放
- UI 元素间距随缩放自适应
- 缩放后不产生内容截断或重叠

### 实现
- 使用 Godot Control 节点的 `size_flags` 和容器布局
- 所有字体大小使用相对单位（基于基础字号的倍数）
- 在设置菜单中提供"UI 缩放"选项

---

## 4. 字幕与音频反馈

### 要求
- 所有语音/音频事件配有字幕
- 字幕可配置（大小、背景、位置）

### 实现
- 字幕使用半透明背景确保可读性
- 字体大小跟随 UI 缩放设置
- 重要音效（如战斗命中）配有视觉反馈

---

## 5. 认知无障碍

### 要求
- 游戏提供清晰的新手引导
- 关键操作有文字说明
- 复杂系统（如武学、奇遇）有说明文档可在游戏中查看

### 实现
- 首次接触新系统时显示引导提示
- 在"帮助"菜单中提供系统说明
- 关键确认对话框提供"不再显示"选项

---
