> **Status**: Ready for Review (Draft — 2026-05-08)
> **Author**: ux-designer
> **Last Updated**: 2026-05-08
> **Journey Phase**: 游戏进行中暂停
> **Template**: UX Spec

## 1. Purpose & Player Need

### 核心目的

暂停菜单是玩家在游戏中按ESC键或点击HUD汉堡菜单按钮打开的模态覆盖层，承担以下核心功能：

1. **继续修炼** — 关闭暂停菜单，恢复游戏运行
2. **保存进度** — 手动存档，记录当前修炼进度
3. **读取存档** — 从存档列表选择并加载（需确认）
4. **修炼设置** — 打开设置子界面（复用 settings.md 的同一实例）
5. **返回主菜单** — 退出当前游戏，回到主菜单（需确认并存档）
6. **退出游戏** — 完全退出程序（需确认）

### 玩家需求

**游戏中途暂停时**：
- 玩家期望游戏立即暂停，不被后台运行打断
- 需要快速存档的入口，防止进度丢失
- 希望快速回到游戏（继续按钮应为默认焦点）

**需要调整设置时**：
- 设置入口清晰，调整后能直接返回游戏
- 画面设置变更时有预览确认机制

**结束游戏会话时**：
- 明确的退出路径，避免误操作丢失进度
- 退出前提供自动存档保护

### 设计原则

- **一键恢复**：默认焦点在"继续"，ESC或Enter即可一秒返回游戏
- **模态阻断**：全屏遮罩，阻断所有游戏输入，确保暂停时游戏完全冻结
- **安全操作**：所有破坏性或不可逆操作（读取、返回主菜单、退出）必须经过确认对话框
- **状态感知**：根据是否有存档、是否游戏中途，动态调整按钮文案和可用性

## 2. Player Context on Arrival

### 战斗中暂停

- **时机**：战斗进行中，按ESC
- **前序状态**：战斗UI可见，行动队列等待中
- **情感状态**：可能有紧迫感（需要快速调整策略或离开）
- **期望**：游戏完全暂停，敌人不会在菜单中行动
- **特殊**：返回游戏后应恢复到暂停前的战斗状态

### 探索中暂停

- **时机**：大地图或场景中移动时
- **前序状态**：HUD正常显示，角色可能在移动
- **情感状态**：从容，可能在规划下一步行动
- **期望**：查看进度、存档、调整设置

### 奇遇触发时暂停

- **时机**：奇遇面板显示中按ESC（Z-index=300）
- **行为**：暂停菜单（Z-index=260）打开但位于奇遇面板下方
- **说明**：奇遇面板是最高优先级模态层，暂停菜单在奇遇关闭后才可交互
- **特殊处理**：此时ESC键优先关闭奇遇面板而非打开暂停菜单

### 对话框显示中暂停

- **时机**：剧情对话框（Z-index=500）显示中按ESC
- **行为**：ESC键优先关闭对话框而非打开暂停菜单
- **说明**：同奇遇面板，高Z-index模态层优先处理ESC

## 3. Navigation Position

### 层级关系

```
[主菜单] → 开始新游戏/继续游戏 → 游戏场景
                                    ↓
                                [暂停菜单] (ESC触发)
                                    ├── 继续（返回游戏场景）
                                    ├── 保存（打开保存确认）
                                    ├── 读取（打开存档列表）
                                    ├── 设置（打开设置子界面）
                                    ├── 返回主菜单（确认后 → 主菜单）
                                    └── 退出游戏（确认后 → 退出）
```

### 导航架构

```
游戏场景 (root)
├── 暂停菜单 (模态覆盖层, Z-index=260)
│   ├── 继续 → 关闭暂停菜单，恢复游戏
│   ├── 保存 → 确认对话框 → 存档操作 → 返回暂停菜单
│   ├── 读取 → 存档列表子面板 → 确认对话框 → 加载存档 → 游戏场景
│   ├── 设置 → 设置子界面 (复用 settings.md, Z-index=200)
│   ├── 返回主菜单 → 确认对话框 → 自动存档 → 主菜单
│   └── 退出游戏 → 确认对话框 → 退出
```

### 定位说明

- **层级深度**：游戏场景 → 暂停菜单（一级模态层）→ 确认对话框/设置（二级）→ 存档列表（三级）
- **返回方式**：ESC键逐级退出（对话框 → 暂停菜单 → 游戏）
- **与HUD关系**：HUD位于Z-index=100~160，暂停菜单覆盖其上
- **与奇遇面板关系**：奇遇面板Z-index=300 > 暂停菜单Z-index=260，奇遇面板始终在最上层

## 4. Entry & Exit Points

### 入口点

| 入口来源 | 触发条件 | 到达状态 |
|----------|----------|----------|
| 游戏场景 | 按ESC键 | 暂停菜单打开，游戏暂停 |
| 游戏场景 | 点击HUD右上角汉堡菜单按钮 | 暂停菜单打开，游戏暂停 |
| 奇遇面板关闭后 | 暂停菜单已打开但被奇遇遮挡 | 奇遇关闭后，暂停菜单成为最上层模态层 |

### 出口点

| 出口去向 | 触发条件 | 状态变化 |
|----------|----------|----------|
| 游戏场景 | 选择"继续"或按ESC（无子面板打开时） | 关闭暂停菜单，恢复游戏运行 |
| 确认对话框 | 选择保存/读取/返回主菜单/退出 | 弹出确认对话框，暂停菜单保持打开但变暗 |
| 设置界面 | 选择"设置" | 打开设置子界面（复用settings.md实例），游戏保持暂停 |
| 存档列表 | 选择"读取存档" | 打开存档列表子面板，暂停菜单保持打开但变暗 |
| 主菜单 | 选择"返回主菜单" → 确认 → 自动存档完成 | 关闭暂停菜单，加载主菜单场景 |
| 退出游戏 | 选择"退出游戏" → 确认 | 关闭游戏程序 |

## 6. States & Variants

### 面板状态

| 状态 / 变体 | 触发条件 | 变化说明 |
|-------------|----------|----------|
| **默认状态** | 游戏中按ESC | 完整6按钮面板，默认焦点在"继续修炼" |
| **首次游戏（无存档）** | 新游戏第一次暂停 | 无存档相关变化，所有按钮可用 |
| **有存档状态** | 存在至少一个存档 | 所有按钮正常可用 |
| **保存成功** | 存档操作完成 | 短暂显示"修炼进度已保存"提示（1.5秒），然后自动关闭子对话框 |
| **保存失败** | 存档操作失败 | 显示"修炼进度保存失败"提示，提供"重试"和"返回"选项 |
| **设置子界面打开** | 选择"修炼设置" | 设置面板居中打开（复用settings.md），暂停菜单在后方变暗（额外15%） |
| **存档列表打开** | 选择"读取存档" | 存档列表子面板居中打开，暂停菜单在后方变暗（额外15%） |
| **确认对话框打开** | 保存/返回主菜单/退出按钮点击 | 居中弹出确认对话框，暂停菜单在后方变暗（额外15%） |

### 确认对话框规格

**保存进度确认**:
```
┌──────────────────────────────────────┐
│         确认保存修炼进度？             │
│                                      │
│    [ 确认保存 ]    [ 取消 ]          │
└──────────────────────────────────────┘
```
- 默认焦点：确认保存
- ESC关闭：取消并返回暂停菜单

**返回主菜单确认**:
```
┌──────────────────────────────────────────┐
│         确认返回主菜单？                       │
│   当前进度将自动保存                           │
│                                              │
│    [ 保存并返回 ]    [ 不保存直接返回 ]       │
│         [ 取消 ]                             │
└──────────────────────────────────────────┘
```
- 默认焦点：保存并返回
- "不保存直接返回"：警告色边框（#FF8C42），提示有丢失进度风险
- "取消"：返回暂停菜单

**退出游戏确认**:
```
┌──────────────────────────────────────┐
│         确认退出修炼？                 │
│   当前进度将自动保存                   │
│                                      │
│    [ 保存并退出 ]    [ 取消 ]        │
└──────────────────────────────────────┘
```
- 默认焦点：保存并退出
- ESC关闭：取消并返回暂停菜单

## 7. Interaction Map

| 保存进度按钮 | 点击/确认 | 鼠标左键 / Enter | 缩放动画 + 音效 | 弹出保存确认对话框 |
| 读取存档按钮 | 点击/确认 | 鼠标左键 / Enter | 缩放动画 + 音效 | 打开存档列表子面板 |
| 修炼设置按钮 | 点击/确认 | 鼠标左键 / Enter | 缩放动画 + 音效 | 打开设置子界面 |
| 返回主菜单按钮 | 点击/确认 | 鼠标左键 / Enter | 缩放动画 + 音效 | 弹出返回主菜单确认对话框 |

|------|------|----------|----------|------|
| 按钮组 | 上下导航 | D-Pad ↑↓ / 左摇杆 | 焦点高亮移动 + 音效 | 焦点在按钮间循环移动 |
| 按钮 | 确认 | A按钮 | 缩放动画 + 音效 | 触发对应功能 |
| 面板 | 关闭 | B按钮 | 退出动画 | 关闭暂停菜单，恢复游戏 |
| 设置/存档子面板 | 关闭 | B按钮 | 退出动画 | 关闭子面板，返回暂停菜单 |
| 对话框 | 关闭 | B按钮 | 退出动画 | 关闭对话框，返回上层 |

### 导航顺序

按钮焦点循环顺序（从上到下）：

**有存档时**:
```
1. 继续修炼 ← 默认焦点（有存档时）
2. 保存进度
3. 读取存档
4. 修炼设置
5. 返回主菜单
6. 退出游戏
```

**无存档时（首次游戏）**:
```
1. 继续修炼 ← 默认焦点
2. 保存进度
3. 读取存档（置灰，不可聚焦 — 无存档可读取）
4. 修炼设置
5. 返回主菜单
6. 退出游戏
```

到达底部后再按 ↓ 回到顶部，形成循环导航。

### 焦点管理规则

| 场景 | 焦点行为 |
|------|----------|
| 暂停菜单打开 | 焦点默认设置到"继续修炼"按钮 |
| 确认对话框打开 | 焦点转移到对话框的默认按钮（确认） |
| 确认对话框关闭 | 焦点返回之前聚焦的暂停菜单按钮 |
| 设置界面打开 | 焦点转移到设置界面的默认Tab |
| 设置界面关闭 | 焦点返回"修炼设置"按钮 |
| 存档列表打开 | 焦点转移到第一个存档项 |
| 存档列表关闭 | 焦点返回"读取存档"按钮 |
| ESC键（无子面板） | 直接关闭暂停菜单 |
| ESC键（有子面板/对话框） | 关闭最上层子面板/对话框 |

## 9. Transitions & Animations

### 暂停菜单入场动画

按ESC或点击汉堡菜单后：

1. **背景遮罩淡入** (0.0s - 0.2s) — 全屏rgba(0,0,0,0.65)遮罩淡入，0.2秒 ease-out
2. **游戏画面减速** (0.0s - 0.1s) — 游戏逻辑立即暂停（非慢动作），所有运行中的动画冻结
3. **面板缩放进入** (0.1s - 0.3s) — 面板从中心缩放进入（85% → 100%），0.2秒 ease-out-back
4. **按钮依次淡入** (0.2s - 0.35s) — 按钮从上到下依次淡入，间隔0.03秒
5. **位置提示淡入** (0.3s - 0.4s) — 底部位置提示文字淡入

### 暂停菜单退出动画

选择"继续修炼"或按ESC关闭时：

1. **面板缩放退出** (0.0s - 0.15s) — 面板向中心缩放收缩（100% → 85%），0.15秒 ease-in
2. **按钮淡出** (0.0s - 0.1s) — 按钮同时淡出
3. **背景遮罩淡出** (0.1s - 0.3s) — 遮罩淡出，游戏恢复运行

### 子面板/对话框过渡

| 过渡类型 | 动画 | 时长 | 缓动 |
|----------|------|------|------|
| 确认对话框弹出 | 居中弹出，暂停菜单15%额外变暗 | 0.2s ease-out |
| 确认对话框关闭 | 缩放退出（100% → 85%），恢复暂停菜单亮度 | 0.15s ease-in |
| 存档列表打开 | 居中缩放进入（90% → 100%），暂停菜单15%额外变暗 | 0.25s ease-out-back |
| 存档列表关闭 | 缩放退出（100% → 90%），恢复暂停菜单亮度 | 0.2s ease-in |
| 设置界面打开 | 复用settings.md入场动画（从中心缩放进入） | 0.2s ease-out-back |
| 设置界面关闭 | 复用settings.md退出动画 | 0.15s ease-in |
| 保存成功提示 | 顶部淡入 → 停留1.5秒 → 淡出 | 0.1s淡入 + 1.5s停留 + 0.15s淡出 |

### 按钮交互动画

| 状态 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 鼠标悬停 | 背景色变化 + 微缩放(1.02x) | 0.15s | ease-out |
| 鼠标离开 | 恢复默认 | 0.15s | ease-out |
| 点击按下 | 缩放(0.98x) + 颜色加深 | 0.1s | ease-in |
| 焦点移动 | 焦点指示器移动 | 0.15s | ease-out |

### 减少运动选项

当设置中"减少运动"启用时：
- 禁用所有入场/退场动画，改为直接显示/隐藏
- 面板直接显示/隐藏，无缩放或淡入淡出
- 按钮交互仅保留颜色变化，无缩放动画

## 11. Accessibility

### 键盘导航

- 所有按钮必须可通过 Tab 键和 ↑↓ 方向键访问
- 焦点指示器必须清晰可见（金色边框 #FFD700 + 1px 内发光）
- Enter/Space 确认选择，ESC 关闭暂停菜单
- 子面板/对话框打开时，焦点自动转移到子面板的第一个交互元素
- 子面板/对话框关闭时，焦点返回触发该操作的按钮

### 手柄导航

- 手柄D-Pad/左摇杆控制焦点移动
- A 按钮确认选择，B 按钮返回/关闭
- 焦点循环：到达底部后回到顶部
- 存档列表中，D-Pad ↑↓ 切换存档项，A 选中/取消选中

### 视觉无障碍

- 所有文字对比度至少达到 WCAG AA 级（4.5:1）
- 按钮文字字号不低于 16px（1080p基准）
- 背景遮罩透明度确保后方游戏内容不干扰菜单阅读
- 禁用/不可用按钮同时使用灰度 + 透明度降低（非仅依赖颜色）
- 读取存档按钮在无存档时置灰且不可聚焦（非仅变灰）

### 减少运动

- 启用时禁用所有入场/退场动画
- 面板直接显示/隐藏，无缩放或淡入淡出
- 按钮交互仅保留颜色变化，无缩放动画

### 屏幕阅读器

- 所有按钮设置 `accessible_name`（如"继续修炼"、"保存进度"）
- 按钮 `accessible_description` 包含操作说明（如"关闭暂停菜单，返回游戏"）
- 打开时播报"修炼已暂停"
- 存档项朗读完整的存档信息（境界、区域、游戏时间、存档时间）
- 确认对话框内容完整播报

## 14. Open Questions

1. **存档槽位数量**：MVP阶段设定为3个存档槽是否足够？是否需要扩展槽位或支持覆盖存档？
   - 建议：MVP 3个存档槽，后续版本可扩展

3. **自动保存触发时机**：除返回主菜单/退出游戏外，是否需要在其他时机（如进入战斗前、完成奇遇后）自动保存？
   - 建议：MVP仅在返回主菜单和退出时自动保存，后续根据设计需求扩展

4. **暂停菜单位置**：当前设计为屏幕偏左（与主菜单风格一致），是否考虑居中布局？
   - 建议：保持偏左布局，与主菜单形成视觉一致性

5. **多人游戏考虑**：若未来支持多人联机，暂停菜单是否仅对房主可用？
   - 建议：MVP为单人游戏，暂不考虑多人场景

6. **HUD汉堡菜单按钮与ESC的等价性**：HUD中点击汉堡菜单按钮是否完全等同于按ESC？是否需要在行为上区分（如HUD点击不暂停但ESC暂停）？
   - 建议：两者完全等价，都暂停游戏并打开暂停菜单
