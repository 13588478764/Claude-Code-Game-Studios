## Purpose & Player Need

### 核心目的

设置界面承担以下功能：

1. **画面设置** — 调整分辨率、全屏/窗口模式、画质等级、UI缩放、减少运动选项
2. **音效设置** — 调整各音量通道（主音量、BGM、音效、UI音效、环境音效）
3. **控制设置** — 键鼠按键绑定、手柄按键映射、灵敏度调整
4. **无障碍设置** — 色盲模式、文本缩放、字幕设置、减少运动
5. **恢复默认** — 一键恢复所有设置为出厂默认值

### 玩家需求

**调整游戏舒适度时**：
- 玩家期望音效调整即时生效，能立即听到变化
- 画面设置需确认后再应用，避免黑屏或不可操作
- 设置项应清晰分类，易于找到目标选项
- 误操作后能一键恢复默认

**无障碍需求时**：
- 色盲玩家需要调整色彩模式
- 低视力玩家需要放大文本和UI
- 晕动症患者需要关闭动画和减少运动

### 设计原则

- **混合生效模式**：音效调整即时生效，画面设置需确认
- **分类清晰**：4个分页签，每个页面聚焦一个维度
- **安全网**：任何页面都支持"恢复默认"
- **效率优先**：常用设置在前两层点击内可达

## Player Context on Arrival

### 从主菜单进入

- **时机**：游戏启动后，点击主菜单"修炼设置"
- **前序状态**：主菜单界面，无游戏运行
- **情感状态**：从容、有目的性，可能在首次游玩前调整设置
- **期望**：快速找到目标设置，调整后立即开始游戏
- **特殊**：可能首次打开设置，所有选项为出厂默认值

### 从游戏内暂停菜单进入

- **时机**：游戏进行中，按ESC打开暂停菜单，选择"设置"
- **前序状态**：游戏正在运行，背景为游戏场景
- **情感状态**：可能有时间压力（如战斗中暂停），需要快速调整
- **期望**：
  - 游戏暂停，不被打断
  - 调整后即时生效并返回游戏
  - 画面设置变更时有预览提示
- **特殊**：设置界面覆盖在游戏画面上方，背景半透明遮罩

### 从无障碍需求触发

- **时机**：玩家在游戏中发现视觉/听觉不适，通过暂停菜单或快捷入口进入
- **情感状态**：可能需要紧急调整（如晕动症、听不清提示音）
- **期望**：无障碍设置易于找到，变更后立即生效
- **处理**：无障碍设置作为独立分页签，不应隐藏在子菜单中

## Navigation Position

### 层级关系

```
[主菜单] → 修炼设置 (子菜单，root level for settings)
```

```
游戏内暂停菜单 → 修炼设置 (同一界面实例)
```

### 导航架构

```
主菜单 (root)
├── 修炼设置 → Settings 界面
│   ├── [Tab 1] 画面设置
│   ├── [Tab 2] 音效设置
│   ├── [Tab 3] 控制设置
│   └── [Tab 4] 无障碍设置
```

### 定位说明

- **层级深度**: 一级设置界面（主菜单的直接子级）+ 4个分页签（设置内一级）
- **返回方式**: ESC键或"返回"按钮回到主菜单/游戏内暂停菜单
- **替代入口**: 游戏内暂停菜单也包含"设置"入口，指向同一界面实例
- **快捷入口**: HUD右上角有设置按钮，可快速访问（不暂停游戏）

## Entry & Exit Points

### 入口点

| 入口来源 | 触发条件 | 到达状态 |
|----------|----------|----------|
| 主菜单 | 点击"修炼设置"按钮 | 设置界面默认状态（上次打开的分页签） |
| 游戏内暂停菜单 | 选择"设置"选项 | 设置界面默认状态，游戏暂停，背景半透明遮罩（15%变暗），Z-index=200 |
| HUD快捷入口 | 点击右上角设置图标 | 设置界面默认状态，**仅开放音效/控制/无障碍三页签**，画面设置页隐藏；游戏不暂停，半透明遮罩（15%变暗），输入被遮罩拦截，点击遮罩不关闭面板 |

### 出口点

| 出口去向 | 触发条件 | 状态变化 |
|----------|----------|----------|
| 返回主菜单 | 点击"返回"按钮或ESC（从主菜单进入时） | 关闭设置界面，返回主菜单 |
| 返回游戏 | 点击"返回"按钮或ESC（从暂停菜单进入时） | 关闭设置界面，恢复游戏运行 |
| 关闭HUD设置 | 点击"返回"或ESC（从HUD快捷入口进入时） | 关闭设置面板，游戏继续运行 |
| 应用并返回 | 画面设置点击"应用" | 应用画面变更，关闭设置界面 |

### 注意事项

- 从主菜单进入时，"返回"按钮文字显示为"返回"
- 从游戏内进入时，"返回"按钮文字显示为"继续修炼"
- 画面设置变更时，如果存在未应用的变更，离开时会弹出确认对话框

## Layout Specification

### Panel Dimensions

| 属性 | 值 | 说明 |
|------|-----|------|
| 宽度 | 40% 屏幕宽度 | 最小 560px，最大 720px；175% 缩放时 70% |
| 高度 | 80% 屏幕高度 | 自适应内容，超出可滚动 |
| 对齐 | 居中 | 水平垂直居中 |
| Z-index | 200 | HUD=100, 面板=200, 奇遇=300, 对话框=400 |
| 半模态 | 15% 变暗遮罩 | 游戏渲染在遮罩后方，输入被遮罩拦截，点击遮罩不关闭 |
| 焦点样式 | 金色边框 #FFD700 + 1px 内发光 | 遵循 interaction-patterns.md |

### Information Hierarchy

| 优先级 | 信息 | 说明 |
|--------|------|------|
| P0 - 最高 | 当前分页签的设置项 | 玩家正在调整的设置内容 |
| P0 - 最高 | 分页签导航 | 4个Tab入口（画面、音效、控制、无障碍） |
| P1 - 高 | "应用"按钮（画面设置页） | 确认画面变更 |
| P1 - 高 | "恢复默认"按钮 | 所有页面可用，一键重置 |
| P2 - 中 | 当前生效状态提示 | 如"设置已更改，点击应用生效" |
| P3 - 低 | 返回按钮 | 退出设置界面 |

```
+-------------------------------------------+
|  顶部栏：标题 + 返回按钮                   |
+-------------------------------------------+

+-------------------------------------------+
|           内容区域                           |

|   画质            [滑块 ◄────●──►]         |
|   ...             ...                      |
+-------------------------------------------+
|  底部栏：恢复默认 | 应用（仅画面页） |
+-------------------------------------------+
```

**Zone A - 顶部栏** (顶部，约占屏幕 8%)
- 设置界面标题："修炼设置"
- 右侧："返回" / "继续修炼"按钮（根据入口不同显示不同文字）

**Zone B - 分页签导航** (上部，约占屏幕 6%)
- 4个水平排列的Tab按钮
- 当前选中Tab高亮（底色 + 底边框）
- 键盘可导航：← → 键切换分页签

**Zone C - 内容区域** (中部，约占屏幕 65%)
- 当前分页签的所有设置项
- 两列布局：左侧标签 + 右侧控件
- 超出时可滚动（ScrollContainer）

**Zone D - 底部栏** (底部，约占屏幕 8%)
- 左侧："恢复默认"按钮
- 右侧："应用"按钮（仅画面设置页显示）
- 注意：无"返回"按钮，返回操作统一由顶部栏按钮或ESC键触发

## States & Variants

| 状态 / 变体 | 触发条件 | 变化说明 |
|-------------|----------|----------|
| **默认状态** | 打开设置界面 | 显示上次打开的分页签，所有设置项为当前值 |
| **首次打开** | 首次进入游戏 | 所有设置项为出厂默认值，默认聚焦"音效设置"Tab |
| **设置已更改（音效页）** | 拖动音效滑块 | 即时生效，无需确认，底部不显示"应用"按钮 |
| **设置已更改（画面页）** | 修改画面设置 | 未应用的变更以橙色提示（#FF8C42，字体大小16pt），提示位于底部栏上方居中，底部"应用"按钮高亮，显示"设置已更改，点击应用生效" |
| **UI缩放已更改** | 调整UI缩放滑块 | 即时生效但ESC可撤销，提示"按ESC撤销UI缩放"，2秒后自动消失 |
| **恢复默认确认** | 点击"恢复默认" | 弹出确认对话框，可选"确认恢复"或"取消" |
| **应用画面变更** | 点击"应用" | 应用画面变更，短暂显示"设置已保存"提示，"应用"按钮恢复默认状态 |
| **按键等待输入** | 点击键鼠/手柄绑定的重映射按钮 | 按钮显示"按任意键..."，ESC取消，5秒超时自动取消，按钮旁显示"按ESC取消"提示 |
| **按键冲突警告** | 绑定的按键与其他功能冲突 | 弹出冲突提示，显示两个功能选项 |
| **分辨率切换预览** | 选择新分辨率 | 立即应用但显示倒计时确认对话框（5秒），超时自动恢复原分辨率 |
| **全屏切换** | 切换全屏/窗口模式 | 立即切换，显示确认对话框（5秒） |
| **错误状态** | 设置文件损坏或无法保存 | 提示"修炼环境配置损坏，请恢复默认设置" |

### 确认对话框规格

**恢复默认设置确认**:
```
┌──────────────────────────────────────┐
│         确认恢复默认设置？             │
│     所有设置将恢复为出厂默认值         │
│                                      │
│    [ 确认恢复 ]    [ 取消 ]          │
└──────────────────────────────────────┘
```

**分辨率切换倒计时**:
```
┌──────────────────────────────────────┐
│         分辨率已切换                    │
│   如果画面异常，5秒后将自动恢复         │
│                                      │
│         5 → 4 → 3 → 2 → 1            │
│                                      │
│  [ 恢复原分辨率 ]    [ 确认保留 ]     │
└──────────────────────────────────────┘
```

- 倒计时期间，设置界面其他设置项仍可交互
- 点击"恢复原分辨率"或超时5秒：恢复原分辨率，关闭对话框
- 点击"确认保留"：保留新分辨率，关闭对话框
- 倒计时期间玩家可暂停（点击暂停图标或按Space），倒计时暂停/恢复

**按键冲突警告**:
```
┌──────────────────────────────────────┐
│         按键冲突                        │
│   该按键已被「跳跃」使用                │
│   是否覆盖？                           │
│                                      │
│    [ 覆盖 ]    [ 取消 ]               │
└──────────────────────────────────────┘
```

## Interaction Map

### 分页签导航

| 操作 | 输入方式 | 即时反馈 | 结果 |
|------|----------|----------|------|
| 切换分页签（下一个） | 键盘 → 右箭头 | Tab高亮移动 + 音效 | 切换到下一页签 |
| 切换分页签（上一个） | 键盘 → 左箭头 | Tab高亮移动 + 音效 | 切换到上一页签 |
| 选择分页签 | 鼠标左键点击 / Enter / 手柄A | 缩放动画 + 音效 | 切换到对应页签 |
| 关闭设置 | 键盘ESC / 鼠标点击"返回" | 退出动画 | 返回上一页（主菜单或游戏内） |

### 画面设置页

| 按键绑定（键鼠） | 点击重映射按钮 | 鼠标点击 / Enter | 按钮显示"按任意键..." | 等待输入，按下新键后绑定 |
| 按键绑定（手柄） | 点击重映射按钮 | 同上 | 同上 | 等待输入，按下手柄键后绑定 |
| 鼠标灵敏度 | 拖动滑块 | 鼠标拖动 / 键盘←→ | 滑块移动 + 等级更新 | 即时生效 |
| 恢复默认 | 点击按钮 | 鼠标点击 / Enter / 手柄A | 弹出确认对话框 | 重置控制设置 |

### 无障碍设置页

| 组件 | 操作 | 输入方式 | 即时反馈 | 结果 |
|------|------|----------|----------|------|
| 色盲模式 | 下拉选择 | 鼠标点击 / 键盘↑↓ + Enter | 下拉展开，高亮选中项 | 即时生效，屏幕色彩变化 |
| 文本缩放 | 拖动滑块 | 鼠标拖动 / 键盘←→ | 滑块移动 + 百分比更新 | 即时生效，所有文本缩放 |
| 字幕开关 | 切换开关 | 鼠标点击 / Enter / 手柄A | 开关状态变化 | 即时生效 |
| 减少运动（无障碍页） | 切换开关 | 同上 | 开关状态变化 | 即时生效（主控，修改此处值） |
| 恢复默认 | 点击按钮 | 鼠标点击 / Enter / 手柄A | 弹出确认对话框 | 重置无障碍设置 |

### 导航顺序

分页签焦点循环顺序（从左到右）：

```
1. 画面 ← 默认焦点
2. 音效
3. 控制
4. 无障碍
```

内容区域焦点顺序（从上到下，按分页签区分）：

**画面设置页**:
```
1. 分辨率
2. 全屏模式
3. 画质等级
4. UI缩放
5. 减少运动（只读快捷入口，跳转到无障碍页）
```

**音效设置页**:
```
1. 主音量
2. BGM音量
3. 音效音量
4. UI音效音量
5. 环境音效音量

分页签切换快捷键: L1/R1 (手柄) 或 Ctrl+←/→ (键盘)
注: 滑块聚焦时，←/→键仅用于调整数值，不触发分页签切换
```

**控制设置页**:
```
1. 键鼠绑定（可滚动多项）
2. 手柄绑定（可滚动多项）
3. 鼠标灵敏度
```

**无障碍设置页**:
```
1. 色盲模式
2. 文本缩放
3. 字幕开关
4. 减少运动（无障碍页）← 与画面页联动，同一设置
```

底部栏焦点顺序（从左到右）：

```
1. 恢复默认
2. 应用（仅画面页）
```

## Transitions & Animations

### 设置界面入场动画

从主菜单或暂停菜单打开设置界面时：

1. **背景遮罩淡入** (0.0s - 0.15s) — 半透明黑色遮罩覆盖全屏，0.15秒缓动
2. **设置面板滑入** (0.1s - 0.3s) — 面板从屏幕中心缩放进入（80% → 100%），0.2秒 ease-out-back
3. **内容淡入** (0.2s - 0.35s) — 设置项依次淡入，间隔0.03秒

### 分页签切换动画

| 过渡类型 | 动画 | 时长 | 缓动 |
|----------|------|------|------|
| 切换到新Tab | 当前Tab内容淡出 + 新Tab内容淡入 | 0.15s fade-out + 0.15s fade-in | ease-in / ease-out |
| Tab高亮移动 | 底部指示器滑动 | 0.15s | ease-out |

### 设置项状态变化动画

| 状态 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 滑块拖动 | 滑块位置平滑移动 + 数值实时更新 | 跟随鼠标 | linear |
| 开关切换 | 开关滑动动画 + 颜色变化 | 0.15s | ease-out |
| 下拉展开 | 下拉菜单从顶部展开（高度0 → 实际高度） | 0.15s | ease-out |
| 下拉收起 | 向上收缩（实际高度 → 0） | 0.1s | ease-in |
| 按钮悬停 | 背景色变化 + 微缩放(1.02x) | 0.15s | ease-out |
| 按钮按下 | 缩放(0.98x) + 颜色加深 | 0.1s | ease-in |

### 确认对话框动画

| 对话框类型 | 动画 | 时长 |
|------------|------|------|
| 恢复默认确认 | 居中弹出，背景遮罩淡入 | 0.2s ease-out |
| 分辨率倒计时 | 从屏幕顶部滑入 | 0.2s ease-out |
| 按键冲突警告 | 居中弹出，背景遮罩淡入 | 0.15s ease-out |
| 设置已保存提示 | 从底部淡入，2秒后自动消失 | 淡入0.15s + 停留2s + 淡出0.15s |

### 设置界面退出动画

| 动画 | 时长 | 缓动 |
|------|------|------|
| 背景遮罩淡出 | 0.2s | ease-in |
| 设置面板缩放退出（100% → 90%） | 0.15s | ease-in |

### 减少运动选项

对于启用"减少运动"选项的玩家：
- 禁用入场动画：直接显示设置界面
- 禁用Tab切换动画：直接切换内容
- 禁用滑块拖动动画：仅保留数值变化
- 确认对话框直接弹出，无滑入效果

## Accessibility

### 键盘导航

- 所有设置项必须可通过键盘Tab键和方向键访问
- 分页签切换：左/右箭头键
- 内容区域导航：上/下箭头键或Tab键
- 滑块调整：左/右箭头键（聚焦滑块时）
- 开关切换：Enter/Space键
- 下拉菜单：Enter打开，上/下箭头选择，Enter确认，ESC关闭
- 返回/关闭：ESC键
- 焦点指示器必须清晰可见（高对比度边框）

### 手柄导航

- 手柄方向键/摇杆控制焦点移动
- A键（或X）确认选择/切换开关
- B键（或O）返回/关闭下拉菜单
- 肩键（L1/R1）可在分页签间切换
- 焦点循环导航支持（到底部后继续到顶部）

### 视觉无障碍

- 所有文字对比度至少达到 WCAG AA 级（4.5:1）
- 设置项标签字号不低于 16pt（1080p 基准）
- 滑块控件有清晰的视觉轨道和滑块指示器
- 开关控件有明确的"开启"/"关闭"文字标签
- 不依赖颜色传达信息（如滑块值同时用数值和位置表示）

### 减少运动

- 本界面本身就是"减少运动"选项的管理入口
- 启用时禁用所有动画和过渡效果
- 设置切换为直接切换，无淡入淡出
- 滑块为即时数值变化，无平滑移动

### 屏幕阅读器

- 所有设置项必须有可读的 Accessible Name 和 Description
- 滑块值变化时触发屏幕阅读器播报当前值
- 开关状态变化时播报"已开启"或"已关闭"
- 确认对话框内容完整播报
- 倒计时确认对话框实时播报剩余秒数

- 分页签标签应支持英文文本 40% 扩展

- 中文：优先使用内置字体或自定义字体（支持简体/繁体中文）
- 英文：标准系统字体
- 日韩文字：确保字符覆盖完整
- 设置界面字体应跟随UI缩放设置缩放

## Acceptance Criteria

- [ ] 设置界面在点击"修炼设置"后 0.5 秒内完全可见
- [ ] 4个分页签可通过键盘左/右箭头循环导航
- [ ] 4个分页签可通过手柄肩键（L1/R1）切换
- [ ] 音效滑块拖动时，音量即时变化，玩家可听到变化
- [ ] 画面设置修改后，"应用"按钮高亮，底部显示"设置已更改"提示
- [ ] 点击"应用"后，画面设置生效，显示"设置已保存"提示
- [ ] 分辨率切换后显示 5 秒倒计时，超时自动恢复原分辨率
- [ ] 全屏模式切换后显示 5 秒倒计时，超时自动恢复
- [ ] 按键重映射时，按下新键后正确绑定，无冲突时直接保存

- [ ] 设置数据在下次打开时正确记忆（上次Tab、上次修改值）
- [ ] 设置文件损坏时显示错误提示，并提供"恢复默认"选项

1. **是否需要"高级设置"选项？** 如垂直同步、抗锯齿、各向异性过滤等高级图形设置
