## 1. 目的与玩家需求

大地图界面是玩家查看修真界全貌、规划旅行路线、追踪探索进度的核心界面，承载以下目标：

1. **世界认知**：展示九州修真界的区域分布、地貌特征、重要地点，帮助玩家建立空间心智模型
2. **导航规划**：查看当前目标位置、任务标记、已发现传送点，规划下一步行动路线
3. **快速旅行**：从已发现的传送点中选择目的地，支付资源后快速到达
4. **探索驱动**：查看各区域的探索完成度，激发"收集"和"探索完所有内容"的欲望
5. **奇遇回顾**：查看已触发和未触发的仙缘点位分布

**玩家来到这个界面的目的是**："我在哪？我该去哪？我能去哪？我错过了什么？"

## 2. 玩家到达时的上下文

| 触发场景 | 到达方式 | 玩家当前状态 | 情绪预期 |
|---------|---------|-------------|---------|
| 探索中主动查看 | 按M键 / 点击HUD大地图按钮 | 在大地图场景中，正常探索 | 好奇、规划 |
| 双击小地图 | 在小地图上双击 | 关注当前区域细节 | 需要更宏观的视野 |
| 任务追踪点击 | 点击任务追踪中的"查看大地图" | 需要找到任务目标位置 | 目的明确、急于导航 |
| 获得传送点后 | 奇遇/任务解锁新传送点，系统提示 | 刚获得新能力 | 兴奋、想试试 |

### 情绪状态

- **初次打开**：好奇、探索欲——"这个世界有多大？"
- **任务导航**：目的明确、专注——"目标在哪？怎么去？"
- **探索回顾**：满足感、FOMO——"我已经探索了多少？"

## 3. 导航位置

### 层级关系

```
Main Game (root)
├── CanvasLayer: HUD [Z-index: 100-160]
│   └── 小地图(左上) / M键提示 ← 点击/按键触发
│
└── CanvasLayer: World Map Overlay [Z-index: 220]
    ├── 全屏半透明遮罩 (游戏暂停，背景模糊)
    ├── 大地图主面板 (全屏)
    │   ├── Tab 导航栏 (地图/传送/探索度)
    │   ├── 内容区域
    │   └── 底部操作提示
    └── 区域详情弹出面板
```

### 层级规则

- **Z-index**: HUD=100-160, Tooltip=200, 大地图=220, 设置面板=250, 暂停菜单=260, 奇遇面板=300, 确认对话框=400, 剧情对话框=500, 加载界面=600（参见 hud.md §5.3 Z-index分层）
- **模态性质**：全屏模态 — 打开时**游戏完全暂停**
- **遮罩效果**：全屏半透明遮罩（黑色60% opacity），背景游戏画面高斯模糊
- **互斥性**：与暂停菜单、设置面板、角色面板等互斥，同一时间只能打开一个
- **面板内导航**：三个Tab页签——地图(默认)/传送/探索度

## 4. 入口与出口

### 入口

| 入口来源 | 触发器 | 默认Tab |
|---------|--------|---------|
| HUD快捷键 | 键盘M键 | 地图Tab |
| HUD大地图按钮 | 鼠标点击 | 地图Tab |
| 小地图双击 | 鼠标双击小地图 | 地图Tab，自动缩放至当前区域 |
| 任务追踪跳转 | 点击任务项的"查看大地图" | 地图Tab，自动定位到任务目标 |
| 获得传送点提示 | 点击系统提示中的"打开大地图" | 传送Tab，高亮新传送点 |

### 出口

| 出口去向 | 触发器 | 状态变化 |
|---------|--------|----------|
| 游戏场景（正常关闭） | 按M键/Escape/点击关闭按钮 | 无，面板关闭，游戏恢复 |
| 游戏场景（确认旅行后） | 在传送Tab选择目的地并确认 | 开始旅行（加载目标区域） |
| 暂停菜单 | 点击暂停菜单按钮 | 切换到暂停菜单 |

## 6. 状态与变体

| 状态 | 触发条件 | 变化说明 |
|------|---------|---------|
| **默认** | 首次打开大地图 | 地图Tab激活，当前区域居中，迷雾遮盖未探索区域 |
| **首次打开** | 游戏后第一次按M | 播放引导提示（2秒，可跳过） |
| **无活跃任务** | 当前无追踪任务 | 不显示任务目标标记 |
| **境界不足** | 尝试传送到更高境界区域 | 传送按钮灰色禁用 |
| **灵石不足** | 灵石不足以支付旅行费用 | 传送按钮灰色禁用 |
| **新区域解锁** | 首次进入未探索区域后打开 | 迷雾散开，播放"区域解锁"动画 |
| **全部探索完成** | 某区域探索度100% | 进度条变为金色，显示"已完全探索" |

## 7. 交互映射

## 9. 过渡与动画

| 动画 | 时长 | 缓动 |
|------|------|------|
| 面板展开 | 350ms | ease_out_cubic |
| 面板收起 | 250ms | ease_in_cubic |
| Tab切换 | 200ms | crossfade |
| 地图缩放 | 200ms | ease_out_cubic |
| 迷雾散开 | 800ms | 水墨晕染 |
| 区域解锁 | 600ms | 发光 + 微震动 |
| 旅行过渡 | 1000-2000ms | 水墨流动 |

### 减少运动

启用时：面板直接显示/隐藏，无缩放动画；Tab切换直接替换；迷雾直接移除。

## 10. 数据需求

| 数据 | 来源系统 | 读/写 | 说明 |
|------|----------|-------|------|
| 区域列表 | WorldMapData | Read | 名称、边界、境界需求、危险等级 |
| 传送点列表 | TravelSystem | Read | 名称、坐标、所属区域、解锁状态 |
| 旅行费用 | TravelConfig | Read | 区域间灵石消耗表 |
| 探索进度 | ExplorationSystem | Read | 每区域完成百分比 |
| 玩家境界 | PlayerData | Read | 判断是否可传送 |
| 灵石余额 | EconomyManager | Read | 判断是否支付得起 |
| 当前位置 | WorldState | Read | 标记玩家位置 |
| 活跃任务 | QuestSystem | Read | 显示任务目标标记 |

> **架构注意**: 大地图打开时读取快照数据，关闭时不写入。旅行确认后调用TravelSystem的`travel_to()`方法。

## 11. 可访问性

### 键盘导航
- Tab键在Tab栏和内容区元素间循环导航
- 方向键↑↓在列表中移动，←→在地图上平移
- Enter确认，ESC/M关闭

### 手柄导航
- 左摇杆平移地图，LB/RB缩放
- 十字键/A在标记和列表间导航
- B关闭

### 视觉无障碍
- 所有标记使用独特图标形状 + 文字标签，不依赖颜色唯一信息
- 文字对比度WCAG AA级
- 色盲模式下传送点使用"传送门"形状识别

### 文字缩放
- 支持100%-175%四档缩放
- 最小可读文字：区域名称16pt，正文14pt

## 13. 验收标准

### 性能
- [ ] 面板从按键触发到完全显示不超过500ms
- [ ] Tab切换响应不超过50ms
- [ ] 地图平移和缩放保持60FPS
- [ ] 面板打开期间游戏完全暂停
- [ ] 面板内存占用不超过80MB

### 功能
- [ ] M键可打开/关闭大地图
- [ ] 双击小地图可打开大地图，自动缩放至当前区域
- [ ] 三个Tab可正常切换
- [ ] 地图支持3级缩放
- [ ] 已发现的传送点可点击，弹出旅行信息
- [ ] 传送按钮在境界/灵石不足时正确禁用
- [ ] 确认旅行后正确加载目标区域
- [ ] 探索度Tab显示总体进度和各区域分解
- [ ] 迷雾正确遮盖未探索区域
- [ ] 与暂停菜单互斥

### 可访问性
- [ ] 键盘/手柄可到达所有交互元素
- [ ] 文字对比度WCAG AA
- [ ] 色盲模式下标记可通过形状区分
- [ ] 175%缩放下无截断

## 14. 待解决问题

1. **地图纹理生成方式** — 手绘纹理还是Shader实时渲染？需与美术总监确认
2. **旅行机制** — 瞬间加载还是过场动画？加载时间>2秒时需要Loading界面
3. **迷雾揭示粒度** — 按区域级别还是按子区域/网格逐步揭示？
4. **传送费用经济** — 按距离定价还是固定定价？需与经济系统GDD对齐
5. **探索度计算权重** — 仙缘/NPC/隐藏要素/传送点/挑战各占多少权重？
6. **地图缩放锚点** — 以鼠标光标位置还是屏幕中心为锚点？
7. **多任务标记** — 3+个活跃任务时是否需要筛选/优先级？
8. **纹理内存预算** — 高分辨率水墨纹理在8GB内存上限下是否可接受？是否需要LOD纹理系统（远观用低分辨率、近看用高分辨率）？
