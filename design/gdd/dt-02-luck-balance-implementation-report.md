### 2. ✅ 修改奇遇触发概率公式

**修改位置**: 第112-125行

**修改前**:
```markdown
### 奇遇触发概率公式

`奇遇触发概率 = 基础概率 × (1 + 福缘属性/100)`

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 基础概率 | base_probability | float | 0.01-0.05 | 不同奇遇类型的基础触发概率（1%-5%） |
| 福缘属性 | luck_stat | int | 0-100 | 玩家的福缘属性值 |
| 奇遇触发概率 | encounter_probability | float | 0.01-0.1 | 最终的奇遇触发概率（上限10%） |

**输出范围:** 0.01到0.1
**示例:** 当基础概率为0.03（3%），福缘属性为50时，奇遇触发概率 = 0.03 × (1 + 50/100) = 0.03 × 1.5 = 0.045（4.5%）
```

**修改后**:
```markdown
### 奇遇触发概率公式（修订版 - DT-02平衡调整）

`奇遇触发概率 = 基础概率 × (1 + 福缘加成系数)`

**福缘加成系数计算**（软上限机制）：
```
if 福缘 <= 100:
    福缘加成系数 = 福缘 / 100
else:
    福缘加成系数 = 1.0 + (福缘 - 100) / 300
```

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 基础概率 | base_probability | float | 0.01-0.05 | 不同奇遇类型的基础触发概率（1%-5%） |
| 福缘属性 | luck_stat | int | 0-495 | 玩家的福缘属性值 |
| 福缘加成系数 | luck_bonus_coefficient | float | 0.0-2.32 | 计算得出的福缘加成系数（100点后递减） |
| 奇遇触发概率 | encounter_probability | float | 0.01-0.15 | 最终的奇遇触发概率（上限15%） |

**输出范围:** 0.01到0.15

**示例计算:**
- 福缘50点：加成系数 = 50/100 = 0.5，触发概率 = 0.03 × (1 + 0.5) = 0.045 (4.5%)
- 福缘100点：加成系数 = 100/100 = 1.0，触发概率 = 0.03 × (1 + 1.0) = 0.06 (6%)
- 福缘200点：加成系数 = 1.0 + 100/300 = 1.33，触发概率 = 0.03 × (1 + 1.33) = 0.07 (7%)
- 福缘495点：加成系数 = 1.0 + 395/300 = 2.32，触发概率 = 0.03 × (1 + 2.32) = 0.10 (10%)

**设计说明**：
- 100点前：每点福缘提供0.3%触发概率加成（线性增长）
- 100点后：每点福缘提供0.1%触发概率加成（边际收益递减）
- 这种软上限机制鼓励玩家平衡Build，避免极端投资福缘
```

**关键发现**：

- ✅ 200点以上：显著降低，抑制极端Build

## 预期效果

### 1. Build多样性提升

**修改前**：
- 极端福缘Build（495点福缘）：17.85%触发率，可能成为主导策略
- 平衡Build（165点福缘）：7.95%触发率
- 纯战斗Build（0点福缘）：3%触发率

**修改后**：
- 极端福缘Build（495点福缘）：10%触发率，不再过强
- 平衡Build（165点福缘）：7.0%触发率，仍然有竞争力
- 纯战斗Build（0点福缘）：3%触发率，专注战斗效率

**结论**：极端福缘Build的优势从17.85% vs 3% (5.95倍) 降低到10% vs 3% (3.33倍)，更加平衡。

---

### 2. 玩家投资建议

**最优投资区间**：50-150点福缘
- 50点：4.5%触发率，性价比高
- 100点：6.0%触发率，达到软上限前的最大收益
- 150点：6.5%触发率，仍然有不错的收益

**不推荐投资**：200点以上福缘
- 200点：7.0%触发率，边际收益已经很低
- 495点：10.0%触发率，投入产出比极低

### 1. ⏳ 奇遇奖励上限（需要修改 encounter-system.md）

**建议添加**：
```markdown
### 奇遇奖励上限

为了保持游戏平衡，奇遇奖励受到以下限制：

1. **属性点奖励**：
   - 单次奇遇最多奖励2-3个属性点
   - 每个境界最多通过奇遇获得10个额外属性点
   - 系统会追踪玩家在当前境界通过奇遇获得的属性点总数

2. **武学奖励**：
   - 奇遇只能获得"武学残页"（需要3-5个残页合成完整武学）
   - 稀有武学（紫色/金色）必须通过主线任务或Boss战获得

3. **装备奖励**：
   - 奇遇最多获得"蓝色"品质装备
   - "紫色"和"金色"装备必须通过战斗获得
```
