# 角色关系系统 (Character Relationship System)

> **Status**: In Design
> **Author**: 系统设计师 + AI助手
> **Last Updated**: 2026-05-02
> **Implements Pillar**: 自由探索与发现、仙缘驱动的成长
> **Creative Director Review (CD-GDD-ALIGN)**: Pending

## Overview

角色关系系统是《武侠奇遇录》的核心社交机制，追踪玩家与所有NPC的关系状态、道心倾向和解锁内容。该系统通过关系值、道心值和关系等级，影响对话选项、任务可用性、剧情分支和最终结局。

**技术层面**：关系系统基于数值化的关系值（-100到+100）和道心值（-100到+100），每个NPC维护独立的关系数据。系统从角色关系数据库读取和写入数据，通过关系值计算系统处理数值变化和等级判定，并通过关系事件触发系统在达到特定阈值时触发专属剧情。

**玩家体验层面**：玩家的每个行为都会影响与NPC的关系和自己的道心倾向。帮助正道NPC会提升关系值和道心值，而选择魔道路线则会降低道心值并改变NPC态度。关系值达到特定阈值会解锁专属对话、任务、技能传授和恋爱剧情。

**修真特色**：关系系统深度整合修真世界观，道心值决定玩家的正魔倾向，影响可修炼的功法类型和NPC态度。正道NPC对高道心值玩家更友好，魔道NPC则相反。系统支持7种关系等级和4种最终结局类型，确保玩家的选择真正影响游戏走向。

## Player Fantasy

**核心幻想：在修真世界中建立深厚的人际关系，用真诚和选择赢得他人的信任与爱**

当玩家与NPC互动时，他们不仅仅是在完成任务——他们在建立真实的人际关系。每一次帮助、每一个承诺、每一次对话选择，都在塑造玩家在修真世界中的社交网络和道德立场。

**玩家应该感受到**：

1. **关系的成长**：从陌生人到朋友，从朋友到挚友，甚至到恋人。玩家能清晰感受到关系的每一步进展，每次见面都有新的对话，每个阈值都解锁新的内容。当柳如烟从冷淡的"这位道友"变成亲密的"你"，玩家知道自己的努力得到了回报。

2. **道心的抉择**：每个选择都在塑造玩家的修真之路。选择正道意味着获得名门正派的认可，但也意味着与魔道势力为敌。选择魔道则能获得禁忌功法，但会失去正道NPC的信任。没有"正确答案"，只有"我的道路"。

3. **关系的代价**：背叛一个NPC的信任会带来真实的后果。如果玩家答应帮助云中鹤却违背承诺，关系值会大幅下降，甚至可能永久失去他的信任。玩家必须谨慎对待每一个承诺。

4. **专属内容的解锁**：当关系值达到80时，柳如烟会向玩家敞开心扉，讲述她的家族秘密，并传授独门剑法。这种"只有我能看到"的专属内容让玩家感到特别和被重视。

**参考体验**：
- 《女神异闻录5》中的Confidant系统——关系等级解锁能力和剧情
- 《火焰纹章：风花雪月》中的支援对话——关系影响战斗和结局
- 《星露谷物语》中的好感度系统——送礼、对话、事件解锁

**反面案例**（我们要避免的）：
- ❌ 关系值只是数字，没有实际影响
- ❌ 所有NPC用相同的方式提升好感（送礼刷好感）
- ❌ 关系等级提升后没有新内容

## Detailed Design

### Core Rules

#### 1. 关系值机制

**关系值范围**：-100（仇敌）到 +100（挚友/恋人）

**关系等级划分**：
| 关系值范围 | 等级名称 | 描述 | 解锁内容 |
|-----------|---------|------|----------|
| -100 到 -50 | 仇敌 | 敌对对话，可能触发战斗 | 无 |
| -49 到 -10 | 冷淡 | 拒绝帮助，对话简短 | 无 |
| -9 到 +9 | 中立 | 普通对话，基础交易 | 基础对话、基础交易 |
| +10 到 +49 | 友好 | 额外对话选项，小幅折扣 | 额外对话、商店折扣10% |
| +50 到 +79 | 亲密 | 支线任务解锁，特殊奖励 | 支线任务、背景故事、特殊训练 |
| +80 到 +100 | 挚友/恋人 | 专属剧情，最佳结局条件 | 专属剧情、技能传授、恋爱线（部分角色）、最终战协助 |

**关系值变化来源**：
1. **对话选择**：±5 到 ±20（根据选择重要性）
2. **任务完成**：+10 到 +30（根据任务难度）
3. **礼物赠送**：+5 到 +15（根据物品喜好度）
4. **战斗协助**：+10 到 +20（保护NPC或并肩作战）
5. **背叛行为**：-30 到 -50（违背承诺、攻击NPC）
6. **时间衰减**：-1/游戏周（长期不互动，仅限友好以上等级）

#### 2. 道心值机制

**道心值范围**：-100（纯魔道）到 +100（纯正道）

**道心等级划分**：
| 道心值范围 | 等级名称 | 描述 | 影响 |
|-----------|---------|------|------|
| -100 到 -60 | 魔道宗师 | 纯粹的魔道修士 | 只能修炼魔道功法，正道NPC敌视，魔道NPC崇拜 |
| -59 到 -30 | 魔道倾向 | 偏向魔道 | 魔道功法加成，正道NPC冷淡，魔道NPC友好 |
| -29 到 +29 | 中立 | 正魔不分 | 可修炼所有功法，NPC态度中立 |
| +30 到 +59 | 正道倾向 | 偏向正道 | 正道功法加成，正道NPC友好，魔道NPC冷淡 |
| +60 到 +100 | 正道宗师 | 纯粹的正道修士 | 只能修炼正道功法，正道NPC崇拜，魔道NPC敌视 |

**道心值变化来源**：
1. **对话选择**：±5 到 ±20（正义/邪恶选择）
2. **任务选择**：±10 到 ±30（帮助弱者/欺压弱者）
3. **战斗行为**：±20（击杀无辜/-20，保护无辜/+20）
4. **功法修炼**：±1/天（修炼正道功法/+1，魔道功法/-1）
5. **物品使用**：±5 到 ±15（使用邪恶物品/-10，正义物品/+10）

**道心值对功法的影响**：
```gdscript
# 功法修炼条件检查
func can_learn_skill(skill_id: String, dao_heart: int) -> bool:
    var skill_data = MartialArtsDatabase.get_skill(skill_id)
    var alignment = skill_data.alignment  # "righteous", "evil", "neutral"
    
    if alignment == "righteous" and dao_heart < 0:
        return false  # 魔道修士无法修炼正道功法
    elif alignment == "evil" and dao_heart > 0:
        return false  # 正道修士无法修炼魔道功法
    
    return true
```

#### 3. 关系事件触发规则

**触发条件**：
- 关系值达到特定阈值（10, 30, 50, 70, 80, 90）
- 主线剧情进度达到要求
- 特定时间或地点
- 玩家境界达到要求

**事件类型**：
1. **对话事件**：NPC主动找玩家对话，揭示背景故事
2. **任务事件**：解锁专属支线任务
3. **剧情事件**：触发专属剧情过场
4. **战斗事件**：NPC协助玩家战斗或传授技能
5. **恋爱事件**：特定NPC的恋爱剧情（关系值≥80）

**事件触发流程**：
```
1. 检查关系值是否达到阈值
2. 检查主线进度是否满足
3. 检查是否已触发过该事件
4. 检查其他条件（时间、地点、境界）
5. 如果所有条件满足，触发事件
6. 标记事件为已触发
```

#### 4. 礼物系统规则

**礼物喜好度**：
每个NPC有独特的礼物喜好列表：
- **最爱**（+15关系值）：1-2种物品
- **喜欢**（+10关系值）：3-5种物品
- **普通**（+5关系值）：所有其他物品
- **讨厌**（-5关系值）：1-2种物品

**礼物赠送限制**：
- 每个NPC每游戏日最多接受1个礼物
- 同一物品连续赠送3次后，喜好度降低50%
- 生日当天赠送礼物，效果翻倍

**示例礼物喜好**：
```json
{
  "yunzhonghe": {
    "loves": ["ancient_sword", "sword_manual"],
    "likes": ["tea", "calligraphy", "wine"],
    "dislikes": ["cheap_jewelry"]
  },
  "liuruyan": {
    "loves": ["jade_pendant", "poetry_book"],
    "likes": ["flowers", "silk", "perfume"],
    "dislikes": ["weapon", "alcohol"]
  }
}
```

#### 5. 结局判定规则

**结局类型**：
1. **正道领袖结局**
   - 道心值 ≥ 60
   - 柳如烟关系值 ≥ 70
   - 玄机真人关系值 ≥ 50
   - 完成正道主线

2. **魔道霸主结局**
   - 道心值 ≤ -60
   - 萧寒夜关系值 ≥ 70
   - 血无痕关系值 ≥ 30（或击败他）
   - 完成魔道主线

3. **隐世大能结局**
   - 道心值 -30 到 +30
   - 慕容雪关系值 ≥ 80
   - 玄机真人关系值 ≥ 60
   - 完成隐世主线

4. **逍遥散仙结局**
   - 所有核心NPC关系值 ≥ 50
   - 道心值 -20 到 +20
   - 拒绝所有阵营邀请

**结局判定优先级**：
1. 隐世大能结局（最高优先级，条件最严格）
2. 逍遥散仙结局
3. 正道领袖结局
4. 魔道霸主结局
5. 默认结局（条件都不满足）

### States and Transitions

关系系统的状态主要体现在关系等级的转换：

| 当前等级 | 触发条件 | 转换到 | 效果 |
|---------|---------|--------|------|
| 中立 | 关系值 ≥ 10 | 友好 | 解锁额外对话、商店折扣 |
| 友好 | 关系值 ≥ 50 | 亲密 | 解锁支线任务、背景故事 |
| 亲密 | 关系值 ≥ 80 | 挚友/恋人 | 解锁专属剧情、技能传授 |
| 友好 | 关系值 < 10 | 中立 | 失去额外对话和折扣 |
| 亲密 | 关系值 < 50 | 友好 | 失去支线任务访问权 |
| 挚友 | 关系值 < 80 | 亲密 | 失去专属剧情访问权 |
| 中立 | 关系值 ≤ -10 | 冷淡 | NPC拒绝交互 |
| 冷淡 | 关系值 ≤ -50 | 仇敌 | NPC可能主动攻击 |

**状态转换事件**：
- 每次关系等级提升时，触发等级提升事件
- 显示UI通知："与[NPC名称]的关系提升至[等级名称]"
- 播放音效和视觉效果
- 解锁对应等级的内容

### Interactions with Other Systems

#### 1. 角色关系数据库（上游依赖）
- **接口**：`get_relationship(npc_id: String) -> int`, `set_relationship(npc_id: String, value: int)`
- **数据流向**：双向（读取和写入）
- **职责边界**：数据库负责存储，关系系统负责逻辑

#### 2. 对话系统（双向依赖）
- **接口**：`modify_relationship(npc_id: String, delta: int)`, `modify_dao_heart(delta: int)`
- **数据流向**：双向（对话读取关系值，对话选择修改关系值）
- **职责边界**：对话系统触发变化，关系系统计算和存储

#### 3. 任务系统（双向依赖）
- **接口**：`unlock_quest(quest_id: String)`, `get_relationship_level(npc_id: String) -> String`
- **数据流向**：双向（关系等级解锁任务，任务完成提升关系）
- **职责边界**：关系系统控制任务可用性，任务系统管理任务逻辑

#### 4. 武学系统（单向依赖）
- **接口**：`can_learn_skill(skill_id: String) -> bool`
- **数据流向**：关系系统 → 武学系统
- **职责边界**：关系系统（道心值）决定功法可学性

#### 5. 战斗系统（单向依赖）
- **接口**：`get_npc_attitude(npc_id: String) -> String`
- **数据流向**：关系系统 → 战斗系统
- **职责边界**：关系系统决定NPC是否敌对

#### 6. 世界状态持久化（上游依赖）
- **接口**：`save_relationships()`, `load_relationships()`
- **数据流向**：双向（保存和加载）
- **职责边界**：关系系统提供数据，持久化系统负责存储

## Formulas

### 关系值变化计算

```
final_relationship = clamp(current_relationship + delta * multiplier, -100, 100)
```

**变量**：
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| current_relationship | CR | int | -100 to 100 | 当前关系值 |
| delta | Δ | int | -50 to +30 | 关系值变化量 |
| multiplier | M | float | 0.5 to 2.0 | 全局倍率（可调节） |
| final_relationship | FR | int | -100 to 100 | 最终关系值 |

**输出范围**：-100 到 +100

**示例**：
- 当前关系 = 45，任务完成 = +20，倍率 = 1.0 → 最终关系 = 65
- 当前关系 = 95，礼物赠送 = +10，倍率 = 1.0 → 最终关系 = 100（截断）
- 当前关系 = 30，背叛行为 = -40，倍率 = 1.0 → 最终关系 = -10

### 道心值变化计算

```
final_dao_heart = clamp(current_dao_heart + delta * multiplier, -100, 100)
```

**变量**：
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| current_dao_heart | DH | int | -100 to 100 | 当前道心值 |
| delta | Δ | int | -30 to +30 | 道心值变化量 |
| multiplier | M | float | 0.5 to 2.0 | 全局倍率（可调节） |
| final_dao_heart | FDH | int | -100 to 100 | 最终道心值 |

**输出范围**：-100（纯魔道）到 +100（纯正道）

### 礼物喜好度计算

```
relationship_gain = base_value * freshness_factor * birthday_bonus
```

**变量**：
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| base_value | BV | int | -5 to +15 | 基础喜好度值 |
| freshness_factor | FF | float | 0.5 to 1.0 | 新鲜度系数（重复赠送降低） |
| birthday_bonus | BB | float | 1.0 or 2.0 | 生日加成（生日当天×2） |
| relationship_gain | RG | int | -10 to +30 | 最终关系值增加 |

**新鲜度系数计算**：
```
freshness_factor = max(0.5, 1.0 - (consecutive_gifts * 0.17))
```
- 第1次赠送：1.0
- 第2次赠送：0.83
- 第3次赠送：0.5（最低值）

### 关系等级判定

```
relationship_level = get_level_by_value(relationship_value)
```

**判定规则**：
```gdscript
func get_relationship_level(value: int) -> String:
    if value >= 80:
        return "intimate_max"  # 挚友/恋人
    elif value >= 50:
        return "intimate"      # 亲密
    elif value >= 10:
        return "friendly"      # 友好
    elif value >= -9:
        return "neutral"       # 中立
    elif value >= -49:
        return "cold"          # 冷淡
    else:
        return "hostile"       # 仇敌
```

### NPC态度修正

```
attitude_modifier = base_attitude + dao_heart_influence
```

**变量**：
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| base_attitude | BA | int | -100 to 100 | 基础关系值 |
| dao_heart_influence | DHI | int | -30 to +30 | 道心值影响 |
| attitude_modifier | AM | int | -130 to 130 | 最终态度值 |

**道心值影响计算**：
```gdscript
func calculate_dao_heart_influence(npc_alignment: String, player_dao_heart: int) -> int:
    if npc_alignment == "righteous":
        return int(player_dao_heart * 0.3)  # 正道NPC喜欢高道心玩家
    elif npc_alignment == "evil":
        return int(-player_dao_heart * 0.3)  # 魔道NPC喜欢低道心玩家
    else:
        return 0  # 中立NPC不受道心影响
```

**示例**：
- 正道NPC，基础关系 = 50，玩家道心 = 60 → 态度 = 50 + 18 = 68
- 魔道NPC，基础关系 = 30，玩家道心 = 60 → 态度 = 30 - 18 = 12
- 中立NPC，基础关系 = 40，玩家道心 = 60 → 态度 = 40 + 0 = 40

## Edge Cases

### 1. 关系值超出范围
**条件**：计算后的值 < -100 或 > 100
**处理**：使用clamp函数截断到[-100, 100]，记录日志

### 2. 道心值极端转换
**条件**：玩家从+100道心突然降到-100（或相反）
**处理**：
- 触发"道心剧变"事件
- 所有NPC重新评估态度
- 显示警告："你的道心发生了剧变，江湖对你的看法已改变"

### 3. 关系等级降级
**条件**：关系值从80降到49（挚友→友好）
**处理**：
- 锁定专属内容访问权
- 显示通知："与[NPC]的关系降低至[等级]"
- NPC对话变化，表达失望

### 4. 同时达到多个结局条件
**条件**：玩家同时满足多个结局的条件
**处理**：按优先级选择结局（隐世 > 逍遥 > 正道 > 魔道）

### 5. NPC死亡后的关系
**条件**：NPC在剧情中死亡
**处理**：
- 关系值冻结，不再变化
- 标记为"已故"
- 保留关系值用于结局判定

### 6. 礼物库存不足
**条件**：玩家尝试赠送不存在的物品
**处理**：
- 检查物品库存
- 如果不足，显示错误："你没有这个物品"
- 不扣除物品，不改变关系值

### 7. 关系事件重复触发
**条件**：由于bug导致同一事件可能触发多次
**处理**：
- 维护已触发事件列表
- 检查事件ID是否已存在
- 如果已触发，跳过事件

### 8. 道心值影响功法修炼中
**条件**：玩家正在修炼正道功法，但道心值降到负数
**处理**：
- 立即中断功法修炼
- 显示警告："你的道心已偏向魔道，无法继续修炼正道功法"
- 功法进度保留，但无法继续提升

### 9. 时间衰减导致关系降级
**条件**：长期不与NPC互动，关系值因衰减降级
**处理**：
- 每游戏周检查一次
- 仅对友好以上等级生效
- 显示提示："你已很久没有见过[NPC]了"

### 10. 结局判定时关系值不足
**条件**：玩家到达结局判定点，但所有结局条件都不满足
**处理**：
- 触发默认结局
- 显示结局说明："你在江湖中留下了自己的足迹，但未能成就一番大业"

## Dependencies

### 上游依赖（Hard Dependencies）

#### 1. 角色关系数据库
- **类型**：数据层，基础设施
- **接口**：`get_relationship()`, `set_relationship()`, `get_dao_heart()`, `set_dao_heart()`
- **依赖原因**：关系系统必须从数据库读写关系数据
- **失败影响**：无法存储关系值，系统完全不可用

#### 2. 世界状态持久化
- **类型**：技术层，基础设施
- **接口**：`save_relationships()`, `load_relationships()`
- **依赖原因**：保存和加载关系数据
- **失败影响**：关系进度无法保存，每次重启游戏都重置

### 双向依赖

#### 3. 对话系统
- **类型**：游戏机制层
- **接口**：`modify_relationship()`, `modify_dao_heart()`, `get_relationship()`
- **依赖原因**：对话选择修改关系值，关系值影响对话选项
- **失败影响**：对话选择无法影响关系，关系值无法通过对话提升

#### 4. 任务系统
- **类型**：游戏机制层
- **接口**：`unlock_quest()`, `get_relationship_level()`
- **依赖原因**：关系等级解锁任务，任务完成提升关系
- **失败影响**：无法通过关系解锁任务，任务无法提升关系

### 单向依赖（关系系统影响其他系统）

#### 5. 武学系统
- **类型**：游戏机制层
- **接口**：`can_learn_skill()`
- **依赖原因**：道心值决定可修炼的功法类型
- **失败影响**：所有功法都可修炼，失去正魔限制

#### 6. 战斗系统
- **类型**：游戏机制层
- **接口**：`get_npc_attitude()`
- **依赖原因**：关系值决定NPC是否敌对
- **失败影响**：所有NPC态度中立，失去敌对机制

#### 7. 商店系统
- **类型**：游戏机制层
- **接口**：`get_discount_rate()`
- **依赖原因**：关系等级影响商店折扣
- **失败影响**：无折扣，失去关系奖励

## Tuning Knobs

### 1. 关系值变化倍率
- **参数名**：`relationship_change_multiplier`
- **类型**：float
- **默认值**：1.0
- **安全范围**：0.5 - 2.0
- **影响**：所有关系值变化的全局倍率
- **极端行为**：
  - <0.5：关系增长过慢，玩家难以建立关系
  - >2.0：关系增长过快，失去成就感

### 2. 道心值变化倍率
- **参数名**：`dao_heart_change_multiplier`
- **类型**：float
- **默认值**：1.0
- **安全范围**：0.5 - 2.0
- **影响**：所有道心值变化的全局倍率
- **极端行为**：
  - <0.5：道心变化过慢，玩家难以转变阵营
  - >2.0：道心变化过快，玩家容易误入极端

### 3. 时间衰减速率
- **参数名**：`relationship_decay_rate`
- **类型**：int
- **默认值**：-1（每游戏周）
- **安全范围**：-5 to 0
- **影响**：长期不互动时关系值的衰减速度
- **极端行为**：
  - 0：无衰减，关系永久保持
  - <-5：衰减过快，玩家难以维持多个关系

### 4. 礼物新鲜度衰减
- **参数名**：`gift_freshness_decay`
- **类型**：float
- **默认值**：0.17（每次重复-17%）
- **安全范围**：0.1 - 0.3
- **影响**：重复赠送同一礼物的效果衰减
- **极端行为**：
  - <0.1：衰减过慢，玩家可刷礼物
  - >0.3：衰减过快，礼物失去价值

### 5. 道心值对NPC态度的影响系数
- **参数名**：`dao_heart_attitude_factor`
- **类型**：float
- **默认值**：0.3
- **安全范围**：0.1 - 0.5
- **影响**：道心值对NPC态度的影响程度
- **极端行为**：
  - <0.1：道心影响过小，正魔选择无意义
  - >0.5：道心影响过大，难以与对立阵营NPC交流

### 6. 关系等级阈值调整
- **参数名**：`relationship_thresholds`
- **类型**：Dictionary
- **默认值**：`{"friendly": 10, "intimate": 50, "intimate_max": 80}`
- **安全范围**：friendly(5-20), intimate(30-70), intimate_max(60-90)
- **影响**：达到各关系等级所需的关系值
- **极端行为**：
  - 阈值过低：内容解锁过快，失去挑战
  - 阈值过高：内容解锁过慢，玩家挫败

### 7. 生日礼物加成
- **参数名**：`birthday_gift_bonus`
- **类型**：float
- **默认值**：2.0（翻倍）
- **安全范围**：1.5 - 3.0
- **影响**：生日当天赠送礼物的效果倍率
- **极端行为**：
  - <1.5：生日加成过小，失去特殊感
  - >3.0：生日加成过大，玩家只在生日送礼

### 8. 背叛惩罚倍率
- **参数名**：`betrayal_penalty_multiplier`
- **类型**：float
- **默认值**：1.5
- **安全范围**：1.0 - 2.5
- **影响**：背叛行为的关系值惩罚倍率
- **极端行为**：
  - <1.0：背叛无惩罚，失去道德约束
  - >2.5：背叛惩罚过重，玩家不敢尝试

### 9. 每日礼物限制
- **参数名**：`daily_gift_limit`
- **类型**：int
- **默认值**：1
- **安全范围**：1 - 3
- **影响**：每个NPC每游戏日可接受的礼物数量
- **极端行为**：
  - 1：限制严格，关系增长慢
  - >3：限制宽松，玩家可刷礼物

### 10. 结局判定宽容度
- **参数名**：`ending_threshold_tolerance`
- **类型**：int
- **默认值**：0
- **安全范围**：0 - 10
- **影响**：结局条件的宽容度（降低阈值要求）
- **极端行为**：
  - 0：严格判定，难以达成特定结局
  - >10：宽松判定，容易达成所有结局

## Acceptance Criteria

### 核心功能验收

#### AC-1: 关系值修改
**GIVEN** 玩家完成对话选择，**WHEN** 选择包含relationship_change效果，**THEN** 关系值正确更新，值被截断到[-100, 100]

#### AC-2: 关系等级判定
**GIVEN** 关系值达到阈值，**WHEN** 系统检查等级，**THEN** 正确判定关系等级，触发等级提升事件

#### AC-3: 道心值修改
**GIVEN** 玩家做出正义/邪恶选择，**WHEN** 选择包含dao_heart_change效果，**THEN** 道心值正确更新

#### AC-4: 功法修炼限制
**GIVEN** 玩家尝试修炼功法，**WHEN** 检查道心值，**THEN** 正确判断是否可修炼（正道功法需道心>0，魔道功法需道心<0）

#### AC-5: 礼物赠送
**GIVEN** 玩家赠送礼物给NPC，**WHEN** 检查礼物喜好度，**THEN** 根据喜好度正确增加关系值

#### AC-6: 关系事件触发
**GIVEN** 关系值达到阈值，**WHEN** 满足所有触发条件，**THEN** 触发专属关系事件，标记为已触发

#### AC-7: NPC态度计算
**GIVEN** 玩家与NPC互动，**WHEN** 计算NPC态度，**THEN** 正确应用道心值影响（正道NPC喜欢高道心，魔道NPC喜欢低道心）

#### AC-8: 结局判定
**GIVEN** 游戏到达结局判定点，**WHEN** 检查所有结局条件，**THEN** 按优先级选择正确的结局

#### AC-9: 时间衰减
**GIVEN** 玩家长期不与NPC互动，**WHEN** 每游戏周检查，**THEN** 友好以上等级的关系值衰减-1

#### AC-10: 关系UI显示
**GIVEN** 玩家打开关系面板，**WHEN** 显示UI，**THEN** 正确显示所有NPC的关系值、等级和解锁内容

### 边缘情况验收

#### AC-11: 关系值超出范围
**GIVEN** 计算后的关系值>100或<-100，**WHEN** 应用变化，**THEN** 值被截断到[-100, 100]，记录日志

#### AC-12: 道心极端转换
**GIVEN** 道心值从+100降到-100，**WHEN** 应用变化，**THEN** 触发"道心剧变"事件，所有NPC重新评估态度

#### AC-13: 关系等级降级
**GIVEN** 关系值从80降到49，**WHEN** 检查等级，**THEN** 等级降为友好，锁定专属内容，显示通知

#### AC-14: NPC死亡
**GIVEN** NPC在剧情中死亡，**WHEN** 尝试修改关系值，**THEN** 关系值冻结，标记为"已故"

#### AC-15: 礼物库存不足
**GIVEN** 玩家尝试赠送不存在的物品，**WHEN** 检查库存，**THEN** 显示错误，不扣除物品，不改变关系值

### 性能验收

#### AC-16: 关系计算性能
**GIVEN** 修改关系值，**WHEN** 计算新值和等级，**THEN** 计算时间<10ms

#### AC-17: UI刷新性能
**GIVEN** 关系值变化，**WHEN** 刷新UI，**THEN** UI刷新时间<50ms

### 集成验收

#### AC-18: 与对话系统集成
**GIVEN** 对话选择修改关系值，**WHEN** 对话结束，**THEN** 关系系统正确更新值，下次对话使用新值

#### AC-19: 与任务系统集成
**GIVEN** 关系等级达到阈值，**WHEN** 检查任务可用性，**THEN** 正确解锁专属任务

#### AC-20: 与武学系统集成
**GIVEN** 玩家尝试修炼功法，**WHEN** 检查道心值，**THEN** 正确限制功法修炼

## Open Questions

> **状态**：✅ 已解决（2026-05-02）
> **决策文档**：design/gdd/character-relationship-system-open-questions-resolution.md

所有开放问题已通过团队决策解决。以下为决策结果：

### 1. 关系值自然恢复 ✅ 已决策
**决策**：方案A - 仇敌等级不自然恢复，需要玩家主动修复
**决策日期**：2026-05-02
**决策者**：游戏设计师

**实现细节**：
- 关系值 ≥ -49（冷淡及以上）：允许自然恢复，速度为+1/游戏周
- 关系值 < -50（仇敌）：不自然恢复，必须通过特殊任务或事件修复
- 修复仇敌关系的方式：
  - 完成NPC的"赎罪任务"（特殊支线任务）
  - 赠送稀有礼物（价值 > 1000银两）
  - 通过第三方NPC调解（需要高关系值的共同好友）

### 2. 道心值锁定机制 ✅ 已决策
**决策**：方案A - 不锁定，但极端转换触发警告事件
**决策日期**：2026-05-02
**决策者**：叙事总监

**实现细节**：
- 道心值不锁定，玩家始终可以改变
- 当道心值发生极端转换时（从+60降到-60，或从-60升到+60），触发"道心剧变"事件
- "道心剧变"事件效果：
  - 所有NPC重新评估态度（正道NPC关系值-20，魔道NPC关系值+20，或相反）
  - 显示警告："你的道心发生了剧变，江湖对你的看法已改变"
  - 触发特殊对话，NPC质疑玩家的转变
  - 冷却期：30天内不能再次发生极端转换（防止反复横跳）

### 3. 多结局共存 ✅ 已决策
**决策**：方案A - 一周目只能达成一个结局，鼓励多周目
**决策日期**：2026-05-02
**决策者**：制作人

**实现细节**：
- 按优先级选择结局（现有设计保持不变）
- 结局达成后，显示"其他可能的结局"列表，鼓励重玩
- 提供"新游戏+"模式，继承部分进度（如天赋点、收集品）
- 结局成就系统：达成所有结局解锁特殊奖励

### 4. 关系值可视化程度 ✅ 已决策
**决策**：方案A - 显示等级和进度条，不显示精确数字
**决策日期**：2026-05-02
**决策者**：UX设计师

**实现细节**：
- 关系面板显示：
  - NPC名称和头像
  - 关系等级（友好、亲密、挚友等）
  - 进度条（显示到下一等级的进度，但不显示具体数字）
  - 下一等级的阈值（如"下一等级：挚友（需要80）"）
  - 解锁内容列表
- 悬停提示：显示模糊的进度描述（如"接近下一等级"、"还需要更多努力"）
- 设置选项：允许玩家在设置中开启"显示精确数字"（默认关闭）

### 5. NPC间关系影响 ✅ 已决策
**决策**：方案A - MVP阶段跳过，完整版本考虑
**决策日期**：2026-05-02
**决策者**：技术总监

**实现细节**：
- MVP阶段：每个NPC的关系值独立，不受其他NPC影响
- 完整版本（Phase 2）：
  - 实现简单的关系网络（A和B友好，B和C敌对，影响A和C的关系）
  - 影响规则：
    - 如果玩家与A的关系值 ≥ 50，且A与B是好友，则玩家与B的初始关系值+10
    - 如果玩家与A的关系值 ≥ 50，且A与B是敌人，则玩家与B的初始关系值-10
  - 仅影响初始关系值，不影响后续变化
  - 在对话中提及（如B说："听说你和A是好友，那你也是我的朋友"）
