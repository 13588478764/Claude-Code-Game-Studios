# 游戏概念文档：武侠奇遇录

## 核心身份

| 属性 | 描述 |
|------|------|
| **工作标题** | 武侠奇遇录 |
| **游戏类型** | 修真武侠RPG (Cultivation Wuxia RPG) |
| **电梯推销** | 一款视觉小说风格的修真武侠RPG，玩家在九州修真界中游历，通过仙缘奇遇获得强大的修真功法和法宝，从炼气初期修炼至渡劫期，最终成为一代修真传奇。 |
| **核心动词** | 探索、修炼、战斗 |
| **核心幻想** | 成为修真传奇，在广袤的九州修真界自由闯荡，突破境界，追寻飞升之谜 |
| **独特卖点** | 结合《最终幻想7重制版-重生》的挑战性玩法、《刺客信条：英灵殿》的开放世界探索和《如龙8》的多样化技能组合，融入深度的修真境界体系和仙缘机遇系统 |

| **目标平台** | Steam (PC) |

## 游戏支柱

### 支柱1：深度武学系统
**定义**：修真功法系统应有深度和多样性，体现修真境界体系  
**设计测试**：如果我们在设计新技能时，这个支柱会问："这个功法是否增加了武学系统的深度和多样性？是否符合修真境界设定？"  
**修真特色**：九大境界（炼气→筑基→金丹→元婴→化神→返虚→合道→大乘→渡劫），四大品阶（黄阶、玄阶、地阶、天阶）

### 支柱2：自由探索与发现
**定义**：玩家应能自由探索九州修真界并不断发现新内容  
**设计测试**：如果我们在设计关卡时，这个支柱会问："这个设计是否允许玩家自由探索并发现新内容？"  
**修真特色**：九大修真区域，每个区域有独特的灵气属性和修真传承

### 支柱3：仙缘驱动的成长
**定义**：玩家通过仙缘奇遇获得独特的修真功法、法宝和境界突破机会  
**设计测试**：如果我们在设计成长系统时，这个支柱会问："这种成长方式是否来自于有趣的仙缘经历？是否符合修真世界观？"  
**修真特色**：仙缘传承、秘境探索、道心考验、隐世大能指点

## 反面支柱（游戏不是什么）

### 不包含复杂经济系统
**原因**：复杂的交易、制造或经济模拟会分散对核心修真武侠体验的关注  
**设计测试**：当我们考虑添加经济系统时，反面支柱会提醒我们："这是否会偏离我们的核心修真体验？"

### 不包含强制多人在线
**原因**：单人修真体验更能体现修真者独自求道的感觉  
**设计测试**：当我们考虑多人功能时，反面支柱会问："这是否破坏了单人修真世界的沉浸感？"

## 乐趣假设 (Fun Hypothesis)

### 假设 1：选择塑造命运
**描述**：玩家在对话和奇遇中的选择会显著影响角色关系、道心倾向和可获得的功法传承，每次游玩都有不同的修真之路。
**验证方式**：Playtest 中观察玩家是否主动尝试不同选择、是否对选择结果表现出惊喜或遗憾。关键指标——至少 60% 的测试玩家表示"想重玩看看另一条路线"。

### 假设 2：探索即奖励
**描述**：每次点击"探索此区域"都有可能触发意想不到的奇遇、战斗或仙缘，这种不确定性驱动玩家持续探索。
**验证方式**：统计玩家平均每局连续探索次数。目标——玩家在单次游戏 session 中至少连续探索 10 次以上才主动停下。

### 假设 3：境界突破的成就感
**描述**：从炼气到渡劫的 10 大境界每次突破都应该让玩家感到明显的实力提升和叙事推进，形成"修炼—突破—更强—再修炼"的核心循环。
**验证方式**：Playtest 中记录玩家在突破时的反应。关键指标——突破后玩家立刻尝试之前打不过的敌人或区域。

### 假设 4：武学组合的策略深度
**描述**：装备不同武学组合 + 五行克制 + 连击/连携系统让战斗不是无脑点攻击，而是需要思考搭配。
**验证方式**：观察玩家是否在战斗中主动切换技能、是否利用五行克制。关键指标——玩家平均每场战斗使用 ≥2 种不同技能。

### 不包含快节奏的载具战斗
**原因**：避免偏离修真武侠主题，专注于御剑飞行、轻功和战斗  
**设计测试**：当我们考虑添加载具时，反面支柱会提醒我们："这是否符合修真世界的设定？"  
**修真特色**：修真者通过境界提升获得御剑飞行、瞬移等能力

## 核心循环设计

### 30秒循环（即时行动）
- **核心动作感受**：爽快有力的打击，强调打击感和力量感
- **战斗特点**：流畅的连击系统，配合华丽的特效和音效反馈
- **满足感来源**：每一次攻击都有明显的反馈，敌人受击时有强烈的物理反应

### 5分钟循环（短期目标）
- **主要活动**：击败特定敌人获得战利品和修炼资源
- **奖励机制**：通过战胜对手获得稀有修真功法、法宝或突破丹
- **循环结构**：遭遇敌人 → 战斗 → 获得战利品 → 强化自身/突破境界 → 寻找下一个挑战

### 30-120分钟循环（会话循环）
- **主要活动**：修炼和自定义角色，专注于境界突破和功法修炼
- **会话结构**：回顾当前进度 → 分配属性点 → 突破境界 → 修炼功法 → 调整装备 → 规划下一段探索
- **自然停点**：完成一次境界突破或达成一个修真里程碑  
**修真特色**：境界突破、功法熟练度提升、天赋网格解锁

### 数天/数周循环（长期进展）
- **成长方式**：探索九州修真界，发现新的修真区域、秘境和上古遗迹
- **长期目标**：解锁全部九大修真区域，收集所有修真功法，揭开飞升之谜
- **进度标志**：访问新修真区域、突破新境界、解锁绝世功法、推进主线剧情  
**修真特色**：九大境界进阶、九州地理探索、飞升之谜揭秘

## 玩家动机分析（基于自我决定理论）

### 自主性
- 玩家可以自由选择探索路径和成长方向
- 多样化的修真功法系统允许个性化构建

### 胜任感
- 通过不断修炼和挑战变得更强大
- 突破境界和解锁高级功法带来成就感

### 关联性
- 与修真界中的各路修士建立关系
- 体验丰富的修真故事情节

## 玩家类型验证

### 主要吸引：探索者
- 喜欢发现修真世界、寻找秘境和探索九州地图的玩家
- 享受在开放世界中漫游和发现隐藏的仙缘、上古遗迹  
**修真特色**：九州修真界探索、秘境发现、仙缘触发

### 次要吸引：成就者
- 喜欢克服挑战、收集功法和突破境界的玩家
- 通过收集稀有修真功法、法宝和达成境界突破获得满足感  
**修真特色**：境界突破成就、功法收集、天赋网格完成

### 适合人群
- 喜爱修真武侠文化的玩家
- 喜欢开放世界探索和修真成长的玩家
- 偏好深度角色成长和境界突破的玩家
- 对中国修仙文化感兴趣的国际玩家

## 范围和可行性

### 目标平台
- Steam (PC)
- 利用现代PC硬件性能提供更高质量的3D体验

### 推荐引擎
- Godot 4.6（用户已有经验）
- 适合2.5D或3D修真世界开发，且支持Steam导出

### 艺术风格
- 中国古典修真武侠风格
- 融合水墨画元素和写实细节
- 强调动态战斗效果和环境氛围

### MVP定义
- 核心战斗系统
- 基础修真功法系统
- 小规模开放世界（中原腹地）
- 1-2种仙缘类型
- 基础角色成长系统（境界突破）

### 最大风险
- 开放世界内容制作量大
- 修真武侠题材市场竞争激烈
- Steam平台发行和营销挑战

### 范围层级

#### MVP版本（3-4个月）
- 中原腹地区域的开放世界
- 基础战斗和修真功法系统
- 10-15种修真功法
- 3-5种仙缘事件类型
- 基础角色成长系统（炼气期境界）

#### 完整愿景（12-18个月）
- 九州修真界完整地图
- 50+种修真功法
- 丰富的仙缘事件系统
- 完整的角色成长和境界突破系统（九大境界）
- 深入的剧情和人物关系系统（飞升之谜）

## 视觉身份锚点

### 选定视觉方向：水墨修真风
- **核心理念**：融合传统水墨画艺术与中国修真元素
- **色彩哲学**：以青绿山水为主色调，点缀暖色系的战斗特效和灵气光效
- **设计原则**：
  1. 场景设计应体现中国传统山水画意境和修真仙境氛围
  2. 角色设计需突出修真者服饰的飘逸感和境界气质
  3. 战斗特效应展现内力、真元与招式的视觉冲击

## 技术考量

### 性能预算
- 目标60FPS在主流PC配置上运行
- 可使用更高多边形数量和纹理分辨率
- 实施LOD系统以优化大型开放世界性能

### 关键技术挑战
- 大型开放世界的流式加载
- 物理系统与修真动作的结合
- Steam平台集成（成就、云存档等）
