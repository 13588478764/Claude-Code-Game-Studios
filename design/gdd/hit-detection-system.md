# 命中检测系统

> **状态**: 设计中
> **作者**: 用户 + 代理
> **最后更新**: 2026-04-25
> **实现支柱**: 支柱1：深度武学系统

## 概述

命中检测系统采用"属性对抗 + 概率判定"的机制，通过"命中率 vs 闪避率"的对抗公式为玩家提供策略深度体验。系统利用2D俯视角的优势，摒弃复杂的物理碰撞检测，转而使用数值逻辑来决定攻击是否生效，既符合回合制策略性，又易于实现和平衡。

玩家通过投资身法属性、选择合适装备、应用状态效果，在"命中-闪避"的博弈中体验武侠高手对决的核心乐趣。系统支持普通攻击、技能、范围攻击等多种检测类型，并提供强制命中机制确保控制技能和爆发窗口期的收益稳定性。所有命中检测结果通过动态UI展示，普通攻击使用固定侧视角，强力技能触发特写镜头，Miss时呈现特殊特效。

如果没有这个系统，游戏将失去策略维度与职业特色，身法属性废弛，坦克/刺客同质化，控制技能贬值，战斗变得无悬念。该系统是实现"深度武学系统"游戏支柱的重要支撑，利用Steam平台的PC硬件优势提供高效的数值计算、动态UI展示和实时战斗反馈。

## 玩家幻想

玩家应该能够体验到"一击必中"、"飘逸难中"、"见招拆招"的武侠核心幻想，通过精准的命中控制和闪避时机把握直接体验到作为武林高手的快感与成就感。

直接层面：玩家在战斗中积极管理命中率和闪避率，选择合适的武学技能、装备和状态效果来应对不同敌人。这是显性的策略决策过程，直接决定了战斗的胜负和效率。玩家应该能够清晰地看到每个技能的命中预览、实际的命中/闪避结果、以及相关的视觉反馈，从而做出明智的战术选择。

间接层面：命中检测的底层逻辑（如属性对抗计算、概率判定、强制命中检查）由系统自动处理。玩家在后台不可见这些计算过程，只体验到最终的结果（是否命中、是否闪避、造成了多少伤害）。这种无缝的体验让玩家专注于策略思考和武侠对决，而不是复杂的数学计算。

参考游戏实现：
- 《最终幻想7重制版》的ATB系统和命中机制，通过精确的时机判断和属性对抗提供深度战斗体验
- 《女神异闻录5》的弱点打击系统，通过强烈的视觉反馈和数值变化提供爽快感
- 《暗黑破坏神4》的命中/闪避系统，通过不同颜色和大小的反馈文字提供直观的战斗信息

## 详细设计

### 核心规则

1. **命中机制**（属性对抗概率）：
   - **基础公式**（Base Formula）：
     - 命中率 = 基础命中率 + (攻击方身法 × 身法系数) - (防御方身法 × 身法系数) + 状态修正
     - 最终命中率 = clamp(命中率, 最小命中率, 最大命中率)（例如限制在5%-95%之间）
     - 是否命中 = 随机数 < 最终命中率
   - **强制命中**（Guaranteed Hit）：
     - 规则：某些特定状态或技能无视闪避率，直接判定为命中
     - 触发条件：
       - 敌人处于Break(破防)状态
       - 敌人处于Stun(眩晕)或Frozen(冻结)状态
       - 特定武学标签：[Sure_Hit]（如：锁定技、范围爆炸中心）

2. **影响因素**（多维度影响）：
   - **角色属性**（Stats）：
     - 身法(AGI)：核心属性，攻击方AGI提高命中率，防御方AGI提高闪避率
     - 福缘(LUK)：轻微影响命中波动（±2%），增加不确定性中的"运气"成分
   - **装备加成**（Equipment）：
     - 武器：提供基础命中率修正（如：+5% Hit）
     - 饰品：提供特殊词条（如：+10% 对眩晕目标命中，-5% 被远程命中几率）
   - **状态效果**（Buffs/Debuffs）：
     - 增益(Buff)：
       - Focus(专注)：下一击命中率+20%
       - Eagle_Eye(鹰眼)：远程攻击命中率+15%
     - 减益(Debuff)：
       - Blind(失明)：命中率-30%，闪避率-10%
       - Slowed(迟缓)：闪避率-15%
       - Rooted(禁锢)：闪避率归零（但未必强制命中，除非配合其他条件）
   - **武学特性**（Skill Traits）：
     - 范围攻击(AoE)：通常命中率略低于单体攻击（如：-10%），因为难以精准覆盖所有人
     - 远程攻击：受距离影响较小（回合制中距离通常为逻辑概念），但可被特定技能（如：Wind_Wall）降低命中
   - **环境因素**（Environment）：
     - 大雾/暴雨：全场命中率-5%，闪避率-5%（视线受阻，大家都看不清）
     - 高地优势：从高处攻击低处，命中率+5%

3. **检测类型**（多种攻击类型）：
   - **普通攻击命中**（Basic Attack Hit）：基于武器类型和角色身法计算，是最基础的命中检测
   - **技能命中**（Skill Hit）：
     - 单体技能：标准命中检测
     - 范围技能(AoE)：对范围内每个目标独立进行命中检测
     - 持续技能(DoT)：施加状态时进行一次命中检测，若成功则施加状态；后续每回合伤害通常不再检测命中
   - **反击/连携命中**（Counter/Link Hit）：触发反击或队友连携时，复用标准命中检测逻辑，但可能享受额外的命中加成

4. **Steam平台优化实现**：
   - **高效数值计算**：使用预计算缓存避免重复计算，多线程后台处理复杂公式
   - **动态UI展示**：实时显示命中预览和Miss反馈，不同颜色代表不同结果（白色=命中，灰色=Miss）
   - **实时战斗反馈**：当Miss时，屏幕显示灰色的"MISS"字样，伴随轻微的音效（如：风声、擦过声）
   - **音频沉浸感**：不同命中结果播放不同的音效（命中-金属碰撞声、Miss-风声、强制命中-特殊音效）

### 状态和转换

- **未检测状态**：攻击尚未开始命中检测，处于战斗指令选择阶段
- **命中计算状态**：系统根据攻击方和防御方属性计算最终命中率
- **强制命中检查状态**：系统检查是否满足强制命中条件
- **随机判定状态**：系统生成随机数并与最终命中率比较
- **命中结果状态**：系统确定最终命中结果（命中或Miss）
- **伤害结算状态**：如果命中，进入伤害计算流程；如果Miss，播放Miss特效

状态转换流程：
- 未检测 → 命中计算：玩家选择技能并确认，系统开始命中检测
- 命中计算 → 强制命中检查：计算完成命中率后，检查强制命中条件
- 强制命中检查 → 随机判定：如果不满足强制命中，则进行随机判定
- 强制命中检查 → 命中结果：如果满足强制命中，直接判定为命中
- 随机判定 → 命中结果：根据随机数和命中率确定最终结果
- 命中结果 → 伤害结算：如果是命中，进入伤害计算；如果是Miss，播放Miss特效
- 伤害结算 → 未检测：伤害结算完成，回到战斗指令选择阶段

### 与其他系统的交互

- **战斗系统**（CombatSystem）：
  - 数据输入：接收攻击者、防御者、技能数据等参数
  - 功能输出：返回命中结果（命中/Miss/强制命中）和相关标志位
- **伤害计算系统**（DamageCalculationSystem）：
  - 数据输入：查询命中检测结果，只有命中时才进行伤害计算
  - 功能输出：提供命中预览信息，帮助玩家了解技能命中率
- **生命值/防御系统**（HealthDefenseSystem）：
  - 数据输入：接收命中结果，只有命中时才扣减HP和Poise
  - 功能输出：提供防御方闪避率数据用于命中计算
- **装备系统**（EquipmentSystem）：
  - 数据输入：查询装备提供的命中率、闪避率加成等属性
  - 功能输出：提供装备属性对命中/闪避能力的影响计算
- **角色成长系统**（CharacterProgressionSystem）：
  - 数据输入：查询角色属性（AGI、LUK）对命中/闪避能力的影响
  - 功能输出：提供属性成长对命中率、闪避率的提升
- **UI系统**（UISystem）：
  - 数据输入：接收命中结果、命中率预览等信息
  - 功能输出：渲染命中预览、Miss反馈、闪避特效等UI元素

## 公式

### 命中率计算公式

`最终命中率 = clamp(基础命中率 + (攻击方身法 - 防御方身法) × 身法系数 + 状态修正, 最小命中率, 最大命中率)`

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 基础命中率 | base_accuracy | float | 0.8-0.95 | 技能或武器自带的基础命中率 |
| 攻击方身法 | attacker_agi | int | 10-200 | 攻击方的身法(AGI)属性值 |
| 防御方身法 | defender_agi | int | 10-200 | 防御方的身法(AGI)属性值 |
| 身法系数 | agi_factor | float | 0.003-0.01 | 每点身法对命中/闪避的贡献系数 |
| 状态修正 | status_modifier | float | -0.5-0.5 | Buff/Debuff提供的命中率修正 |
| 最小命中率 | min_chance | float | 0.05-0.1 | 最低命中率限制（5%-10%） |
| 最大命中率 | max_chance | float | 0.9-0.95 | 最高命中率限制（90%-95%） |
| 最终命中率 | final_hit_chance | float | 0.05-0.95 | 最终的命中率 |

**输出范围:** 0.05到0.95
**示例:** 当基础命中率为0.9，攻击方身法为80，防御方身法为60，身法系数为0.005，状态修正为0.1时，最终命中率 = clamp(0.9 + (80-60) × 0.005 + 0.1, 0.05, 0.95) = clamp(0.9 + 0.1 + 0.1, 0.05, 0.95) = clamp(1.1, 0.05, 0.95) = 0.95

### 强制命中判定公式

`是否强制命中 = 敌人破防状态 OR 敌人眩晕状态 OR 敌人冻结状态 OR 技能标签包含Sure_Hit`

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 敌人破防状态 | is_broken | boolean | true/false | 敌人是否处于Break(破防)状态 |
| 敌人眩晕状态 | is_stunned | boolean | true/false | 敌人是否处于Stun(眩晕)状态 |
| 敌人冻结状态 | is_frozen | boolean | true/false | 敌人是否处于Frozen(冻结)状态 |
| 技能标签包含Sure_Hit | has_sure_hit_tag | boolean | true/false | 技能是否包含[Sure_Hit]标签 |
| 是否强制命中 | is_guaranteed_hit | boolean | true/false | 是否强制命中 |

**输出范围:** true或false
**示例:** 当敌人处于破防状态(is_broken=true)，其他条件为false时，是否强制命中 = true OR false OR false OR false = true

### 范围攻击命中率公式

`范围攻击命中率 = 单体攻击命中率 × 范围命中修正`

**变量:**
| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 单体攻击命中率 | single_target_hit | float | 0.05-0.95 | 标准单体攻击的命中率 |
| 范围命中修正 | aoe_modifier | float | 0.8-0.9 | 范围攻击的命中率修正系数 |
| 范围攻击命中率 | aoe_hit_chance | float | 0.04-0.86 | 范围攻击的最终命中率 |

**输出范围:** 0.04到0.86
**示例:** 当单体攻击命中率为0.9，范围命中修正为0.9时，范围攻击命中率 = 0.9 × 0.9 = 0.81

## 边缘情况

- **如果Steam平台内存不足无法加载命中检测系统数据**：系统将使用默认的通用命中检测配置，确保核心战斗功能正常运行。
- **如果网络连接中断**（单机模式不影响）：在未来的多人模式中，系统将保存当前战斗状态，等待网络恢复后同步数据。
- **如果命中率计算结果溢出**：系统将自动限制最终命中率在5%-95%范围内，防止数值溢出导致游戏崩溃。
- **如果身法属性值异常**：系统将自动限制身法属性在10-200范围内，防止异常数据影响平衡。
- **如果随机数生成失败**：系统将使用备用随机数生成器，确保命中判定能够正常进行。
- **如果强制命中条件冲突**：系统将优先处理强制命中条件，确保控制技能和爆发窗口期的收益稳定性。

## 依赖关系

- **上游依赖**（此系统依赖的系统）：
  - **战斗系统**：需要战斗系统提供攻击者、防御者、技能数据等参数
  - **伤害计算系统**：需要伤害计算系统提供基础命中率、技能类型等数据
  - **生命值/防御系统**：需要生命值/防御系统提供防御方闪避率、状态效果等数据
  - **装备系统**：需要装备系统提供命中率、闪避率加成等属性数据
  - **角色成长系统**：需要角色成长系统提供AGI、LUK等基础属性数据

- **下游依赖**（依赖此系统的系统）：
  - **战斗系统**：依赖命中检测系统提供命中结果（命中/Miss/强制命中）和相关标志位
  - **伤害计算系统**：依赖命中检测系统提供命中结果，只有命中时才进行伤害计算
  - **UI系统**：依赖命中检测系统提供命中结果、命中率预览等信息

- **技术依赖**：
  - **Godot 4.6引擎**：利用Godot的随机数生成器、数值计算和UI系统功能
  - **Steam平台API**：使用Steam的性能监控功能优化数值计算效率

## 调整参数

- **基础命中率范围**：0.8-0.95（可调整范围：0.7-1.0）
- **身法系数范围**：0.003-0.01（可调整范围：0.001-0.02）
- **最小命中率范围**：0.05-0.1（可调整范围：0.01-0.2）
- **最大命中率范围**：0.9-0.95（可调整范围：0.8-0.99）
- **范围命中修正范围**：0.8-0.9（可调整范围：0.7-1.0）
- **福缘波动范围**：±2%（可调整范围：±1%-±5%）
- **环境影响范围**：±5%（可调整范围：±1%-±10%）

这些参数可以通过游戏配置文件进行调整，无需修改代码，便于平衡命中检测系统和适应不同难度级别。

## 视觉/音频要求

- **视觉风格一致性**：所有命中检测UI元素必须符合艺术圣经中定义的水墨武侠风格，包括青绿山水主色调和传统中式元素。
- **命中反馈显示**：不同颜色代表不同结果（白色=命中，灰色=Miss），字体大小根据重要性动态调整
- **特效表现**：
  - 命中效果：伤害数字正常显示，播放金属碰撞声
  - Miss效果：屏幕显示灰色的"MISS"字样，角色身上出现残影或白光表示成功闪避
  - 强制命中：特殊金色边框围绕伤害数字，播放特殊音效
- **UI动效**：
  - 命中预览：在战斗菜单选中技能时，显示"命中率：XX%"，若过低则字体变红警告
  - Miss反馈：灰色"MISS"字样从目标位置向上浮动，带有描边效果
  - 闪避特效：角色模型短暂闪烁白色，播放风声特效
- **音频要求**：
  - 命中音效：清脆的金属碰撞声或拳风声
  - Miss音效：轻柔的风声或擦过声
  - 强制命中音效：特殊的"叮"声配合屏幕震动
  - 背景音乐：战斗BGM根据命中/闪避情况动态调整节奏

## UI要求

- **命中预览界面**：
  - 位置：战斗菜单选中技能时，在技能描述下方显示
  - 样式：半透明提示条，显示"命中率：XX%"，若过低（<60%）则字体变红警告
  - 内容：包含预计的命中率、影响因素（如：身法差值、状态效果）
  - 交互：鼠标悬停显示详细计算过程，帮助玩家理解命中构成

- **命中反馈界面**：
  - 位置：战斗场景中目标头顶上方
  - 样式：不同颜色代表不同结果（白色=命中，灰色=Miss），字体大小根据重要性动态调整
  - 动画：命中数字正常显示，Miss字样从目标位置向上浮动，带有描边效果
  - 交互：点击可查看详细命中分解（基础命中率、修正系数等）

- **闪避特效界面**：
  - 位置：成功闪避的角色模型周围
  - 样式：角色模型短暂闪烁白色，出现残影或白光效果
  - 动画：闪避时播放特殊粒子效果，持续0.5秒
  - 交互：无交互，纯视觉反馈

- **详细命中分解界面**：
  - 位置：按F1打开开发者控制台，输入show_hit_breakdown命令
  - 样式：表格形式显示完整的命中计算过程
  - 内容：显示基础命中率、身法修正、状态修正、最终命中率等详细信息
  - 交互：支持复制命中计算日志，便于平衡测试和调试

- **UI交互原则**：
  - 所有UI元素应使用水墨风格图标和传统纹样边框
  - 命中反馈通过颜色和大小直观传达结果（白色=成功，灰色=失败）
  - 确保UI在不同分辨率下清晰可读，适配16:9、16:10、21:9等常见比例
  - 提供直观的命中预览和详细分解，帮助玩家理解战斗机制和做出明智决策

## 验收标准

- **GIVEN** 玩家使用普通攻击，**WHEN** 命中检测系统执行计算，**THEN** 系统正确使用基础命中率(90%-95%)和身法差值计算最终命中率。
- **GIVEN** 敌人处于Break状态，**WHEN** 玩家发动攻击，**THEN** 系统强制判定为命中，无视防御方闪避率。
- **GIVEN** Steam平台内存有限（<2GB），**WHEN** 进入战斗场景，**THEN** 系统使用默认的通用命中检测配置，确保核心战斗功能正常运行。
- **GIVEN** 游戏运行在不同分辨率的设备上（1920x1080到3440x1440），**WHEN** 查看命中预览界面，**THEN** UI元素正确适配屏幕尺寸，保持清晰可读。
- **GIVEN** 玩家命中率低于60%，**WHEN** 战斗菜单选中技能，**THEN** 命中率显示为红色字体警告，提示玩家风险较高。
- **GIVEN** 攻击Miss，**WHEN** 命中检测系统处理结果，**THEN** 屏幕显示灰色的"MISS"字样，角色身上出现残影或白光表示成功闪避。
- **GIVEN** 范围攻击命中率计算，**WHEN** 系统处理AoE技能，**THEN** 对范围内每个目标独立进行命中检测，使用修正后的命中率（单体命中率×0.8-0.9）。
- **GIVEN** 命中率计算结果溢出，**WHEN** 系统处理最终命中率，**THEN** 自动限制最终命中率在5%-95%范围内，防止数值溢出导致游戏崩溃。

## 开放问题

- **命中平衡性**：如何建立有效的命中平衡测试框架，确保不同角色构建和敌人配置之间的公平性？
- **动态难度调整**：如何根据玩家表现动态调整敌人强度和战斗节奏？
- **跨平台兼容性**：虽然目标平台是Steam (PC)，但如果未来需要支持其他平台，当前的命中检测系统设计是否足够灵活？
- **本地化支持**：如何设计命中检测系统以支持多语言本地化，特别是UI文本和音频提示？
- **多人模式扩展**：虽然当前是单人游戏，但命中检测系统是否为未来的多人合作或对战模式预留了扩展接口？
