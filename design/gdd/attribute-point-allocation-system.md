# 属性点分配系统

## 1. 概述

属性点分配系统允许玩家在角色升级时自定义分配属性点数，以塑造独特的角色build。该系统与角色成长系统紧密集成，支持六维属性体系和境界突破机制。

## 2. 核心机制

### 2.1 属性体系
- **力道**：影响物理攻击力、负重能力
- **身法**：影响闪避率、移动速度、先攻值
- **根骨**：影响生命值上限、防御力、内力上限
- **悟性**：影响武学学习速度、暴击率、技能效果
- **定力**：影响抗控制能力、内力回复率、命中率
- **福缘**：影响奇遇触发概率、稀有物品掉落率、商人折扣

### 2.2 属性点获取
- **基础获取**：每升1级获得5点自由属性点
- **境界突破奖励**：境界突破不额外给予属性点，仅提供全属性+10%加成
- **总计属性点**：99级 × 5点 = 495点属性点

### 2.3 分配规则
- **分配时机**：可在任意安全区域（非战斗状态）进行属性点分配
- **重置机制**：每次境界突破后可免费重置所有已分配属性点一次
- **付费重置**：使用特殊道具"洗髓丹"可在任意时间重置属性点
- **属性上限**：单个属性最高可分配至99点（受等级限制）

## 3. 技术规格

### 3.1 数据结构
```yaml
AttributeAllocation:
  totalPoints: Integer  # 总获得属性点数（最大495点）
  allocatedPoints: Integer  # 已分配属性点数
  attributes:
    strength: Integer  # 力道
    agility: Integer   # 身法  
    constitution: Integer  # 根骨
    intelligence: Integer  # 悟性
    willpower: Integer  # 定力
    luck: Integer  # 福缘
  resetCount: Integer  # 免费重置次数（境界突破获得）
```

### 3.2 接口定义
- `allocatePoint(attribute: String)`: 分配1点到指定属性
- `resetAttributes()`: 重置所有属性点（消耗免费重置次数或洗髓丹）
- `getAvailablePoints()`: 获取可用属性点数
- `getAttributeValue(attribute: String)`: 获取指定属性值

## 4. 平衡考虑

### 4.1 Build多样性
- 确保六维属性都有明确的用途和价值
- 避免出现明显的最优解，鼓励多样化的build选择
- 不同武学流派对属性有不同的偏好

### 4.2 新手友好性
- 提供智能推荐分配方案（基于当前武学配置）
- 允许随时重置，降低试错成本
- 清晰的属性效果说明

## 5. 依赖关系

- **依赖系统**：角色成长系统、等级提升机制
- **被依赖系统**：战斗系统、伤害计算系统、武学系统

## 6. 验收标准

- [ ] 玩家可以在升级后分配属性点
- [ ] 境界突破后获得额外属性点和免费重置机会
- [ ] 属性点分配实时影响角色战斗属性
- [ ] 支持使用洗髓丹进行付费重置
- [ ] 提供智能推荐分配方案
- [ ] 属性点数据正确保存和加载
