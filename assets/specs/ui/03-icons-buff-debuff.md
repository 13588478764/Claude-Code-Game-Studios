# 03 — Buff / Debuff 图标

> 战斗中的增益与减益状态图标，HUD 上方堆叠显示。
> 共 ~36 个图标（增益 18 + 减益 18）。

**引用文档**: [design/gdd/status-effects-system.md](../../../design/gdd/status-effects-system.md), [design/ux/hud.md](../../../design/ux/hud.md)

## 设计原则

- **极小尺寸辨识**: HUD 渲染 32×32px，主体必须超过 70% 占比
- **正负易分**: 增益用暖色系/上扬箭头，减益用冷色系/下沉箭头或破碎元素
- **类别分组配色**: 同类型 Buff 共享主色（攻击系红/防御系蓝/增益系绿/控制系紫）
- **方框 vs 圆形**: Buff 用圆形玉佩外框，Debuff 用棱形碎片外框，便于盲识

## 通用规格

| 项 | 值 |
|---|----|
| **基础尺寸** | 64×64px（HUD 显示 32×32） |
| **格式** | PNG-32 透明背景 |
| **路径** | `assets/ui/buff_icons/` |
| **外框** | Buff = 圆形玉佩；Debuff = 棱形碎玉 |

## 通用提示词模板

```
水墨修真风格的[增益/减益]状态图标, [圆形玉佩/棱形碎玉]外框, 主体居中,
[类别配色], 灵气流动效果, 透明背景, 极简扁平, 32×32 网格友好,
中国仙侠美学
```
