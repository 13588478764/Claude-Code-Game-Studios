# 04 — 武学 / 天赋图标

> 玩家技能树、武学功法、天赋节点的视觉资产。
> 含 16 天赋节点 + ~16 武学技能 = ~32 项。

**引用文档**: [design/ux/character-panel.md](../../../design/ux/character-panel.md), [design/gdd/talent-system.md](../../../design/gdd/talent-system.md), [design/gdd/martial-arts-system.md](../../../design/gdd/martial-arts-system.md)

## 设计原则

- **类别色彩**: 不同流派功法用主色区分（攻击红 / 防御蓝 / 辅助绿 / 控制紫 / 修身金）
- **图标可读性**: 64×64 渲染下主体清晰
- **天赋分层**: 4×4 天赋树第 1-4 层视觉风格递进（朴素→华丽）
- **未学/已学**: 灰阶 + 锁链 vs 全彩 + 微光

## 通用规格

| 项 | 值 |
|---|----|
| **基础尺寸** | 128×128px（实际渲染 64×64） |
| **格式** | PNG-32 透明背景 |
| **路径** | `assets/ui/skill_icons/` , `assets/ui/talent_icons/` |
| **状态变体** | locked(灰+锁) / unlocked(默认) / active(微光) |
