# 10 — 物品 / 装备图标

> 背包内的所有物品图标（武器、防具、消耗品、材料、丹药、法宝等）。
> 共 ~70 项。

**引用文档**: [design/ux/inventory-panel.md](../../../design/ux/inventory-panel.md), [design/gdd/item-system.md](../../../design/gdd/item-system.md), [assets/data/items.json](../../data/items.json)

## 设计原则

- **64×64 极简识别**: 主体占据 70%+ 面积
- **类别区分清晰**: 武器/防具/消耗品/材料/法宝五大类视觉风格不同
- **稀有度边框统一**: 由清单 09 提供，本清单只出主体
- **古风韵味**: 严格水墨修真风，避免现代设计

## 通用规格

| 项 | 值 |
|---|----|
| **基础尺寸** | 128×128px（背包格 64×64） |
| **格式** | PNG-32 透明背景 |
| **路径** | `assets/ui/item_icons/` |
| **背景** | 透明（边框由代码层叠加） |

## 通用提示词模板

```
水墨修真风格的物品图标, 方形构图, 主体居中占 70%+, 物品悬浮于
淡淡灵气云气之上, [物品具体描述], [稀有度对应配色暗示],
工笔细腻, 透明背景, 64×64 网格友好, 中国仙侠美学
```
