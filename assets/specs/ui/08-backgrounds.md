# 08 — 场景 / 菜单背景

> 主菜单、加载、对话、战斗、剧情等界面的全屏背景图。
> 共 ~16 张背景。

**引用文档**: [design/ux/main-menu.md](../../../design/ux/main-menu.md), [design/ux/loading-screen.md](../../../design/ux/loading-screen.md), [design/art/art-bible.md](../../../design/art/art-bible.md), [design/levels/act1-jiangnan-water-town.md](../../../design/levels/act1-jiangnan-water-town.md)

## 设计原则

- **氛围至上**: 背景为玩家奠定情绪基调
- **留白构图**: 中央或一侧留白以容纳 UI 元素
- **图层友好**: 必要时分前/中/远景三层（便于视差）
- **风格统一**: 全部使用宋代山水画风 + 水墨晕染

## 通用规格

| 项 | 值 |
|---|----|
| **基础尺寸** | 1920×1080px (16:9) |
| **4K 备份** | 3840×2160px |
| **格式** | JPG (低压缩) 或 PNG-32 (含 alpha) |
| **路径** | `assets/backgrounds/` |
| **画风** | 宋代山水画 + 水墨写意 + 仙侠氛围 |

## 通用提示词模板

```
宋代山水画风格的全屏背景, [场景描述], 水墨写意, 留白构图,
[主色调], 笔触苍劲, 古韵深远, 仙侠氛围, 概念艺术, 4K 画质,
中国传统色彩, 范宽/马远/傅抱石风格参考, [前/中/远景描述]
```
