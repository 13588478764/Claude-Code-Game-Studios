# 01 — 境界图标 (Realm Icons)

> 修真九大境界的视觉标识，是修炼系统的核心视觉资产。每个境界一个主图标，
> 共 9 个；另含 9 个境界突破特效贴图。

**引用文档**: [design/gdd/cultivation-system.md](../../../design/gdd/cultivation-system.md), [design/ux/hud.md](../../../design/ux/hud.md)

## 设计原则

- **递进感**: 9 个境界从下到上需有明显视觉等级差，越高境界越华丽磅礴
- **统一性**: 共享圆形外轮廓、相同尺寸、相同描边风格
- **辨识度**: 玩家在 HUD 一瞥即知当前境界
- **文化感**: 取道家、佛家、太极意象，避免西方魔幻
- **状态变体**: 每个境界图标含「锁定」「解锁/未达成」「当前」「已完成」4 态

## 通用规格

| 项 | 值 |
|---|----|
| **基础尺寸** | 256×256px（HUD 显示 24×24 / 角色面板 64×64） |
| **格式** | PNG-32 透明背景 |
| **路径** | `assets/ui/realm_icons/` |
| **状态变体** | default / locked / current / completed (4 态) |
| **背景** | 透明，主体居中 |
| **画风** | 水墨修真风 + 道纹装饰 + 灵气流动 |

## 通用提示词模板

```
水墨修真风格的境界标识图标, 圆形构图, 主体居中, 透明背景,
[境界专属意象], 道家符号点缀, 灵气流动效果, 中国水墨写意,
青绿/金色调为主, 边缘有[等级对应]描边, 高细节, 概念艺术,
4K 画质, 中国仙侠美学
```

## 状态变体说明（通用，4 态共享生成）

| 状态 | 处理方式 |
|------|---------|
| `default` | 主图，已开放但非当前 |
| `locked` | 主图叠加 50% 灰度 + 锁链或封印纹 |
| `current` | 主图 + 外圈金色脉动光环（程序生成或单独贴图） |
| `completed` | 主图右下角加金色对勾纹章 |

> **建议**: locked / current / completed 三态可由程序对 default 进行后处理生成，
> 节省美术资源；如要求高品质可另出 4 套独立贴图。
