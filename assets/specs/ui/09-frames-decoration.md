# 09 — 边框 / 装饰元素

> UI 面板边框、按钮、分隔线、转场特效等装饰资源。
> 共 ~16 项，多数支持 9-Slice 拉伸。

**引用文档**: [design/art/art-bible.md](../../../design/art/art-bible.md), [design/ux/hud.md](../../../design/ux/hud.md)

## 设计原则

- **9-Slice 友好**: 边框资源四角与四边可独立拉伸
- **风格统一**: 全部采用古风纹饰（卷云纹/回字纹/八卦纹/竹节纹）
- **轻量装饰**: 不喧宾夺主，主体内容仍是焦点
- **品质感**: 描边精细，避免锯齿与色阶

## 通用规格

| 项 | 值 |
|---|----|
| **边框基础尺寸** | 256×256px (含九宫格切片标注) |
| **格式** | PNG-32 透明背景 |
| **路径** | `assets/ui/frames/` , `assets/ui/decorations/` |
| **9-Slice 标注** | 提供 PSD 含切片参考线 |

**清单总计**: 4 边框 + 5 稀有度边框 + 6 按钮控件 + 6 装饰元素 = 21 项

> **生产建议**:
> - **P0 必出 (Alpha)**: 4 边框基础 + 5 稀有度 + 标准/主菜单按钮 + 关闭 + 进度条 = 13 张
> - **P1 次批 (Beta)**: 任务卷轴 + 滚动条 + 分隔线 + 标题带 + 转场 = 5 张
> - **P2 末批 (Release)**: 角部装饰 + 章节卷轴 + 经验特效 = 3 张
> - **重要**: 9-Slice 边框必须标注切片点，建议同步出 PSD 源文件
> - **建议**: 整套 UI 装饰建议同一美术统一出图，避免风格不一
