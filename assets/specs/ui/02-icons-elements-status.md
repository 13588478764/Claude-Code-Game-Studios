# 02 — 五行 / 战斗状态图标

> 五行系统是战斗与功法克制的核心机制，状态图标在 HUD 高频显示。
> 本清单含 5 元素 × 4 态 = 20 个五行图标，外加 5 个战斗状态图标。

**引用文档**: [design/gdd/five-elements-system.md](../../../design/gdd/five-elements-system.md), [design/ux/hud.md](../../../design/ux/hud.md), [design/gdd/combat-system.md](../../../design/gdd/combat-system.md)

## 设计原则

- **极简辨识**: HUD 32×32 显示，必须一眼识别
- **五行分色**: 严格遵循传统五行配色（金白银 / 木青绿 / 水蓝黑 / 火朱赤 / 土黄褐）
- **状态语义**: 4 态视觉差异显著（中性/抗性/弱点/破弱）
- **统一外形**: 五元素共用同款外环（圆形 + 道纹）

## 二、五行状态变体（每元素 4 态，共 20 个）

> 5 元素 × 4 态 = 20 张贴图。每个状态可由程序对 `active` 后处理，
> 也可单独出图。下表给出独立出图时的提示词差异。

### 状态语义

| 状态 | 含义 | 视觉处理 |
|------|------|---------|
| `active` (中性) | 默认，元素正常存在 | 主图饱和度正常，亮度 100% |
| `abstinence` (戒断) | 该元素被压制/失效 | 50% 灰度去色 + 锁链纹叠加 |
| `weakness` (弱点) | 敌人弱该元素，标记高亮 | 红色光晕外圈脉动 |
| `broken` (破弱) | 弱点已被攻破 | 主图叠加金色裂纹 + 半透明 |

### 命名规则

```
element_icon_[元素]_[状态].png
例:
  element_icon_metal_active.png
  element_icon_metal_abstinence.png
  element_icon_metal_weakness.png
  element_icon_metal_broken.png
```

### 列表（金/木/水/火/土 各 4 态）

| 元素 | active | abstinence | weakness | broken | 优先级 |
|------|--------|-----------|----------|--------|--------|
| 金 metal | ✓ | ✓ | ✓ | ✓ | P0 / P1 / P0 / P1 |
| 木 wood | ✓ | ✓ | ✓ | ✓ | P0 / P1 / P0 / P1 |
| 水 water | ✓ | ✓ | ✓ | ✓ | P0 / P1 / P0 / P1 |
| 火 fire | ✓ | ✓ | ✓ | ✓ | P0 / P1 / P0 / P1 |
| 土 earth | ✓ | ✓ | ✓ | ✓ | P0 / P1 / P0 / P1 |

> **简化方案**: active 4 张为 P0 必出；其余 16 张可由 active 后处理生成（推荐）。

**清单总计**: 5 元素主图 + 20 状态变体 + 5 战斗状态 = 30 项

> **生产建议**:
> - **首批必出 (P0)**: 5 元素 active + Down + Break = 7 张
> - **次批 (P0/P1)**: weakness 5 张 + Link/Execute/Parry = 8 张
> - **末批 (P1)**: abstinence + broken 各 5 张可由后处理代替
