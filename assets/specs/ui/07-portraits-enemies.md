# 07 — 敌人 / Boss 立绘

> 战斗中遇到的敌人与剧情 Boss 立绘，用于战斗 UI 与剧情对话。
> 共 ~18 个敌人。

**引用文档**: [design/art/character-visual-profiles.md](../../../design/art/character-visual-profiles.md), [design/gdd/enemy-design.md](../../../design/gdd/enemy-design.md)

## 设计原则

- **威胁感分级**: 普通敌人 → 精英 → Boss → 最终 Boss 视觉冲击递增
- **敌人主题统一**: 同一区域敌人共享视觉元素（妖兽群/魔修/邪修/凶兽）
- **Boss 标识**: 大型 Boss 含金红色背景烟雾或紫黑魔气
- **高标识度**: 战斗中 200×300 缩略图也需立刻识别威胁等级

## 通用规格

| 项 | 值 |
|---|----|
| **敌人立绘尺寸** | 800×1200px (3:2) |
| **Boss 立绘尺寸** | 1600×2000px (4:5 大型) |
| **格式** | PNG-32 透明背景 |
| **路径** | `assets/portraits/enemies/` |
| **画风** | 工笔重彩 + 水墨晕染 + 凶煞氛围 |

> **⚠️ 背景规则修正（2026-07-21）**：立绘为叠加层 sprite，**只画角色/妖兽本体，禁止绘制背景**。本文件历史条目提示词结尾的"背景墨色烟雾 / 火焰云气 / 紫黑魔气"等字样为错误写法（与"透明背景"矛盾），实际生成时应忽略，统一以"无背景（透明背景）"收尾；Boss 的金红煞气等标识元素仅可以"身周环绕"形式附着于角色本体。详见 [11-portraits-act1-expansion.md](11-portraits-act1-expansion.md)「背景规则」。

**清单总计**: 8 普通 + 3 精英 + 5 Boss = 16 项敌人立绘

> **生产建议**:
> - **P0 必出 (Alpha)**: 山贼喽啰 + 邪修弟子 + 邪修长老 + 血煞老祖 + 万妖之王 = 5 张
> - **P1 次批 (Beta)**: 火狼/水蛇/山妖/鬼修 + 雷鹫 + 五行守卫 + 上古凶神 + 心魔 = 8 张
> - **P2 末批 (Release)**: 狐妖 + 傀儡 + 天劫真君 = 3 张
> - **Boss 战斗背景**: Boss 立绘建议同步出 1-2 张专属战斗背景（见清单 08）
