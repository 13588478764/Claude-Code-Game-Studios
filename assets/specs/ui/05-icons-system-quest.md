# 05 — 系统 / 任务 / UI 元素图标

> 系统按钮、菜单图标、任务标识、地图图例等通用 UI 元素。
> 共 ~22 项。

**引用文档**: [design/ux/hud.md](../../../design/ux/hud.md), [design/ux/main-menu.md](../../../design/ux/main-menu.md), [design/ux/quest-log.md](../../../design/ux/quest-log.md), [design/ux/world-map.md](../../../design/ux/world-map.md)

## 设计原则

- **极简扁平**: 系统图标避免过度装饰，主体识别度优先
- **统一线条**: 描边粗细一致，圆角统一
- **配色规范**: 默认态米白 #F5F5DC + 墨黑描边；激活态金色 #FFD700
- **48×48 友好**: HUD 系统按钮渲染 48×48px

## 通用规格

| 项 | 值 |
|---|----|
| **基础尺寸** | 96×96px（HUD 显示 48×48） |
| **格式** | PNG-32 透明背景 |
| **路径** | `assets/ui/system_icons/` |
| **状态变体** | default / hover / active / disabled |
