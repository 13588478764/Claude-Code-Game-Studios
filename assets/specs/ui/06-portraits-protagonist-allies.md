# 06 — 主角 / 队友立绘

> 玩家角色与可招募队友的立绘，用于对话框、角色面板、队伍选择 UI。
> 共 ~12 个角色。

**引用文档**: [design/art/character-visual-profiles.md](../../../design/art/character-visual-profiles.md), [design/narrative/characters.md](../../../design/narrative/characters.md)

## 设计原则

- **统一画风**: 工笔重彩 + 水墨晕染（半写实，避免日漫萌系）
- **角色特征鲜明**: 视觉关键词必须显著（云中鹤的青、柳如烟的红等）
- **多表情系统**: 每个主要角色含 4-6 张表情立绘（默认/微笑/愤怒/悲伤/震惊/思考）
- **多姿势支持**: 主要角色可考虑半身（对话）+ 全身（角色面板）双版本

## 通用规格

| 项 | 值 |
|---|----|
| **半身像尺寸** | 800×1200px (3:2 上半身) |
| **全身像尺寸** | 1200×2000px (3:5 全身) |
| **格式** | PNG-32 透明背景 |
| **路径** | `assets/portraits/protagonist/` , `assets/portraits/allies/` |
| **画风** | 工笔重彩 + 水墨晕染 + 仙侠氛围 |

## 通用提示词模板

```
中国仙侠工笔重彩人物立绘, [姓名/身份/年龄/性别], [发型/服装/配饰描述],
[体态姿势], [面部表情], [手持物品/法器], [背景留白/淡墨晕染],
水墨修真风格, 工笔细腻, 留白构图, 透明背景, 概念艺术, 4K 画质,
《卧虎藏龙》《长安三万里》风格参考
```

**清单总计**: 1 主角（含觉醒态）+ 11 队友 = 12 角色

> **生产建议**:
> - **P0 必出 (Alpha)**: 主角默认 + 云中鹤 + 柳如烟 + 萧寒夜 = 4 角色 × 3 表情/角色 = 12 张
> - **P1 次批 (Beta)**: 慕容雪 + 铁无双 + 沈青螺 = 3 角色 × 4 表情 = 12 张
> - **P2 末批 (Release)**: 楚天南 + 玄机子 + 顾长歌 + 灵犀 + 老张 + 主角觉醒 = 6 角色 × 2 表情 = 12 张
> - **总立绘量**: 约 36-50 张（取决于表情变体数量）
> - **建议**: 每角色优先出 default + smile + serious 三态，剩余表情按剧情需求补
