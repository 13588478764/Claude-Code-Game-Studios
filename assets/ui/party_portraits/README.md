# 队友头像资源目录

此目录存放所有队友的头像资源。

## 资源规范

- **尺寸**: 60x60 像素
- **格式**: PNG (推荐) 或 JPG
- **命名规范**: `party_member_{member_id}.png`

## 占位符说明

当前目录包含占位符文件,实际头像资源需要由美术团队提供。

## 资源列表

- party_member_001.png - 队友1头像
- party_member_002.png - 队友2头像
- party_member_003.png - 队友3头像
- party_member_004.png - 队友4头像
- party_member_005.png - 队友5头像

## 加载策略

如果指定的头像文件不存在,UI将显示默认占位符(灰色圆形)。
