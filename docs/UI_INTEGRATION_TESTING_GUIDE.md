## 🎮 手动游戏内测试

### 准备工作

1. 确保CharacterSystem已添加到AutoLoad:
   - 打开 `Project > Project Settings > AutoLoad`
   - 添加 `CharacterSystem`: `res://src/scripts/character/character_system.gd`

2. 确保EncounterIntegration已添加到AutoLoad:
   - 添加 `EncounterIntegration`: `res://src/scripts/encounter/encounter_integration.gd`

#### 步骤1: 打开场景
```
1. 在Godot编辑器中打开 src/scenes/ui/character_growth_ui.tscn
2. 按 F6 运行当前场景
```

## 🔧 常见问题排查

### 问题1: CharacterSystem not found

**症状**: 控制台显示 `[CharacterGrowthUI] CharacterSystem not found!`

**解决方案**:
```
1. 打开 Project > Project Settings > AutoLoad
2. 添加 CharacterSystem:
   - Path: res://src/scripts/character/character_system.gd
   - Node Name: CharacterSystem
3. 重启场景
```

### 问题2: 入场动画不显示

**症状**: 奇遇卡片直接显示，没有动画效果

**解决方案**:
```
1. 检查AnimationPlayer是否正确配置
2. 确认AnimationLibrary已创建
3. 验证动画名称为"entrance"
4. 查看控制台是否有警告信息
```

### 问题3: 属性分配无效

**症状**: 点击确认按钮后属性没有增加

**解决方案**:
```
1. 检查滑块值是否>0
2. 确认CharacterSystem引用正确
3. 查看控制台错误信息
4. 验证信号连接是否正常
```

### 问题4: 天赋解锁失败

**症状**: 点击天赋按钮没有反应

**解决方案**:
```
1. 检查是否有可用天赋点
2. 确认天赋未被重复解锁
3. 查看控制台输出
4. 验证CharacterSystem.unlock_talent()返回值
```
